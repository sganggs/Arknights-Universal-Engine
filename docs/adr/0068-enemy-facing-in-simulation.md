# 0068 敌人的左右面向记在模拟里，渲染读它

- 状态：已采纳
- 日期：2026-10-29
- 来源：PRTS「作战机制」§3.2.2 敌人朝向与相对方位（[oldid=428460](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=428460)）「具有面向判定的敌人只有左右两种朝向，其朝向与其模型表现一致。」；issue #57 的讨论

## 背景

渲染-4 原来自己按敌人的移动方向给模型镜像，模拟里没有敌人的朝向。§3.2.2 写敌人只有左右两种朝向，并且朝向与模型一致；伤害按来源在左还是在右分正面、背面，有几名敌人的能力靠它（箭棘兽背面减伤，岩冠兽、圆仔、驮兽补给员等正面减伤，圆仔、驮兽补给员面向干员较多的一侧）。只在渲染里推，模拟用不上；只在这几名的能力里各记一份，移动、阻挡、攻击时的转向就要各写一遍，渲染也看不到。

## 决定

- 每个敌人在模拟里有左右面向：单位的 `lr`，向左为 −1，向右不写（敌能-90）。它进入快照和状态哈希。出场的朝向、移动、阻挡、攻击时怎么转，以及背后怎么判定，写在敌能-90；改面向的能力写在各自的条款里。
- 渲染状态第 7 版起，每个单位带 `lr`：敌人向左为 −1、向右为 1，其他单位为 0。渲染-4 的敌人模型镜像、渲染-11 敌人特效的左右都读它，不再按移动方向推。
- 所有敌人都记，不只是有这类能力的。

## 理由

- 一份朝向：规则只写在模拟里一处，结算和画面看到的是同一个值。被阻挡、攻击时转向而这一帧没有移动的，模型也跟着转，与 §3.2.2「其朝向与其模型表现一致」相符；按移动方向推的做法做不到这一点。
- 渲染只读、不推：渲染状态多一格，渲染不需要知道转向的规则。

## 后果

- 敌能-90 合入时，所有对局的状态哈希变了一次（多了 `lr`）。渲染改读它不再改变状态哈希，只把渲染状态升到第 7 版；旧版本的渲染状态读不进来（ADR 0053：改格式就升版本）。
- 以后改面向的能力只改模拟的 `lr`，渲染自动跟着。
- 装置不是敌人，渲染状态里是 0，仍按移动方向（它们不移动）。

## 备选方案

- 只在渲染里按移动方向推：模拟里的减伤和背后判定用不上它，也做不到攻击、阻挡时转向。
- 只给有面向能力的敌人记：其他对局的状态哈希不变，但渲染要两套做法（有记的读模拟，没记的自己推），转向规则也会分散。
