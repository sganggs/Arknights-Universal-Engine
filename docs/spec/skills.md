# 技能

实现见 `packages/sim/src/skills.js`（技能运行）和 `packages/sim/src/sp.js`（技力），官方技能的数据转换和行为见 `packages/content/src/skills.js`。

### 技能-1 技能数据与种类

技能来自 skill_table 的一级数据：

- 触发类型：自动、手动、被动；
- 技力回复方式：自动回复、攻击回复、受击回复；
- 技力消耗、初始技力、充能次数（maxChargeTime，至少 1）；
- 持续时间（秒）、持续类型（弹药或普通）；
- blackboard（键和数值）。

按数据分成五种：

| 种类 | 条件 |
|---|---|
| 被动 | 触发类型为被动 |
| 弹药 | 持续类型为弹药（AMMO） |
| 持续 | 持续时间大于 0 |
| 下次攻击 | 没有持续时间，blackboard 有攻击类的键（技能-5） |
| 立即 | 其余 |

开启时切换到替身、持续时间不大于 0 的，按立即，不当作下次攻击（职业-15）。

- 来源：数据：skill_table[].levels[]（skillType、spData、duration、durationType、blackboard）；[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)「触发条件」：自动触发、手动触发、被动；种类的划分为推断 INF-0031；开启时切换的例外见职业-15，为推断 INF-0303

### 技能-2 技力

- **整数**：技力是整数，不超过上限 = 技力消耗 × 充能次数。部署时（每次部署）获得初始技力。
- **自动回复**：每个技力点来自一个「技力冷却槽」。槽在技力自然回复速度为 1 时 1 秒填满。
  - 每帧，槽的进度加上「技力自然回复速度 ÷ 30」。
  - 剩余时间（1 − 进度）÷ 速度小于 10⁻⁵ 秒时，槽算填满：得 1 点技力，进度减 1，多出的部分保留。
  - 技力已满或阻回时，槽保留进度，暂停计时。
- **攻击回复**：干员每进行一次不由技能发动的攻击，得 1 点。一次攻击打多个目标也只算一次。
- **受击回复**：干员每受到一次伤害（伤害-7），得 1 点。无敌、消失时受到的伤害不算；被闪避、被护盾或屏障挡下的也算；生命流失不算。
- **阻回**：技能运行期间不回复技力；持有阻回（状态-9）时也不回复。
- **无视阻回**：写明无视阻回的技力（如重岳【变身】后每次普通攻击额外回复的 1 点、佩佩天赋的技力）在技能运行期间和持有阻回时也照加，到上限为止。

- 来源：[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)：自动回复「通常每秒回复1点技力」，技力冷却槽、「当前剩余冷却时间 < 10^-5秒（0.1毫秒）时，视为冷却完成」、阻回或技力条已满时保留剩余冷却时间并暂停计时，「对技力自然回复速度的修改实际上是对技力冷却槽的修改」，「其最小单位为1点，不存在小数部分」，攻击回复「每次攻击时回复1点技力」，受击回复「每次被攻击时回复1点技力」，「仅在携带者入场时，技能会预先充入"初始技力"」，充能技能「当前技力上限等于该技能技力需求的X倍」；无视阻回：[PRTS「重岳」oldid=434893](https://prts.wiki/index.php?title=%E9%87%8D%E5%B2%B3&oldid=434893)「每次普通攻击额外回复1点技力（无视阻回）」、[PRTS「佩佩」oldid=435093](https://prts.wiki/index.php?title=%E4%BD%A9%E4%BD%A9&oldid=435093)「天赋技力回复效果无视阻回」；攻击和受击的计法为推断 INF-0032

### 技能-3 发动

- **共同条件**：技能没在运行，技力不少于技力消耗，干员能行动（不处于晕眩、冻结、沉睡、浮空、麻痹震颤），没有被沉默或静默（状态-9）。
- **手动**：玩家的技能指令（协议第 2 版：`{ type: 'skill', unit }`）在执行帧的指令阶段生效。只能对自己在场的干员发出，技能必须是手动的；不满足条件的指令被忽略。技能运行中、可以关闭时，同一个指令改为关闭技能（技能-7）。
- **自动**：在干员每帧的回合里检查。
  - 立即类技能（没有攻击类的键）一满足条件就发动；不进行普通攻击的干员（如吟游者，职业-13）的自动技能也一满足条件就发动；
  - 其他自动技能在干员即将攻击时（冷却结束、有目标）发动，这次攻击就算技能的攻击。
  - 内容的行为可以指定发动时机（就绪即发动，或即将攻击时发动），也可以按当时的情况给出其中之一。
- **被动**：部署时发动。

- 来源：[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)：自动触发「技能在满足给定条件后自动触发」，手动触发「需要玩家交互以触发」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 晕眩「无法移动、阻挡、攻击及使用技能」；[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606) 沉默「无法触发可沉默的技能与能力」；自动技能的发动时机为推断 INF-0033；不攻击的干员就绪即发动为推断 INF-0238（数据：浊心斯卡蒂二技能、魔王一技能是自动、持续时间无限的吟游者技能）

### 技能-4 运行与结束

技能发动后发 `skillStart`、结束后发 `skillEnd` 事件，带原因（钩子-3）。

发动时扣除技力消耗；有充能的技能保留剩下的技力。各种技能的运行和结束：

- **持续**：持续时间换成 n 帧（时间-2）。从发动那一帧起运行，n 帧后在干员的回合开始时结束。晕眩不停止计时。
- **无限**：没有持续时间、不是弹药、不是被动的技能，说明写了「持续时间无限」的（如拉普兰德一技能、铃兰二技能、史尔特尔三技能、浊心斯卡蒂二技能），按持续技能处理但没有结束的时刻：一直运行到玩家关闭它（可关闭的，技能-7）或干员离场；它的攻击键用在运行期间的每一次攻击上，不是只用一次。
- **弹药**：弹药数取 blackboard 的 `attack@trigger_time`，没有时取 `trigger_time`（技能说明写作「装有{trigger_time}发弹药」，如克莱门莎三技能、机械师二技能、望三技能），再没有时取 `cnt`，再没有时为 1。技能的每次攻击用掉一发。弹药不多于 0 时，到下次攻击才退出技能，这次攻击是普通攻击。持续时间大于 0 的弹药技能，时间到了也结束。
- **下次攻击**：等待干员的下一次攻击，用技能的攻击修正打完这一次就结束。
- **立即**：发动当时起作用，同一帧结束。
- **被动**：有持续时间的按持续结束，没有的一直运行。

技能开始和结束时各产生一个表现事件（事件第 2 版：`skill`，active 为 1 或 0）。

内容可以设运行中的弹药技能剩余的弹药数（至少 0）。

- 来源：[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)：「触发技能后，触发技能的单位将消耗相应的技力」，「绝大多数技能结束时，因技力在处理时被消耗，其技力将从0开始重新积累」，弹药技能「当下次普通攻击时弹药不高于0，则会退出技能状态」；弹药的键和各种技能的帧计法为推断 INF-0034；无限：[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)「增益未说明持续时间可认为持续时间无穷大，而且也确实存在持续时间无限的部署触发类技能」，数据：skill_table 中 duration 为 −1、说明写「持续时间无限」的主动技能 41 个；按说明文字识别、按持续技能运行为推断 INF-0237

### 技能-5 通用效果

没有专门行为的技能，按 blackboard 起作用：

- **属性键**：技能运行期间（持续、弹药、被动），在干员身上加一个 Buff，修饰器如下表。

  | 键 | 修饰器 | 类型 |
  |---|---|---|
  | `atk` | `atkPct` | 直接乘算 |
  | `def` | `defPct` | 直接乘算 |
  | `max_hp` | `hpPct` | 直接乘算 |
  | `move_speed` | `movePct` | 直接乘算 |
  | `attack_speed` | `aspd` | 直接加算 |
  | `magic_resistance` | `resFlat` | 直接加算 |
  | `block_cnt` | `blockCnt` | 直接加算 |
  | `base_attack_time` | `batFlat` | 直接加算 |
  | `sp_recovery_per_sec` | `spRecoveryFlat` | 直接加算 |
  | `hp_recovery_per_sec` | `hpRegen` | 直接加算 |
  | `ability_range_forward_extend` | `rangeExtend` | 直接加算 |
  | `taunt_level` | `taunt` | 直接加算 |

  另外四种穿透（`def_penetrate`、`def_penetrate_fixed`、`magic_resist_penetrate`、`magic_resist_penetrate_fixed`）也按直接加算。`hp_recovery_per_sec_by_max_hp_ratio` 为正时，生命回复速度（直接加算）+ 技能开始时的最大生命值 × 这个数（如蛇屠箱二技能「每秒恢复最大生命的{hp_recovery_per_sec_by_max_hp_ratio}」）。

  说明里显示时不带百分号的 `atk`、`def`、`max_hp`（占位符写作 `{max_hp}` 而不是 `{max_hp:0%}`，如史尔特尔三技能「生命上限+{max_hp}」）是数值，按直接加算：修饰器换成 `atkFlat`、`defFlat`、`hpFlat`。说明把一个键给了别的单位（技能-11）时，它不是干员自己的属性键。
- **攻击键**：技能发动的攻击中，`atk_scale`（或 `attack@atk_scale`）是攻击力倍率（伤害-6），`times`（或 `attack@times`）是每个目标受到的次数，`max_target`（或 `attack@max_target`）是目标数（索敌-3 取前 n 个）。行为可以给攻击修正加上一种元素和每下的元素损伤（元素-2）。
- **`cost`**：立即技能和持续技能开始时，拥有者立刻获得这么多费用，不超过上限（如香草「获得 6 点部署费用，攻击力 +X%」，持续 10 秒）。

- 来源：不带百分号的数值：[PRTS「史尔特尔」oldid=435132](https://prts.wiki/index.php?title=%E5%8F%B2%E5%B0%94%E7%89%B9%E5%B0%94&oldid=435132) 三技能「生命上限{{+|5000|…}}」（加算模板），数据 `max_hp` 5000、说明 `{max_hp}`；按占位符格式判断为推断 INF-0239；数据：battle/buff_template_data 中官方属性修饰器的类型分布（ATK 388 个中 MULTIPLIER 337 个；ATTACK_SPEED 214 个中 ADDITION 196 个；DEF 以 MULTIPLIER 为主；MAX_HP 以 MULTIPLIER 为主；MAGIC_RESISTANCE、BLOCK_CNT、SP_RECOVERY_PER_SEC、BASE_ATTACK_TIME、ABILITY_RANGE_FORWARD_EXTEND、TAUNT_LEVEL、各种穿透以 ADDITION 为主）；[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)「倍率」：攻击力倍率；键到效果的对应为推断 INF-0035；持续技能的 `cost` 在开始时获得：[PRTS「香草」oldid=435199](https://prts.wiki/index.php?title=%E9%A6%99%E8%8D%89&oldid=435199) 技能 1 描述「获得 6 点部署费用，攻击力 +5%」，持续 10 秒

### 技能-6 行为接口

内容可以按技能 id 提供行为：发动时机，以及开始、每帧、结束和改动攻击修正时做的事；还可以给出这名干员的这个技能另一种类型与持续时间（`timing`：类型、秒数，各自缺省时用技能记录的，技能-1、技能-4），发动时按它计时，运行中按它的类型处理攻击。行为只能通过上下文作用：

- 读取干员、blackboard 和属性；
- 加减 Buff、施加异常状态；
- 造成伤害、元素损伤（元素-2）、治疗；
- 给拥有者费用。

没有行为的技能用通用效果（技能-5）。内容代码不能直接写单位字段，由 lint 检查（ADR 0045）。

行为接口有版本号（`BEHAVIOR_API_VERSION`，现为第 5 版；第 4 版加了特性行为的 `canAttack` 与 `store`，第 5 版加了特性行为的 `skip` 与技能行为的 `range`，职业-6、技能-8）。第 3 版起，结束时做的事还会得到技能结束的原因（同 `skillEnd` 事件：`duration`、`instant`、`ammo`、`stopped`、`move`，钩子-3）。上下文成员：`self`、`bb`、`frame`、`stats`、`addBuff`、`removeBuff`、`applyStatus`、`dealDamage`、`dealEp`、`heal`、`gainCost`，技能的上下文另有 `kind` 和（第 2 版起）`extra`（说明加上的修饰器，技能-9）；行为造成的伤害击杀敌人时算干员的击杀（职业-5）。成员有增减就是新版本，由契约测试检查。

- 来源：设计决定，见 [ADR 0055](../adr/0055-sdk-prepared-now-built-after-mvp.md)、[ADR 0046](../adr/0046-versioned-interfaces.md)；生命回复（skcom_heal_self）「立即恢复最大生命的{heal_scale}」见数据：skill_table

### 技能-7 主动关闭

有些技能运行中可以由玩家关闭（「可关闭」）：

- **哪些技能**：技能说明（skill_table 的 `description`）写了可以随时停止或主动关闭的，即「随时」「主动」「手动」之后、同一句里（不跨过逗号、句号、分号、换行和标签）出现「停止」或「关闭」，例如「打完后结束（可随时停止技能）」「技能持续时间无限，可主动关闭技能」「手动停止或棋子耗尽后技能结束」。持续、弹药、手动、自动的技能都可能是。
- **关闭**：技能运行中，玩家的技能指令（技能-3）关闭它：按技能-4 的结束处理，当帧结束，产生 `skill` 事件（active 为 0），技力从 0 开始重新积累，剩余的持续时间和弹药作废。
- **条件**：关闭是第二次触发，所以干员处于不能发动技能的状态（不能行动、沉默、静默，技能-3）时也不能关闭，指令被忽略。
- 关闭时另有效果的技能（如弹药倾泻）由内容的行为提供（技能-6），不在通用规则里。

- 来源：[PRTS「技能」oldid=420458](https://prts.wiki/index.php?title=%E6%8A%80%E8%83%BD&oldid=420458)：「可关闭（可随时主动关闭）……允许玩家下达"关闭技能"的指令」「此类技能接收到玩家二次触发的指令时，通常会立刻终止当前技能效果（称为主动关闭），也可能产生关闭以外的一些其他的效果」「由于实现上为二次触发，干员处于任何无法触发技能的状态时将同样无法主动关闭技能」；数据：skill_table[].levels[].description；按说明文字识别可关闭的技能为推断 INF-0056

### 技能-8 技能期间的攻击范围

技能运行时，干员的攻击范围（攻击-1）可以改变：

- 技能这一级的说明（去掉富文本标签）写「攻击范围扩大至整个战场」时，攻击范围是整张地图；
- 否则说明写「攻击范围扩大」「攻击范围改变」或「攻击范围缩小」、这一级有范围编号（`rangeId`）时，攻击范围是范围表（干员-8）里的这个范围，随干员朝向转动，攻击距离（`ability_range_forward_extend`）照常加在上面；
- 其余技能不改变攻击范围。
- 内容的技能行为可以给出运行中技能这时的范围（`range`，行为接口第 5 版），代替上面的规则。

改变后的范围用于技能运行期间干员的索敌、按攻击范围的光环与天赋（职业-13、部署-6）和伤害转治疗（职业-11）。

- 来源：数据：skill_table 的 levels[].rangeId 与 description；按说明判断 rangeId 是攻击范围为推断 INF-0100（全部 111 个写攻击范围变化的技能中，101 个带 rangeId，其中「扩大」的 91 个都比干员原范围大，「改变」「缩小」的 10 个更小或形状不同）

### 技能-9 说明里写明的攻击变化与修饰器

技能这一级的说明（去掉富文本标签，按「，」「。」「；」和换行分句——数据里写作 `\n` 两个字符的也是换行——，占位符记作 `{键}`）里，下面这些句子在通用效果（技能-5）之外另起作用；其余句子不读：

| 句子 | 作用 |
|---|---|
| 同时攻击阻挡的所有敌人 | 技能的攻击目标数等于阻挡数（至少 1） |
| （每次攻击）额外攻击一/两/1/2个（名）目标（敌人） | 目标数在原来的（技能或特性给的较大者）之上多这么多个 |
| 攻击变为二/三/2/3连击（连射） | 每个目标受到这么多次（blackboard 已有次数键时不改） |
| 普通攻击造成法术伤害；伤害类型变为法术；（每次）攻击造成相当于攻击力{(attack@)atk_scale}的法术伤害 | 技能的攻击造成法术伤害 |
| （且/并）攻击（会）使目标、（并）使（令）命中（击中）目标 晕眩/停顿{键}秒（键为 stun、sluggish 或加 attack@ 的） | 技能的攻击每一下给目标这么久的晕眩或停顿 |
| （并）获得{prob}的物理（和法术）闪避 | 技能运行时物理（和法术）闪避 + `prob` |
| 阻挡数变为0 | 技能运行时阻挡数最终乘算 ×0 |
| 防御力降至0 | 技能运行时防御力最终乘算 ×0 |
| 技能持续期间内干员的生命值（始终）不会低于1 | 技能运行时持有不死（`undying`，状态-5） |
| （攻击、攻击后、并）（使）（命中）目标失去特殊能力{(attack@)silence}秒 | 技能的攻击每一下给目标这么久的沉默 |

### 技能-10 消耗部署费用的技能

说明的第一句是「消耗{cost}点部署费用…」或「消耗N点部署费用…」的技能（佣兵，如雷狼龙S空爆一技能「消耗20点部署费用」、哈蒂娅二技能「消耗10点部署费用组合剑和杖」）开启时要付费用：

- **数额**：blackboard 的 `cost`，没有时取说明里写的数。这个 `cost` 是代价，不是技能-5 里开启时获得的费用。
- **条件**：除了技能-3 的条件，拥有者的费用还要不少于这个数；不够时技能指令被忽略，自动技能不发动，渲染状态里这个技能是积攒中而不是可以发动（技力已满也是）。
- **支付**：开启时（内容自己的免费开启除外）从拥有者的费用里扣掉。
- 技能期间再付费用的「装备应变」不在这里。

带佣兵 MCN-X 的干员付费用时，每付 1 点，本次技能期间攻击力直接乘算 + 模组自己的数据 `atk`，最多 `max_stack_cnt` 层（Buff `spendAtk`，技能结束时去掉，职业-20）。

### 技能-11 技能给范围内友方的效果与鼓舞

技能说明写「（攻击）范围内所有（其他）友方单位…」的，技能运行期间每帧给干员攻击范围（攻击-1，技能运行时的范围，技能-8）里有格的友方单位（干员和召唤物）：

- **对象**：说明写「其他」时不含干员自己。
- **修饰器**：「…范围内所有友方单位阻挡数-3」：blackboard 的 `block_cnt` 是给它们的阻挡数，直接加算（海蒂一技能 −3、二技能 +1）。
- **鼓舞**：「获得相当于<干员>{键}攻击力（与防御力）的鼓舞效果」「{def}防御力和{max_hp}生命值上限的鼓舞效果」「{max_hp}的最大生命值的鼓舞效果」：每个占位符的值是它后面（到下一个占位符为止）写到的属性的倍率；受益者的这项属性最终加算 + 干员这项属性（不含干员自己受到的鼓舞）× 倍率。同一项属性受到几个鼓舞时，只有倍率最高的生效（倍率相同取先算到的），不看最终数值。吟游者不受鼓舞（职业-13）。

这些键（以及鼓舞那项属性的同名键，如浊心斯卡蒂二技能的 `def`）不是干员自己的属性键：通用效果（技能-5）里它们的修饰器为 0。离开范围、技能结束或干员离场时效果去掉。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 鼓舞「获得额外附加的基础属性加成（同类属性取最高）」「鼓舞提供的属性加成算法为最终加算（非基础属性加成）」「同类效果取倍率最高（非最终数值）生效」；数据：skill_table 空二技能「攻击范围内所有其他友方单位获得相当于空{atk:0%}攻击力的鼓舞效果」，海蒂一、二技能，三角初华一、二技能，浊心斯卡蒂二、三技能，魔王二、三技能；吟游者特性「自身不受鼓舞影响」；读法、每帧按攻击范围更新、干员的属性不含自己受到的鼓舞、阻挡数也给干员自己为推断 INF-0241

### 技能-12 史尔特尔的黄昏

史尔特尔三技能（skchr_surtr_3）在通用效果（技能-5；生命上限 + `max_hp` 是直接加算）之外：

- 开启时立即回复相当于最大生命值的生命；
- 运行期间每 `interval`（0.2）秒生命流失（伤害-10）一次，每秒的流失量从 0 起在 `duration`（60）秒内均匀增加到最大生命值的 `hp_ratio`（20%），之后保持；每次流失这个速度 × `interval`。

### 技能-13 炼金单元

说明写「投掷一个炼金单元，在{projectile_delay_time}秒内使落点…」的技能（炼金师：锡人、旅骨、引星棘刺的一、二技能）开启时投出一个炼金单元，技能本身是立即技能（技能-4），不按攻击键当作下次攻击；自动的、对敌人投掷的要等干员即将攻击（有目标，技能-3）才开启。

- **落点**：对敌人的，落在干员当前第一个目标（索敌-3）所在的格；攻击范围里没有可选的敌人时，落在攻击范围里干员正前方最远的格（都不在时干员自己的格）。对友方的（「向友方单位投掷」），落在攻击范围里生命比例最低的友方单位（干员和召唤物，不含装置职业）所在的格，相同时取最晚部署的；没有时干员自己的格。投出当帧就落地。
- **范围**：以落点格中心为圆心、半径 `projectile_range`（格）的圆，单位的位置在圆里就算在里面；`projectile_range` 为 0、说明写「落点和周围8格」时是落点格和周围 8 格。
- **持续**：`projectile_delay_time` 秒；带引星棘刺的天赋「心相」时，投出时攻击范围里有别的干员（召唤物不算）就再加 `projectile_extend` 秒。到时后消失；干员离场时它留在场上。
- **伤害**：从落地起每 `interval`（没有时 1）秒，范围里的地面敌人受到一次法术伤害 = 投出时干员的攻击力 × `atk_scale`（锡人的天赋「凋敝魂灵」再 × `skill@damage_scale`）；重量（`massLevel`）不小于 `value` 的敌人（「重量大于等于3的敌人」）再加 `heavy_atk_scale` 倍。伤害无来源（伤害-7），到时的那一刻也算一次。
- **敌人的修饰器**：范围里的地面敌人：`atk` 为负时虚弱，攻击力最终乘算 ×(1 + `atk`)；`move_speed` 移动速度直接乘算（写在「重量大于等于…的敌人」之后时只给重型敌人）；`heal_scale` 受到治疗倍率 ×(1 − `heal_scale`)。
- **命中率**：带旅骨的天赋「潜水作业」时，范围里的地面敌人的物理和法术命中率最终乘算 ×(1 + `hitrate`)，重量不小于 `value` 的 ×(1 + `heavy_hitrate`)；几个炼金单元同时作用时取命中率最高（降得最少）的一个。命中率低于 1 的单位造成的物理、法术伤害（可以被闪避的、有来源的）在伤判之前以 1 − 命中率的几率落空（同闪避，伤害-8）。
- **友方的修饰器**：范围里的友方单位：生命回复速度 + `hp_recovery_per_sec_ratio`（或 `hp_recovery_per_sec_ratio_chr`）× 投出时的攻击力；「防御力+{def}」防御力直接加算 + `def`。
- **漂移**：说明写「缓慢沿投掷方向移动且影响范围持续扩大」时，它在 `remaining_time` 秒内以每秒 `projectile_move_speed` 格离开干员所在格的方向移动，半径每秒增大初始半径 × `value`；落点就是干员的格时不动。

每个炼金单元各自起作用（Buff 键 `alchemy:<id>`，几个的效果可以叠加），每帧在光环（职业-13）之前更新。投出时产生 `alchemy` 表现事件（事件第 12 版：位置、半径、持续帧数和漂移）。炼金单元是状态的一部分（同步-1、同步-2），合作的阶段之间清空（合作-8）。

带炼金师 ALC-X 的干员，自己投出的炼金单元在场时技力自然回复速度 + 模组自己的数据 `sp_recovery_per_sec`（职业-18 的 `alchemy`）。

还没有实现的：引星棘刺三技能（向几名干员投掷、围成区域），旅骨未精英化时「潜水作业」的命中率固定为 0 的现象。引星棘刺的天赋「视界」见 部署-5。
