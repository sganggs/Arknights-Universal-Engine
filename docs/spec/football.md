# 阵地足球

促融共竞的阵地足球：场上的足球被干员打动、在场地里滚动和反弹，滚进球门得分。实现见 `packages/sim/src/ball.js`（球的计算）、`packages/sim/src/football.js`（伤害钩子）与 `packages/sim/src/displacement.js`（踢动与滚动写入失衡状态）；球的天赋由内容给出（`packages/content/src/ball.js`）。比赛流程见足球-6～足球-8（`packages/sim/src/football.js`）；球员、球门屏障、守门位与球卡见后续条款。

### 足球-1 球场与球门

阵地足球关的地块里有我方球门 `tile_allygoal` 和敌方球门 `tile_enemygoal`。IG-FT-1 的场地 13×9：第 0、8 行是不可通行的 `tile_forbidden`，第 0 列是我方球门，第 12 列是敌方球门，其余是球场 `tile_football`。球门地块可以通行，不能部署。

- 来源：数据：关卡 `level_act1multi_football` 的 `mapData`（`tile_allygoal`、`tile_enemygoal`、`tile_football`、`tile_forbidden`）；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839) 阵地足球「玩家需和协作者一同防守敌方射球，将足球送入敌方的球门吧！」

### 足球-2 足球

带天赋 `physic` 的敌人是足球。`physic` 的四个值都来自数据：摩擦倍数 `friction_factor`、弹性 `restitution_factor`、踢动所需的累计伤害 `value`、默认推动力度 `force`。天赋 `aura` 只有 `block_cnt` 一项时是足球的阻挡数门槛（足球-4），不是敌能-28 的补给车。

- **身体**：受击判定与物理碰撞箱都是半径 0.3 的圆。
- **不受伤害**：它受到的所有伤害都取消，生命值不变；伤害照常经过伤判（伤害-5），取消发生在扣除生命之前（钩子-3 的 `hpDamage`），并按足球-3 计入踢动。
- **不自己动**：不走路线（束缚），不进行普通攻击，无法被阻挡；只在踢动（足球-3）或被推、拉（位移-2、位移-4）后滚动（足球-4）。
- **异常**：晕眩、寒冷、冻结、沉睡对它不生效；浮空免疫来自数据。

- 来源：[PRTS「RMA70刺球」oldid=436366](https://prts.wiki/index.php?title=RMA70%E5%88%BA%E7%90%83&oldid=436366)「足球类敌人，弹性敌人；受击判定与物理碰撞箱均为半径0.3的圆」「摩擦力0.7倍，弹性0.75，默认推动力度450，累计伤害阈值2300」「晕眩免疫，寒冷免疫，冻结免疫，沉睡免疫，束缚，不进行普通攻击，无法被阻挡，取消自身受到的所有伤害」；数据：enemy_database 的 `physic.friction_factor`、`physic.restitution_factor`、`physic.value`、`physic.force`、`aura.block_cnt`；各种球的数值见 [PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「比赛用球一览」；异常的实现方式为推断 INF-0624

### 足球-3 踢动

球受到来源于我方角色类单位（干员、我方装置）的伤害时，若它既不在失衡中也没有消失：

1. **方向**：球与来源不在同一格时，记来源中心到球心的单位向量；在同一格时记 (1, 0)，即向右。
2. **远近**：来源所在格不是球所在格或它上下左右的 4 格时，这一方向 ×0.2，否则 ×1。
3. **累计**：把这一方向加进累计向量，把这次伤害量加进累计伤害。
4. **踢动**：累计伤害达到 `value` 时，以默认力度沿累计向量的方向（累计向量为 0 时为 (1, 0)）推动它，然后清空累计伤害和累计向量。

推动力度与速度的换算同位移-2：初速度 = 力度 × 0.01 格/秒（质量为 1），RMA70 刺球的 450 即 4.5 格/秒。被推动时球停下原来的运动、以这一速度进入失衡，带位移-3 的 0.1 秒硬直；它离开阻挡它的单位。失衡中受到的伤害、敌方造成的伤害和没有来源的伤害同样取消，但不计入。

- 来源：[PRTS「RMA70刺球」oldid=436366](https://prts.wiki/index.php?title=RMA70%E5%88%BA%E7%90%83&oldid=436366)「受到来源于角色类单位的伤害时，若自身未处于失衡/消失状态，则：①若自身与伤害来源不处于同一地块，则记录伤害来源到自身的单位向量，否则记录伤害来源朝向的单位向量②若伤害来源所在地块不处于自身所在地块及周围4格，则①中所得单位向量×0.2，否则×1.0③将②中所得向量累加入累计向量中，此次受到的伤害量累加入累计伤害中④若此时累计伤害到达阈值，则以默认力度向累计向量方向（若累计向量为0则变为(1,0)）推动自身，随后清空累计伤害与累计向量」；[PRTS「推与拉」oldid=434089](https://prts.wiki/index.php?title=%E6%8E%A8%E4%B8%8E%E6%8B%89&oldid=434089)「实际受力大小为列表值×0.01」；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「踢动的方向取决于干员中心点向足球方向的直线」「距离足球过远的干员，其对方向的影响会削弱至五分之一」「与足球处于相同格而对其造成伤害时，会固定尝试将其向右推动」；同格的方向、力度的换算与硬直为推断 INF-0619

### 足球-4 滚动

踢动或推、拉后的球按位移-3 进入失衡、每帧滚动，但：

- **摩擦**：减速度 a 是位移-3 的 μg 乘以球的摩擦倍数（RMA70 刺球 0.5 × 9.81 × 0.7）。球每帧按匀减速走精确的位移：速度为 v 时这一帧走 v·Δt − a·Δt²/2（这一帧内停下时走 v²/2a），速度减去 a·Δt。所以从静止被踢出的球共走 v²/2a（RMA70 刺球被干员踢出约 2.95 格）。
- **反弹**：先沿 x、再沿 y 移动；移动会使球的圆与不可通行的地块（地面单位不能进入的格子，地图之外也算）重叠时，这一轴这一帧不移动，这一轴的速度反向并乘以弹性；另一轴的速度不变。
- **撞到单位**：滚动的球只和有方形碰撞箱的单位（阵地屏障，足球-12）相撞。干员和其他装置不挡球、也不受伤，球从它们身上滚过（能阻挡的我方干员按下面的停球停下它）。
- **停球**：滚动期间，球心 0.35 格以内有能阻挡（阻挡-1）、剩余阻挡数（阻挡数减去已阻挡的敌人的阻挡占用）不小于 `aura.block_cnt` 的我方干员时，球立刻停下（速度清零，失衡结束）。
- **结束**：其余与位移-3 相同：速度不超过 0.1 且硬直已过时停下。

- 来源：[PRTS「RMA70刺球」oldid=436366](https://prts.wiki/index.php?title=RMA70%E5%88%BA%E7%90%83&oldid=436366)「摩擦力0.7倍，弹性0.75」「失衡移动期间，与角色类单位产生物理碰撞时，对目标造成自身当前移动速度*自身攻击力的真实伤害」「半径0.35范围内存在阻挡数不小于3的我方单位时，自身立刻强制停止移动」；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「只能被剩余阻挡数不小于3的单位阻挡」；反弹的算法为推断 INF-0620，撞到单位为推断 INF-0621，停球为推断 INF-0622；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839) 参赛球队一览：球德联「射球具有撞击伤害」；[PRTS「IG-TR-2 规则教学-阵地足球」oldid=430161](https://prts.wiki/index.php?oldid=430161) 关卡内剧情：第一波玫兰莎（4,5）与红云（3,7）两次踢动后「足球即将进入红色目标点」「进球！」，第二波「守门员接球」；精确位移为推断 INF-0658

### 足球-5 进球

滚动中的球的球心进入球门地块时进球：进入我方球门是对方进球，进入敌方球门是我方进球。产生表现事件 `score`（事件第 14 版，`id` 为球，`goal` 0 为我方球门、1 为敌方球门）。球随即离场：不算击倒，不扣生命。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839) 阵地足球「将足球送入敌方的球门吧！」「注意防守敌方球员的进攻，在规定的时间内尽可能射门吧！」；以球心进门为准、离场方式为推断 INF-0623；第一季录像（哔哩哔哩 BV173JM6iErM P19 约 141.2 秒）一球以约 6.6 格/秒进敌方球门，进球后停在原处显示的球心约在 11.46 格（门线 11.5）：按「球的圆碰到球门格」它应在 11.2 处就判进

### 足球-6 赛制与开球

阵地足球关的设置来自合作战斗表与关卡（内容整理成关卡的 `football`）：比赛时长（关卡选项 `maxPlayTime`，IG-FT-1 为 300 秒）、开球后球员的等待（`footballPlayersWaitTimeOnWaveStart`，3 秒）、领先球数到开球等级的对照（`footballAheadGoalCntFactor`）、每个开球等级下各波次标签的权重（`footballLevelOfWaveFactor`）、球队与球员（`footballTeamWeights`、`footballTeamPlayers`、`footballPlayersName`）。

- **球队**：战斗开始时在权重大于 0 的球队里按权重抽一支（随机-2），整场不变。可抽的是阵地队（标准）、战术队、爱球会、球德联四支；IG-S-4 不抽阵地队（权重当作 0）。
- **球员**：波次里的标准队球员（名字中带 `mumssi` 的击球手、`mubufn` 的守门员、`mugnfu` 的击人手）出场时换成本场球队同一角色的球员。难度把标准队球员换成了精英（关卡-2 的 `level_enemy_replace`，名字加 `_2`，如 IG-FT-2 与 IG-S-4）时，换上的是本场球队同一角色的精英球员：该队球员加 `_2`、关卡的敌人引用里有的那名（如战术队精英击球手 enemy_4022_mushtm_2）。组装关卡时保留可抽到的球队在这个难度会出场的全部球员（关卡-2 的出场敌人）。
- **开球**：每个波次是一种开球布局，带标签 `advancedWaveTag`（0～9）；只有数字才是标签，别的关卡在这一栏写的文字（`stage`、`bosswave` 等）不读。开新一波时，取我方领先球数（落后按 0 算）所达到的表中最后一项的开球等级；按这一等级的权重抽一个标签（随机-2）；再在带这个标签的波次中等概率抽一个（随机-1），开始这一波。波次照常出怪和激活预部署单位（波次-1、波次-6），波次里的随机组照常抽取（波次-5）。有开球标签的关卡波次没有最后一波。
- **教学关**：没有一个波次带开球标签的关卡（IG-TR-2 规则教学）不抽球队，上场的是阵地队（标准队，波次里的球员不换）；按波次的顺序开球：第一波开场，每次进球后开下一波；最后一波之后进球，波次全部完成，战斗按结束-1 胜利。比赛时长照常。
- **等待**：一次开球出场的球员，在开球（这一波开始的那一帧）后的等待时间内不移动、不攻击、不使用能力（Buff `kickoff`）；从开球帧 + 等待时间那一帧起行动。球和其他敌人不等待。
- **状态**：阵地足球的进度（本场球队、双方进球、当前开球的帧、比赛结束的帧）是状态的一部分，进入快照和状态哈希。

- 来源：数据：cooperate_battle_table 的 `footballAheadGoalCntFactor`、`footballLevelOfWaveFactor`、`footballTeamWeights`、`footballTeamPlayers`、`footballPlayersName`、`footballPlayersWaitTimeOnWaveStart`；关卡 `level_act1multi_football` 的 `options.maxPlayTime`、波次的 `advancedWaveTag`；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「参赛的敌方球员组成了不同的球队，每次比赛都会随机登场其中一支队伍作为本次的对手」与参赛对手一览；[PRTS「阵地足球锦标」oldid=434049](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E8%B6%B3%E7%90%83%E9%94%A6%E6%A0%87&oldid=434049) 参赛球队一览（直球队、门神会、魔球帮标为新增）；[PRTS「IG-FT-2 大力出奇迹」oldid=428765](https://prts.wiki/index.php?title=IG-FT-2%20%E5%A4%A7%E5%8A%9B%E5%87%BA%E5%A5%87%E8%BF%B9&oldid=428765) 情报「[[“脚脚生风”阵地击球手]]，[[“头头是门”阵地守门员]]，[[“锤锤到肉”阵地击人手]]可能替换为战术队/爱球会/球德联系列的对应精英敌人组，于本场比赛中不再改变」；[PRTS「IG-S-4 大力出奇迹」oldid=428766](https://prts.wiki/index.php?title=IG-S-4%20%E5%A4%A7%E5%8A%9B%E5%87%BA%E5%A5%87%E8%BF%B9&oldid=428766) 情报「将会遭遇下列球员之一：战术队/爱球会/球德联精英球员」；数据：两关的 `enemyDbRefs` 列着四支球队的 `_2`；第一季录像（哔哩哔哩 BV173JM6iErM，2025.4 促融共竞#1 阵地足球）的四场 IG-FT-2 里出现「爱球会荣誉守门员」「战术队精英守门员」「“头头是门”阵地守门员」「球德联老牌守门员」，一场 IG-S-4 里出现「爱球会荣誉守门员」；四支球队、开球等级的取法与等概率抽波次为推断 INF-0625，等待的对象与起止为推断 INF-0626，精英球员的取法为推断 INF-0648，IG-S-4 不抽阵地队为推断 INF-0649；教学关：数据：关卡 `level_act1multi_tr02` 的三个波次都没有 `advancedWaveTag`，波次只出阵地队的击球手与守门员；[PRTS「IG-TR-2 规则教学-阵地足球」oldid=430161](https://prts.wiki/index.php?oldid=430161) 关卡内剧情按波次依次讲进攻（第一波，以「进球！」结束）、防守（第二波：「<阵地击球手>出现」「守门员接球」——这一波我方球门的每一行都有屏障或守门位）与自由比赛（第三波，「剩下的时间，就交给您了」）；不抽球队、按顺序开球与最后一波后的结束为推断 INF-0656

### 足球-7 进球与结束

- **得分**：进球（足球-5）时，进入敌方球门是我方得分，进入我方球门是对方得分。每球 1 分；至纯源石球 3 分（内容在它的 `physic` 上加 `score` 3）。
- **清场**：有进球的那一帧末尾，球离场；场上所有敌人安静离场（不算击倒，不扣生命）；生效中的预部署单位全部离场；我方所有干员撤退（撤退-1），进入再部署。下一帧这一波没有敌人了，下一次开球开始（足球-6）。
- **结束**：比赛时长到时，战斗以胜利结束（结束-1），产生事件 `end`。嘉奖印章按净胜球（我方进球减对方进球）达到任务「争取 N 个净胜球」的个数计，IG-FT-1 为 1、2、4。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「每次射门后所有干员都会撤退并进入再部署时间」「比赛时间结束后将计算净胜球数量」「每次射门后开球时，我方和敌方球门前方都会随机部署一些阻止足球进入的“阵地屏障”」；[PRTS「至纯源石球」oldid=437059](https://prts.wiki/index.php?title=%E8%87%B3%E7%BA%AF%E6%BA%90%E7%9F%B3%E7%90%83&oldid=437059)「进球时获得3倍得分」；数据：activity_table 的 MULTIPLAY_V3 任务「争取1个净胜球」「争取2个净胜球」「争取4个净胜球」；清场的范围、撤退按普通撤退、结束算胜利为推断 INF-0627

### 足球-8 场地加成

阵地足球中干员撤退或倒下后，再部署惩罚（部署-3）不增加。IG-FT-1 的关卡符文（关卡-2）另给所有干员：技能所需技力 ×0.8（`char_skill_cd_mul`，符文-2），技力自然回复速度 ×1（`sp_recovery_reduction` 的 `sp_recovery_per_sec` 为 1，符文-3）。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「所有球员再部署时不再增加部署费用消耗」「所有球员的技力需求-20%（特级赛没有这个效果），技力自然回复速度翻倍」；数据：关卡 `level_act1multi_football` 的符文；页面写技力自然回复速度翻倍，数据里对应的符文是 ×1，按数据，见推断 INF-0632

### 足球-9 球员

带天赋 `football`（击球手、守门员）或 `searchtarget`（击人手）的敌人是球员。

- **自主移动**：不在开球等待（足球-6）、不在重生、没被阻挡、不在攻击中、能移动时，球员有目标就朝目标直线移动（速度同路线-1，走到它能站的格子上），这一帧不再走路线；没有目标时照常走路线（巡逻，路线-3）。
- **追球**：击球手和守门员的目标是 `searchBall` 的 `range_radius` 以内最近的、没有被别的球员持有的球（足球-10）。守门员只去列号不小于它的 `football` 的 `tile_col_end` 的球。
- **重生**：`Reborn` 只有 `duration` 时，球员每次被击倒都按敌能-18 重生：清除 Buff，生命回到最大值，`duration` 秒内无敌、不可选中、不可阻挡、不行动；次数不限。`Reborn` 带 `hp_ratio` 时仍是敌能-18 的一次重生。

- 来源：[PRTS「阵地击球手」oldid=437052](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E5%87%BB%E7%90%83%E6%89%8B&oldid=437052)「球员类敌人；持续追踪半径2.0范围内的足球类敌人进行移动」「被击倒时进行持续20s的重生，恢复100%生命值（无次数限制）」；[PRTS「阵地守门员」oldid=437054](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E5%AE%88%E9%97%A8%E5%91%98&oldid=437054)「持续追踪半径2.0范围内的足球类敌人进行移动」；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「只要把他们往死里打进入'''喘息状态'''，就是我们的时间啦！」；数据：enemy_database 的 `searchBall.range_radius`、`football.tile_col_end`、`Reborn.duration`；自主移动的条件、直线移动与守门员的区域为推断 INF-0628，重生的状态为推断 INF-0630

### 足球-10 射门、传球与发球

- **触球**：自主移动时，若有没被别的球员持有的球在触球距离内（击球手 0.2，守门员为它的 `football` 的 `defence`），球员停下这个球并持有它，开始踢球（强制触发，不看技能冷却）：
  - 击球手：自己是离我方球门最近的球员，或场上没有别的球员时射门；否则以 1/(场上球员数 + 1) 的概率射门（随机-1），不然传球。
  - 守门员：发球。
- **方向**：射门朝我方球门随机一格（随机-1）的中心；传球朝离我方球门最近的另一名球员；发球朝场地中间一列（第 ⌊敌方球门列 ÷ 2⌋ 列，IG-FT-1 为第 6 列）随机一行（球门所在的各行，随机-1）的格子中心。到球门的距离取到球门各格中心的最近距离，相同时取先出场的。
- **时机**：起脚在技能动画的命中时刻：击球手的传球用 Skill1、射门用 Skill2，守门员的发球用 Attack，各取动画的 OnAttack 事件（内容的 `KICK_TIMES`）。到时球若仍在触球距离内，球员先停下它，再以默认力度 × 倍率（传球 `passing_force`、射门 `slapshot_force`、发球 `clearance_force`）沿方向推动（足球-3 的换算），球不再被持有。从触球到动画结束，球员站在原地，不走路线。
- **持有**：被持有的球别的球员不能去追、不能触球；持有到起脚为止。

- 来源：[PRTS「阵地击球手」oldid=437052](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E5%87%BB%E7%90%83%E6%89%8B&oldid=437052)「处于自主移动状态时，若半径0.2范围内存在未被选择的足球类敌人，则停止此足球的移动，随后：①：若自身为距离我方球门最近的球员类敌人，或场上不存在其他球员类敌人，则强制触发技能【射门】②：不满足①时，则有1/(场上球员类敌人总数+1)的概率强制触发技能【射门】，否则强制触发技能【传球】」，射门「若足球仍处于半径0.2范围内，则停止其移动，随后以足球默认力度的1.5倍，将足球以自身到随机一个我方球门的方向推动」「※技能期间选取此足球」，传球「以足球默认力度的1.2倍，将足球以自身到距离球门最近的球员类敌人的方向推动」；[PRTS「阵地守门员」oldid=437054](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E5%AE%88%E9%97%A8%E5%91%98&oldid=437054)「若半径0.5范围内存在未被选择的足球类敌人，则停止此足球的移动，随后强制触发技能【发球】」「以足球默认力度的1.5倍，将足球以自身到场地中央列随机行的方向推动」；数据：enemy_database 的 `football.passing_force`、`football.slapshot_force`、`football.clearance_force`、`football.defence`；各球员模型（PRTS 资源站 `assets/enemy_spine/<敌人>/`）的 Skill1、Skill2、Attack 动画与 OnAttack 事件；距离、目标点与时机的取法为推断 INF-0629

### 足球-12 阵地屏障

阵地屏障（trap_154_mugtps）是敌方装置（装置-3，嘲讽等级取记录的 −1），每次开球由波次的 `ACTIVATE` 放到球门前（装置-1），进球后清场时离场（足球-7）：

- **免疫**：晕眩、沉默、寒冷、冻结、沉睡。
- **阻挡路线**：在场时所在格是类障碍物地块（寻路-1）；球员自主移动不进入这格（足球-9）。
- **方形碰撞箱**：以所在格中心为中心、边长 0.9 的正方形。滚动的球的圆进入这个正方形时，按撞墙处理（足球-4：这一轴这一帧不移动，速度反向并乘以弹性），并且屏障受到「球这一帧的平均速度（格/秒，足球-4，反弹之前）× 球的攻击力 × 记录的 `damage_scale`（5）」的真实伤害；同一个屏障在持续接触期间只受一次。
- **环境伤害**：没有来源的伤害对它为 0。

- 来源：[PRTS「阵地屏障」oldid=417821](https://prts.wiki/index.php?title=%E9%98%B5%E5%9C%B0%E5%B1%8F%E9%9A%9C&oldid=417821)「阵营=敌方」「持有晕眩免疫，沉默免疫，寒冷免疫，冻结免疫，沉睡免疫」「重写所在地块可以<阻挡路线>」「受击判定区域与物理碰撞箱均为边长0.9的正方形」「受到的环境伤害降低至0%」「受到来自足球类敌人的伤害提升至500%」；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「屏障可以被我方单位打掉，也可以用足球弹掉（参见足球的'''攻击力'''）」；数据：character_table trap_154_mugtps 隐藏天赋 `damage_scale` 5；关卡 `level_act1multi_football` 的预部署单位与波次的 `ACTIVATE`；反弹与撞击的取法、环境伤害按没有来源的伤害为推断 INF-0633；伤害的速度单位：第一季录像（BV173JM6iErM P16 约 540.0 秒）压缩建材球（攻击力 12000）以约 5.3 格/秒撞上屏障，屏障上显示 63786（= 5.3155 × 12000），一下即倒（录像里没有体现 ×5，当前数据有）

### 足球-13 守门位

`aura` 的 blackboard 为 `block_cnt`、`sp`、`value` 三项的敌人是守门位（数据：守门位 enemy_4021_muredy），由波次刷在我方球门前：

- **它自己**：无敌、不可选中、不可阻挡、束缚（不移动）、不攻击，浮空免疫。
- **守门员**：守门位所在格上的我方单位（干员与我方装置，不论是否可选中、是否迷彩）是守门员：阻挡数加 `block_cnt`（直接加算），离开这格或守门位离场后失去。

### 足球-14 接球与重新发球

- **接球**：滚动的球被守门员（足球-13）停下（足球-4）时，球被接住：它离开场地（隐藏在原处，不再滚动，不被选中，球员不再追它），守门员所在的座位持有它，记下接住的格子；关卡自己的预置干员（波次-7，如 IG-TR-2 的守门员）接住的，归第一个座位（训练场里的玩家）。
- **球卡**：关卡自带的装置卡足球（trap_165_muftbl，关卡-7）是每个座位的一张卡：近战位，不占部署位，部署费用取记录的（3）。座位持有球时可以部署它，只能部署到我方半场——数据里标了 `landball` 的格子（IG-FT-1 为第 1～6 列）——且格上没有干员。部署时不放下单位：座位持有的第一个球回到这格的中心，静止。
- **时限**：接住后 5 秒（150 帧）内没有部署的，第 150 帧末球回到接住它的格子的中心，静止。
- 进球后清场（足球-7）时，持有的球一并离场，不再回来。

### 足球-15 球队特性

各球队的球员在 足球-9…足球-11 之外：

- **战术队击球手**：射门和传球都瞄准我方球门中「开放」的一格的中心（随机-1）：这格前方（朝场地中间的相邻一格）没有阻挡路线的装置（阵地屏障），也不是站着守门员的守门位（足球-13）；没有开放的格时瞄准球门任意一格。
- **战术队守门员**：发球瞄准我方球门中、从它到这格中心的直线上球不会碰到我方单位（干员与我方装置，按球的半径加碰撞半径）和阵地屏障（方形碰撞箱加球的半径）的一格（随机-1）；没有时按 足球-10 发向中间列。
- **战术队击人手**（`passiveMarkTarget`）：不在冷却时，若上一帧或这一帧有我方干员对其他球员造成伤害，它标记那名干员（取最先记下的一次）：`duration` 秒内移动速度 + `move_speed`（直接加算），自主移动时追向它（不论距离）；同时开始 `cooldown` 秒的冷却。
- **爱球会击球手**：射门换成带球（技能 `slapshot` 带 `up_duration` 时）：触球后 `duration` 秒起，`up_duration` 秒内带球——占用阻挡数 + `block_volume`、移动速度 + `move_speed`（直接加算，Buff `dribble`），自主移动时朝我方球门最近的一格走，球每帧在它的中心；开始前原地持球。球被踢走（进入失衡）或不在触球距离内时提前结束。带着的球心进入球门地块时进球（足球-5）。
- **爱球会守门员**：发球瞄准离我方球门最近的击球手（足球-10 的距离）；场上没有击球手时按 足球-10。
- **爱球会击人手**（有 `football`、没有射门、传球、发球技能的球员）：自主移动时追向离它最近的球附近、`searchBall` 半径以内的我方单位中阻挡数大于 0、离那个球最近的一个。
- **球德联击球手**：射门（技能 `slapshot` 带 `ball_damage` 时）踢出的球在 `aoe_duration` 秒内每 `damage_duration` 秒（从踢出后第一个间隔起）对与它接触的我方单位（足球-4 的接触）造成 `ball_damage` 物理伤害，来源是球。
- **球德联守门员**（`rage`）：生命不高于最大值的 `hp_ratio` 时被激怒：`rage_duration` 秒内攻击力 + `atk`、防御力 + `def`（直接乘算，Buff `rage`），期间自主移动时追向离它最近的我方干员（不论距离），不追球。生命回到最大值（重生）前不再被激怒。
- 球德联击人手、阵地队与上述以外的技能没有另外的规则。

### 足球-16 特殊的球

几种球在 足球-2…足球-5 之外：

- **起滚**：球「开始滚动」指它在这一回合开始时处于失衡、上一回合没有（被踢动、推动、发球都算）。
- **高能源石球**（`boom` 带 `max_value` 的计数）：计数从 `max_value`（10）开始；每次开始滚动，计数加上 [`add_value_min`, `add_value_max`) 中的一个随机数（随机-1，−6～−2）；计数不高于 0 时，`duration`（1.5）秒后在球当时的位置爆炸：半径 `range_radius`（1.5）以内的所有单位（敌我双方，包括空中）受到 `damage`（1500）点真实伤害与 `stun`（3）秒晕眩（敌能-3 的爆炸，`all`），来源是球；随后计数回到 `max_value`。等待爆炸期间计数照常变化，不再另外排一次。
- **漏气甲虫球**（`airleakage`）、**膨胀甲虫球**（`airinflation`）：每次开始滚动，踢动阈值（足球-3）加 `value`（−2200 / +150），不低于 0，最多 `kick_times`（3 / 25）次。
- **北境意志球**、**底海滑动球**：滚动中进入球场地块（`tile_football`）时，给这格铺上冰面（摩擦力 −0.3）或黏液（+0.3），覆盖原有的冰面或黏液。球在铺了冰面或黏液的格上，摩擦倍数（足球-4）加上这个值，不低于 0。进球清场（足球-7）时冰面与黏液消失。铺设的状态是阵地足球进度的一部分。

### 足球-17 领先时的追赶

关卡的全局 Buff `cooperate_enemy_catch_up` 给出每领先一球球员增加的最大生命值、攻击力与移动速度的比例（IG-S-4 为 0.2、0.15、0.01；IG-FT-1 都是 0，不起作用）。本场球队的球员（含精英，足球-6）出场时，若我方领先 L 球（我方进球减对方进球，不足 0 不算），它的基础最大生命值、攻击力、移动速度分别乘以 1 + 比例 × L，满血出场。改的是基础值，重生（足球-9）后仍在。球和其他敌人不受影响。`attack_speed` 不为 0 时还不支持（提取时拒绝）。
