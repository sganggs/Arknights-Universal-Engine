# Buff 与异常状态

Buff 是纯数据（ADR 0054）。实现见 `packages/sim/src/buffs.js` 和 `packages/sim/src/status.js`。

### 状态-1 Buff

单位的 Buff 按获取顺序排列。每个 Buff 有：

- 键、来源单位；
- 同名规则（状态-2）、强度；
- 修饰器（属性-2）、标记；
- 层数和层数上限；
- 剩余帧数（−1 表示无限）；
- 触发间隔（帧）及其进度，触发是否固定（状态-4）；
- 是否可抵抗、自身的衰减倍率（状态-3）；
- 事件优先级、屏障量、护盾层数、吸收的伤害类型（伤害-8）；
- 行为键（空即它自己的键）。

Buff 的行为（触发时、到期时做什么）按行为键查找，不存在 Buff 里：一般就是 Buff 的键；键名各异而行为相同的一类 Buff（如兼容层转换的带回调的增益，兼容-4）写同一个行为键。移除不是到期，不执行到期行为。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：Buff 结算「按照其在buffContainer中的顺序」（通常即获取顺序）；[PRTS「伤判效果」oldid=439572](https://prts.wiki/index.php?title=%E4%BC%A4%E5%88%A4%E6%95%88%E6%9E%9C&oldid=439572)：「事件优先级＞获取顺序」

### 状态-2 同名 Buff

同一个键的 Buff 怎样共存，由它的同名规则决定：

| 规则 | 列表里 | 生效的 |
|---|---|---|
| 排队（默认） | 都保留 | 最早获取、仍然存在的那条；后来的在列表里等待，时间照常流逝 |
| 效果取最高 | 都保留 | 强度（数值的绝对值）最大的那条；一样强时取较早的 |
| 叠层 | 合并成一条：层数相加，不超过上限；剩余时间换成新的 | 这一条 |
| 延长时间 | 合并成一条：剩余时间取两者中较长的（无限最长） | 这一条 |
| 独立 | 都保留，超过层数上限时移除最早的那条 | 每一条 |

叠层和延长时间合并时，修饰器和标记换成新的。

内容可以设一个 Buff 的层数（至少 1，至多它的最大层数），持有者的生命按比例跟随最大生命（属性-4）。

- 来源：[PRTS「常见同名状态」oldid=417450](https://prts.wiki/index.php?title=%E5%B8%B8%E8%A7%81%E5%90%8C%E5%90%8D%E7%8A%B6%E6%80%81&oldid=417450)：默认叠加方式「新BUFF以一种无效果无法被检测的状态存在于BUFF列表中，当所有比它更早或优先级的BUFF结束时才正常生效」，「额外的叠加规则」一列有「效果取最高」「延长时间」；等待时时间照常流逝为推断 INF-0016；叠层、延长时间的细节为推断 INF-0017

### 状态-3 持续时间与衰减率

每一帧，每个有限时长的 Buff 的剩余帧数减去它这一帧的衰减率；减到 0 或以下时到期：先离开列表，再执行到期行为。

- 衰减率 = 自身的衰减倍率，可抵抗状态再除以持有者的一减状态抵抗率（属性-3，下限 0.001，所以衰减率最大 1000）。
- 抵抗率按这一帧开始时持有者的属性算；中途获得或失去抵抗，从那一帧起生效。
- 浮空、缚地：施加时目标的重量大于 3，自身衰减倍率为 2，即持续时间减半；按施加时的重量决定。
- 剩余帧数可以是小数。

- 来源：[PRTS「Buff的持续时间衰减率」oldid=429893](https://prts.wiki/index.php?title=Buff%E7%9A%84%E6%8C%81%E7%BB%AD%E6%97%B6%E9%97%B4%E8%A1%B0%E5%87%8F%E7%8E%87&oldid=429893)：每帧按当时的衰减率扣除，综合抵抗衰减率为抵抗倍率之积的倒数、计算下限 0.001；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 浮空、缚地：「对重量大于3的单位持续时间减半」「效果持续时间取决于触发效果时敌人的重量」

### 状态-4 周期触发

有触发间隔 k 帧的 Buff，每帧把进度加上它的衰减率（固定触发的加 1），进度达到 k 时触发一次并减去 k，可以连续触发。第一次触发在获得后满一个间隔时。

- 来源：[PRTS「Buff的持续时间衰减率」oldid=429893](https://prts.wiki/index.php?title=Buff%E7%9A%84%E6%8C%81%E7%BB%AD%E6%97%B6%E9%97%B4%E8%A1%B0%E5%87%8F%E7%8E%87&oldid=429893)：2 倍衰减时「每1秒」触发的效果变为每 0.5 秒，「固定」的触发间隔不受衰减影响

### 状态-5 异常状态目录

战斗中（攻击带的状态、元素爆发、天赋与技能、敌人能力）施加状态之前先发 `beforeStatus` 事件（钩子-3），处理函数可以取消，或改它的帧数、数值。起飞的单位不受行动方式为地面的敌人或未浮空的敌对装置施加的状态，这一拒绝在 `beforeStatus` 之前（阻挡-2）；没有来源的、空中敌人的、同阵营的照常施加。

| 键 | 名称 | 效果 | 可抵抗 | 同名规则 |
|---|---|---|---|---|
| `stun` | 晕眩 | 无法移动、阻挡、攻击及使用技能 | 是 | 排队 |
| `cold` / `enemyCold` | 友方寒冷 / 敌方寒冷 | 攻击速度 −30（直接加算）；叠成冻结见 状态-6 | 是 | 状态-6 |
| `freeze` / `enemyFreeze` | 友方冻结 / 敌方冻结 | 无法移动、攻击及使用技能；友方冻结另有法术抗性 −15（直接加算） | 是 | 排队 |
| `sleep` | 沉睡 | 无敌且无法行动 | 否 | 排队 |
| `root` | 束缚 | 无法移动 | 否 | 排队 |
| `sluggish` | 停顿 | 移动速度 ×0.2（最终乘算） | 否 | 排队 |
| `fragile` | 脆弱 | 受到的物理、法术、真实伤害 ×(1 + v)（伤判，伤害-8） | 否 | 效果取最高 |
| `artsFragile` | 法术脆弱 | 受到的法术伤害 ×(1 + v)（伤判） | 否 | 效果取最高 |
| `elemFragile` | 元素脆弱 | 受到的元素伤害 ×(1 + v)（伤判） | 否 | 效果取最高 |
| `weaken` | 虚弱 | 攻击力 ×(1 − v)（最终乘算） | 否 | 效果取最高 |
| `buffres` | 抵抗 | 一减状态抵抗率 ×(1 − v)（最终乘算），v 默认 0.5 | 否 | 效果取最高 |
| `levitate` | 浮空 | 变为空中单位，无法移动、攻击及使用技能；不对空中单位生效 | 否 | 排队 |

| `fear` | 恐惧 | 无法被阻挡并四散逃跑（状态-10）；不对角色类单位生效 | 是 | 排队 |
| `attract` | 诱导 | 无法被阻挡并向目标位置移动（状态-11） | 是 | 独立 |
| `palsy` | 麻痹 | 层数上限 3，未消耗时持续时间无限；打断敌人的攻击、在抵抗下流失（状态-8） | 是 | 叠层 |
| `palsyShake` | 麻痹震颤 | 无法移动、攻击及使用技能（状态-8） | 否 | 排队 |
| `disarmedCombat` | 战栗 | 敌人被阻挡时不能开始普通攻击；正在进行的攻击照常 | 否 | 排队 |
| `invincible` | 无敌 | 受到的伤害变为 0（伤害-7） | 否 | 排队 |
| `undying` | 不死 | 生命不会降到 1 以下（伤害-9） | 否 | 排队 |
| `healFree` | 禁疗 | 受到的治疗量变为 0（伤害-11） | 否 | 排队 |
| `silence` | 沉默 | 无法使用可沉默的技能与能力（技能-3） | 否 | 排队 |
| `mute` | 静默 | 无法使用技能与能力，但不算沉默（状态-9） | 否 | 排队 |
| `noSp` | 阻回 | 不回复技力（状态-9） | 否 | 排队 |
| `elementFree` | 元素免疫 | 元素值不会损失（元素-2） | 否 | 排队 |
| `dying` | 重伤 | 移动速度 ×0.2（最终乘算），无法被阻挡，禁疗；结束时死去（无来源），被击杀时击杀者获得它的值那么多技力（职业-34） | 否 | 排队 |

脆弱、法术脆弱、元素脆弱、虚弱必须给出强度 v。没有给出持续时间的状态没有结束时间。

由标记得出的状态：

- **无法攻击及使用技能**：晕眩、冻结、沉睡、浮空、麻痹震颤；
- **无法移动**：以上五种，加上束缚、缚地；
- **空中单位**：浮空时是，缚地时不是，否则按单位的行动方式；
- **无敌**：无敌、沉睡；沉睡的无敌挡不住标明穿透沉睡的伤害（伤害-7：使敌人沉睡、再对其造成伤害的技能，如死芒「令…敌人陷入沉睡，每0.5秒对目标造成…法术伤害」）。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)（晕眩、寒冷、冻结、沉睡、束缚、停顿、脆弱、法术脆弱、元素脆弱、虚弱、抵抗、浮空、缚地、恐惧、麻痹）；[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606)（无敌：「受到的伤害与元素值变为0」；禁疗：「受到的治疗量变为0」；沉默；战栗 DISARMED_COMBAT：「若状态机处于COMBAT则无法触发普通攻击」「打断当前正在进行的普通攻击的效果为相关Buff操控，非异常效果战栗本身的效果」「战栗虽然能在实质上阻止敌方单位在阻挡状态下发动攻击」，抗性键 disarmedCombatImmune；战栗不在可抵抗状态之列；COMBAT 状态即敌人被阻挡、只作用于敌人为推断 INF-0141）；[PRTS「可抵抗状态」oldid=429763](https://prts.wiki/index.php?title=%E5%8F%AF%E6%8A%B5%E6%8A%97%E7%8A%B6%E6%80%81&oldid=429763)（晕眩、寒冷、冻结、恐惧、诱导、麻痹）；[PRTS「常见同名状态」oldid=417450](https://prts.wiki/index.php?title=%E5%B8%B8%E8%A7%81%E5%90%8C%E5%90%8D%E7%8A%B6%E6%80%81&oldid=417450)（效果取最高）

### 状态-6 寒冷叠成冻结

- **友方寒冷**（干员与我方召唤物施加）：目标已有友方寒冷时，两条寒冷两两一对变为友方冻结，持续时间取两者剩余时间中较长的；原来那条寒冷移除。
- **敌方寒冷**（敌人施加）：目标已有敌方寒冷或敌方冻结时，新施加的敌方寒冷变为敌方冻结，持续时间为新寒冷的持续时间；原有的寒冷保留。
- 两类寒冷、冻结互不干预。冻结免疫的单位，寒冷不会变为冻结。
- 敌人施加 `cold` 或 `freeze` 时，按敌方寒冷、敌方冻结处理。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 寒冷：「对已具有敌方寒冷或敌方冻结的敌人施加的敌方寒冷会变为敌方冻结」「友方寒冷始终需要两两一对产生友方冻结，持续时间取双方之中最高」「具有冻结免疫的单位身上的任何寒冷都不会尝试变为冻结」；敌方冻结的持续时间、原有寒冷是否保留为推断 INF-0018

### 状态-7 免疫与施加条件

- **免疫**：单位对某个标记免疫时，带这个标记的 Buff 仍在列表里，但这个标记不生效；免疫结束后重新生效。免疫由单位数据给出，或由生效的 Buff 的标记 `immune:<标记名>` 给出（如 职业-10 的阻挡时免疫）。停顿没有自己的标记：持有 `immune:sluggish` 时停顿施加不上，不添加 Buff（敌能-47）。
- **不生效的施加**：浮空不对空中单位生效，缚地不对地面单位生效，恐惧不对角色类单位生效；这时不添加 Buff。持续时间为 0 帧的状态也不添加。

- 来源：[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606)：免疫令对应的异常效果「无法生效，无法被检测」，不移除带有它的 Buff；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)：浮空「触发效果时不会对空中单位生效」，缚地「触发效果时不会对地面单位生效」，恐惧「效果无法对角色类单位生效」

### 状态-8 麻痹

- **打断**：敌人的攻击（攻击-2）在命中那一帧、或开始后 2 秒（60 帧）还没命中时，如果它的麻痹生效（不免疫），就消耗一层麻痹，这次攻击被打断：
  - 不造成伤害；攻击开始时起计的冷却照常；
  - 敌人得到 0.5 秒（15 帧）麻痹震颤。
  - 麻痹只打断敌人的攻击；干员身上的麻痹没有效果。
- **流失**：单位持有抵抗（`buffres`）时，每帧给麻痹 Buff 的计数加上它的综合抵抗衰减率（状态-3）；计数到 300（10 秒 × 30 帧）时，减 300，流失一层。没有抵抗时计数不变，只降低一减状态抵抗率也不会流失。默认抵抗（0.5）下每 5 秒流失一层。
- **免疫**：麻痹免疫的单位，麻痹 Buff 留在列表里但不打断（状态-7）。神经爆发对麻痹免疫的单位不施加麻痹（元素-4）。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 麻痹：「每层麻痹可以使敌人在普通攻击时打断本次攻击，上限3层；麻痹未被消耗时持续时间无限，拥有抵抗的单位每5秒流失1层」，「存在该状态的敌人在普通攻击动作期间，即将攻击的瞬间或开始动作2秒时被打断，进入0.5秒的麻痹震颤状态」，「流失层数仅在持有术语抵抗或麻痹抵抗时生效（意味着在仅改变一减状态抵抗率的情况下并不会流失麻痹层数）」，「流失机制实际为每(10/综合抵抗衰减率)秒流失1层麻痹」；[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606)：麻痹（PALSY）「敌人类单位在进行普通攻击动作期间……获得0.5s麻痹震颤以打断本次普通攻击」，麻痹震颤（PALSYING）「无法攻击、释放技能」，「晕眩、无法行动、麻痹震颤同样因切换状态机而让单位无法移动」，麻痹抗性 palsyImmune；打断后的冷却为推断 INF-0048

### 状态-9 阻回、静默、元素免疫

- **阻回**（`noSp`）：不回复技力——技力冷却槽暂停，攻击回复、受击回复不加技力（技能-2）。技力的流失（凋亡爆发）不受影响。
- **静默**（`mute`）：技能不能发动（技能-3），效果与沉默相同，但不是沉默：识别沉默的效果不识别它。
- **元素免疫**（`elementFree`）：元素值不会损失（元素-2）。

- 来源：[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606)：阻回（SP_RECOVER_STOPPED）「停止技力自然回复，并阻止任何形式的非强制性技力增加」，静默（SKILL_NOT_ACTIVATABLE）「无法触发技能与能力」「效果与沉默相同，但不会被识别为沉默」，元素免疫（ELEMENT_FREE_ALL）「元素值不会损失」

### 状态-10 恐惧移动

恐惧生效的敌人不走路线上的移动段，改为恐惧移动。路线上的消失、出现照常执行；停驻的时间照常扣除（恐惧不是「无法移动」，移动-1 的暂停等待不适用于它）。恐惧结束时立刻清除恐惧移动；停驻若还有剩余，留在原地继续停。持续帧数按状态-3：秒由时间-2 换成帧。

控制器的状态记在敌人身上（命中位置、效果源位置、可达地块、检查点、临时路径、地图印记），快照因此带得走。

- **可达地块**。施加时记下命中位置（敌人当时的坐标）和效果源的坐标。列表在下一次敌人行动时建立——施加本身拿不到地图（推断 INF-0295）。
  - 没有效果源，或效果源就是自己，或效果源与命中位置的距离为 0：列表为空。
  - 否则收入同时满足下面几条的格：
    - 格心在命中位置半径 10 格以内（含正好 10）。格心与命中位置重合时算在扇形里（推断 INF-0294）。
    - 落在远离效果源方向的左右各 45° 里（含正好 45°）。远离向量 d = 命中 − 效果源，格心向量 v：|v| ≤ 10，且 v 为 0，或 v·d > 0 并且 2(v·d)² ≥ |v|²|d|²。
    - 沿这名敌人的路线能走到终点（流向终点的流场距离 ≥ 0，寻路-1）。没有路线，或走不到终点：这一格不算（推断 INF-0294）。
    - 对它的行动方式可通行（地面只要 ALL，空中只要不是 NONE），不论该格是不是障碍物。
    - 不是保护目标点，也不是地穴。保护目标点指任一路线的终点格、键以 `tile_end` 开头的格、以及标了 `goal` 的格（推断 INF-0294）。
- **检查点**。从列表里寻路距离不超过 5 的格中随机取 1 格，下标是 `floor(draw × 个数)`；再加上边长 0.5、以该格中心为中心的正方形里的均匀偏移，每轴 `(draw − 0.5) × 0.5`（推断 INF-0292）。寻路距离是流向该格的流场距离（寻路-1）：普通步代价 1，所以就是不超过 5 步；路径上要走出障碍物或地穴时代价超过 5，该格被放弃。找不到这样的格，或列表为空：用自己所在格，同样的偏移。所在格按四舍六入五成双（数值-6）。被放弃的格从本次列表里去掉，直到列表被刷新。
- **走法**。地面沿平滑流场（路线-2，含站在格心以外时先回到格心）；空中直线走向检查点（推断 INF-0295）。抵达后立刻再选一个检查点。速度是自己的移动速度（移动-1）。随机数只用对局的 `draw`。
- **再次获得与多个恐惧**。同名仍按排队（状态-2）：时间都在走，最早的一条提供标记。再次获得时，用这一次的命中位置和效果源重做列表，并重选检查点。多个都在时，其中任一结束，只重选检查点，不重做列表，已经去掉的格也不放回（推断 INF-0295）。
- **重规划**。位置与上一帧这次移动结束时不同（被推开，或路线把它出现到别处），或地图印记变了，就向同一个检查点重做临时路径，不另抽随机数。印记是每一格的通行、障碍、地穴，加上封闭格边。这个检查点因此走不到时才重选（推断 INF-0295）。
- **不做的事**。不能被阻挡（阻挡-1）。不开始普通攻击，正在进行的普通攻击中止（推断 INF-0293）。失衡的那一帧只滑行，不恐惧移动（位移-3）。
- 对自己施加的恐惧（效果源是自己，敌能-49）就是上面「效果源就是自己」：列表为空，在当前格里按本条抖动，飞行走直线。用增益往可达地块里另加地块，本条不实现。

### 状态-11 诱导

诱导是目录里的状态 `attract`：无法被阻挡（阻挡-1），可抵抗（状态-3，不在施加时把时长乘一次）。同名规则是独立，层数上限 1000000——页面没有上限，效果一直留到它自己结束（推断 INF-0296）。持续帧数与恐惧相同（状态-3、时间-2）。目标、路径和「现在盯着哪一条」记在敌人身上，快照带得走。

- **目标**。给了点，就用这个点所在格的中心；否则用效果源所在格的中心。所在格按四舍六入五成双（数值-6）。不产生偏移。没有点也没有效果源：状态仍在，这一帧不移动（推断 INF-0298）。效果源还在场时，每帧改盯它现在的格；不在场则留在上次记下的位置所在格（推断 INF-0298）。
- **走法**。地面沿平滑流场（路线-2），空中直线，速度是自己的（移动-1）。走到该格中心后停在那里，直到这一条诱导结束。
- **多条**。每一条都保留，时间都在走。当前目标是最近施加、还在的那一条。它结束或消失后，下一条更早的立刻成为目标。敌人停在当前这一格上，不是在多条都还在时把所有点连成一条折线（推断 INF-0296）。
- **路径安全**。页面写了路径距离有最大限制（路径安全阈值），但没有给出数字。地面单位在扣除自己所在格的走出代价之后，流向目标的流场距离 ≥ 1000（类障碍物一步的代价，寻路-1）时，这一帧不走诱导路径（推断 INF-0297）；流场走不到也不走。状态仍在，也不改走原来的路线。空中单位没有这道限制。站在高代价格里的敌人可以被拉出来：当前格的走出代价不算。
- **重规划**。被其他效果移动（位置与上一帧结束时不同），或地图印记变了（与状态-10 同一份印记），向当前目标重做路径，不抽随机数。
- **和恐惧一起**。同时存在时只做恐惧移动（恐惧 > 诱导）。恐惧结束而诱导还在，从当时的位置继续诱导。
- **路线**。与恐惧相同：消失、出现照常，停驻照常扣除，不走移动段。诱导不阻止普通攻击（推断 INF-0298）。失衡的那一帧只滑行，不诱导移动（位移-3）。
