# 常量

名字和 Stronghold Protocol 的内容接口一致（ADR 0012）。这里只收已经找到出处的官方常量；状态、元素、推拉等机制的常量随各自的机制加入。每关的地图大小不是常量（见 M4 的内容适配）。

### 常量-1 最低伤害比例

伤害减免后，至少保留减免前数值的 5%（`MIN_DAMAGE_RATIO` = 0.05）。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：物理、法术、元素伤害公式都取 max(…, 0.05 × A)

### 常量-2 我方碰撞半径

我方单位的碰撞体积是半径 0.25 格的圆（`ALLY_COLLIDER_RADIUS`）。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：「我方干员碰撞体积基本均为以0.25格为半径的圆形」

### 常量-3 阻挡半径

地面阻挡半径 0.70709997，飞行阻挡半径 0.8944（再乘单位的阻挡半径倍率）。官方比较的是平方：地面 0.49999037，飞行 0.79995137。这两个平方值正好是半径先转成单精度浮点数、再按单精度平方的结果。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：「地面阻挡半径 = 0.70709997」，飞行阻挡半径与两个平方值

### 常量-4 攻击速度的上下限

攻击速度属性的下限是 20，上限是 600（`ASPD_MIN`、`ASPD_MAX`）。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：「攻击速度属性实际被限制了下限为20」，「参与攻击间隔计算时会被限定在10~600以内」

### 常量-5 默认移动倍率与每帧时长

- **默认移动倍率**：关卡的默认移动倍率是 0.5（`MOVE_SCALE`），每秒移动的格数 = 移动速度 × 倍率（移动-1）。
- **每帧时长**：一帧是 1/30 秒（`TICK`，时间-1）。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：「move_multiplier 默认值为0.5」

### 常量-6 敌方碰撞半径

普通敌人的碰撞体积是半径 0.1 格的圆（`ENEMY_COLLIDER_RADIUS`），我方的范围按它判定（体积-5）。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)「碰撞体积与位置识别」：「索敌抬手等均使用碰撞箱」；半径为推断 INF-0287
