# 阻挡

实现见 `packages/sim/src/blocking.js`。坐标以格为单位，干员站在格中心。

### 阻挡-1 何时被阻挡

每个敌人在自己的回合开始时检查一次是否被阻挡；没被阻挡、走了一段之后，再检查一次。已被阻挡的敌人不再检查。

- 敌人此时可以被阻挡：不处于无法被阻挡、恐惧、诱导、浮空、沉睡。
- 候选是所有干员中，敌人位于其阻挡半径内的：(dx² + dy²) < r²。dx、dy 是敌人坐标与干员所在格中心之差。r² 按这个干员自己算（常量-3）：地面敌人 0.49999037；空中敌人 0.79995137 × 它的阻挡半径倍率²。
- **不再接触阻挡**（标记 `noNewBlock`）：持有它的单位不因接触再接下新的敌人；已经挡住的留到解除（阻挡-3）。内容仍可用 `blockBy` 在生成或刷新时指定阻挡。迷狂牢笼「可以阻挡生成/刷新时本格所有敌人」：阻挡在那时判定。消失、受击次数和技能结束后的持续时间不在本条。
- 候选还要能接下这个敌人（阻挡-2）；关卡有玉门天灾工事的规则时，地面上的两者还要同在工事上或同不在工事上（地图-3）。
- 取距离最近的；距离相等时取较早创建的。
- 内容可以让一个在场、有生命、还没被阻挡的敌人立即被某个单位阻挡（`blockBy`），不检查阻挡半径和阻挡数；之后照 阻挡-3 解除。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：「判断阻挡距离时会使用相应的阻挡半径平方数判断距离」；[PRTS「游戏数据基础」oldid=405837](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=405837)：「飞行阻挡半径平方数 = 0.79995137 × 阻挡半径倍率²」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)：恐惧「无法被阻挡」、浮空「无法被阻挡」、沉睡「无法阻挡/被阻挡」；[PRTS「术语释义」oldid=401060](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=401060)：诱导「无法被阻挡」；数据：character_table `token_10055_phatm2_mndclv.description`（ArknightsGameData 17759cc8cdf37388414145d16262a3a06f3ab25e）「牢笼可以阻挡生成/刷新时本格所有敌人，没有阻挡目标或受到3次来自阻挡目标的攻击后消失，酒神技能结束后额外持续30秒」；[PRTS「酒神」oldid=392146](https://prts.wiki/index.php?title=%E9%85%92%E7%A5%9E&oldid=392146)「迷狂牢笼本身存在大量特殊机制，具体参考页面迷狂牢笼」；检查时机、取最近者为推断 INF-0024；内容立即指定阻挡为设计决定（兼容层的 kit 会直接指定，兼容-4）

### 阻挡-2 谁能阻挡、能阻挡多少

- **能阻挡的干员**：生命大于 0，不处于晕眩、沉睡。
- **地面敌人**：只能被站在地面格（不是高台）、且所有单位都能通行的格上的干员阻挡。
- **空中敌人**：只能被带「阻挡空中单位」标记（`blockFly`）的单位阻挡（M3e 的分支特性给出）。
- **起飞**（标记 `liftoff`）：单位只阻挡空中敌人（不论站在什么格上），不阻挡地面敌人；起飞时的阻挡数取特性的 `liftoffBlock`（巡空者，职业-12），没有时为阻挡数。起飞后行动方式仍是地面。
- **地面来源的伤害、元素损伤和状态**：行动方式为地面的敌人，对起飞单位的伤害、元素损伤和异常状态都不生效。空中敌人照常。没有来源的照常生效。同阵营的照常生效。生命流失不经过这一拒绝（伤害-10）。敌对装置是角色类单位，行动方式为地面——模型看起来在飞也一样；处于浮空时行动方式不是地面，照常生效。我方装置同阵营，不在此列。索敌的对地规避仍只看敌人（`evadesGround`）；装置不作普通攻击（装置-1）。
- **已经出手的一击**：目标在被锁定之后、或弹道已经飞出之后才起飞的，这一击的伤害、元素损伤和状态仍然不生效。判定在 `hit`、`elementHit`、`beforeStatus` 之前各做一次；处理函数里才起飞的，这一击仍然结算。
- **选择与光环**：对地规避属于无法选择。行动方式为地面的不同阵营单位，其索敌、范围攻击和 Buff 选择器都看不到起飞单位。迷彩写明光环默认不受制约，且迷彩不属于无法选择；对地规避没有这条例外，会去选择目标的光环也不能选中。已经指定好目标的施加（`lend`）是直接选中，不受仅在选择时生效的效果制约。本引擎没有这种敌方光环，不另做一层。
- **阻挡数**：干员已阻挡的敌人的阻挡数消耗之和，加上这个敌人的，不能超过干员的阻挡数（属性-3）。阻挡数不大于 0 的干员不阻挡。
- **阻挡数消耗**：敌人的阻挡数属性，数据里没写时为 1。

### 阻挡-3 解除阻挡

- 敌人的回合开始时，下列情况解除阻挡：阻挡者已不在场或生命为 0；阻挡者不能再阻挡（晕眩、沉睡）；敌人变得不能被阻挡（恐惧、浮空、沉睡等）。所以敌人被施加浮空后，最晚在下一帧脱离阻挡。
- 干员撤退或阵亡时，它阻挡的敌人全部解除。
- 每一帧干员行动前，如果它的阻挡数装不下已阻挡的敌人，从最后被阻挡的开始解除，直到装得下。同一帧被阻挡的，创建较晚的算后被阻挡。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 浮空：「被阻挡的单位在触发浮空1帧后脱离阻挡」；容量不足时先解除最后被阻挡的为推断 INF-0026

### 阻挡-4 被阻挡的敌人

- 被阻挡的敌人不移动。
- 近战干员可以选中自己阻挡的敌人，即使它不在攻击范围内；它在排序中也排在前面（索敌-3）。
- **部署时的偏移**：干员部署到一个已有敌人的格上、当帧阻挡了这个敌人时，敌人被移到以干员为中心、半径 0.5 的圆上，方向是从干员中心指向敌人。离中心不到 0.00001 的敌人不移动。同一干员后来阻挡的敌人还有一个不超过 0.2 的旋转偏移，PRTS 没写算法，不模拟。

- 来源：[PRTS「索敌的概念」oldid=376233](https://prts.wiki/index.php?title=%E7%B4%A2%E6%95%8C%E7%9A%84%E6%A6%82%E5%BF%B5&oldid=376233)：「大部分我方近战单位（包括重装要塞分支）常态都可以并优先索敌自己阻挡的敌人（即使那敌人根本没走入攻击范围内）」；[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：「向一个已经有敌人的格子空降干员时，敌人坐标会被阻挡偏移到0.5半径圆边界上」，偏移方向为干员中心指向敌人中心，位于方格正中心（0.00001 以内）的不偏移
