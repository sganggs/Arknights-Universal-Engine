# 体积：单位在哪里能被打到

函数名和 Stronghold Protocol 的内容接口一致（ADR 0012），但网格大小作为参数传入：每个关卡的地图大小不同。格子编号是 `行 × 列数 + 列`。

### 体积-1 点单位所在的格

普通单位是一个点。它所在的格是位置取整后的 (行, 列)，取整用四舍六入五成双（数值-6）。超出网格时不在任何格上。格子编号不出现 −0。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：「受击方坐标经round函数取整(四舍六入五成双)得到其所属格坐标，按是否属于该格判定」（固定对照 v0.3.1 的 `body.js` 同样五成双，DIF-0003 已消除）

### 体积-2 巨型单位占据的格

巨型单位有受击区域 `hitArea` { w, h, dx, dy }（格）：一个以位置偏移 (dx 列, dy 行) 为中心、宽 w 列、高 h 行的矩形。

- **占据的格**：与矩形内部重叠的每个格都算占据；只碰到边的格不算，比较时容差 1e-9。这些格各自都能通过格子判定。
- **数据校验**：w、h 必须为正的有限数，dx、dy 必须是有限数，否则当作点单位。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：「巨型BOSS单位的每一个占据的格子都可以让其本身通过格子判定」；矩形模型与边界规则为推断 INF-0014

### 体积-3 到单位的距离

- **距离**：从点 (x, y) 到点单位的距离，是到它位置的距离（hypot，数值-2）；到巨型单位的距离，是到它矩形的距离，点在矩形内时为 0。
- **半径判定**：距离 ≤ r + 1e-9 时，算作在半径 r 之内。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)：碰撞箱碰撞「为最常用的方式，索敌抬手等均使用碰撞箱」；对矩形的距离为推断 INF-0014

### 体积-4 以格为单位的距离

从格 (r, c) 到单位的切比雪夫距离（行差、列差中较大的那个）：单位所在的格为 0，周围八格为 1，依此类推。巨型单位取它占据的格中最近的一个。

- 来源：设计决定，与 Stronghold 内容接口一致，用于"周围八格"一类的方形区域，见 [ADR 0012](../adr/0012-stronghold-compatible-core.md)

### 体积-5 范围按碰撞体判定

我方的范围（攻击范围、技能和特性的范围、范围天赋，索敌-1）判定普通敌人时，看它的碰撞体：以位置为圆心、半径 0.1 格（常量-6）的圆。圆与范围里某一格的内部重叠，敌人就在范围内。

- **重叠的格**：位置所在的格（体积-1）；圆越过这一格的某条边（位置离格中心超过 0.4 格）时，加上那条边外相邻的格；同时越过两条边、并且盖过两边相交的角时，再加上斜对的格。只碰到边或角不算重叠。网格外的格不算。
- **不变的**：巨型敌人仍按矩形（体积-2）；我方单位和装置仍按所在的格（体积-1）；地形、格子状态、陷阱、按"所在格"的判定和敌方的范围仍按位置所在的格；阻挡仍按中心距离（阻挡-1）。正面被阻挡的地面敌人停在离阻挡者中心约 0.7 格处（阻挡半径 0.7071，常量-3），它的圆止于约 0.6 格，在阻挡者那一格外约 0.1 格，所以只到阻挡者那一格的范围打不到它。
- **按格索敌**：特性带 `rangeTiles` 的干员（谬因，职业-7）索敌和攻击按敌人位置所在的格，不看碰撞体。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)「碰撞体积与位置识别」：「索敌抬手等均使用碰撞箱」；[PRTS「谬因」oldid=435070](https://prts.wiki/index.php?title=%E8%B0%AC%E5%9B%A0&oldid=435070)天赋「链路协议」备注：「谬因的索敌与攻击始终采用格子判定而非碰撞判定（只能攻击到格子坐标位于范围内地块上的敌人）」；重叠的细节为推断 INF-0285，近处范围（职业-11）和范围天赋（部署-6）也按碰撞体为推断 INF-0286
