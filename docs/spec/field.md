# 地图、部署、费用

### 地图-1 坐标

地块按"路线坐标"存放：第 0 行是离镜头最近的一行，第 0 列是最左一列。关卡文件的 `mapData.map` 从最上一行开始列出，路线的位置（起点、检查点、终点）已经是第 0 行在下。所以：

```
tiles[r] = mapData.map[高 − 1 − r]
```

- 来源：数据：level.mapData.map、level.routes[].startPosition（出怪起点必须落在出怪点地块上，测试据此核对）

### 地图-2 封闭的格边

关卡可以封闭一些格边（`blockEdges`）：每条给出一格（行列同路线坐标，第 0 行在下）、这格的哪一边（UP 朝行 + 1，RIGHT 朝列 + 1，DOWN，LEFT）和它挡谁（WALK_ONLY 挡地面单位，FLY_ONLY 挡空中单位，ALL 都挡，NONE 不挡）。一条格边把它两侧的格隔开，两个方向都隔开；数据里每条边只从一侧列出。

- **寻路**：被挡的单位不能在这两格之间走（寻路-1），视线也不能跨过它（寻路-2）；斜着走一步时，交于那个角的四条格边都不能对它封闭。
- **滑行**：失衡滑行的地面单位要跨过封闭的格边时停下（位移-3）。

- 来源：[PRTS「玉门天灾工事」oldid=440587](https://prts.wiki/index.php?title=%E7%8E%89%E9%97%A8%E5%A4%A9%E7%81%BE%E5%B7%A5%E4%BA%8B&oldid=440587)「每个玉门天灾工事的四个边缘具有“可进出性”配置，不可进出的边缘上会存在？宽度的物理碰撞“墙体”，并在敌人寻路时将此地块与相应的周边地块之间的路径视为不可通行」；数据：level.mapData.blockEdges（pos、direction、blockMask）。方向的取法由数据核对：按上述取法，IG-10 匪帮集会与 IG-S-2 爬高上低里每一处玉门天灾工事与普通地块（云梯除外）的交界都有一条 WALK_ONLY 的边，每条地面路线仍然走得通（测试据此核对）。两侧都隔开、FLY_ONLY/ALL/NONE 的含义、斜走与滑行的处理为推断 INF-0149

### 地图-3 玉门天灾工事

玉门天灾工事（`tile_passable_wall`，不可部署的 `tile_passable_wall_forbidden` 相同）是地势高于普通地面的远程位地面地块。关卡有地形增伤控制时（内容把它当作关卡的规则，不是场上的单位），对两个都在地面上（不飞行、在地图上）的单位：

- **伤害**：站在工事上的单位对站在普通地块上的单位造成的伤害乘 `dealt`，受到它们的伤害乘 `taken`（伤害-7 第 6 步；无来源的伤害没有）。两者都在或都不在工事上时不变。地形增伤控制的数值取它天赋的 blackboard：`ymdgct_damage_scale[up].damage_scale`（1.3）为 `dealt`，`[down]`（0.7）为 `taken`。
- **阻挡**：站在工事上的与站在普通地块上的互相不阻挡（阻挡-1）。
- 敌人只能经云梯上下工事，由关卡的封闭格边做到（地图-2）。

- 来源：[PRTS「地形增伤控制」oldid=421599](https://prts.wiki/index.php?title=%E5%9C%B0%E5%BD%A2%E5%A2%9E%E4%BC%A4%E6%8E%A7%E5%88%B6&oldid=421599)「<玉门天灾工事>与此装置正常生效时，位于<玉门天灾工事>地块中与位于普通地块中的角色类单位/敌人类单位无法相互阻挡」「位于<玉门天灾工事>中的单位对位于普通地块中的非飞行单位，造成伤害提升至130%，受到伤害降低至70%」；[PRTS「玉门天灾工事」oldid=440587](https://prts.wiki/index.php?title=%E7%8E%89%E9%97%A8%E5%A4%A9%E7%81%BE%E5%B7%A5%E4%BA%8B&oldid=440587)「地势高于普通的地面地块」「远程位」，不可部署的工事「机制与玉门天灾工事完全相同」；数据：character_table trap_103_ymdgct 隐藏天赋 blackboard。哪个键是增伤、哪个是减伤（按数值对应），减伤只对来自地面单位的伤害、飞行单位不算在工事上，为推断 INF-0151

### 地图-4 地穴

地穴（`tile_hole`）是地面上的破洞：

- **寻路**：地面单位走出地穴格的一步代价 1,000,000，其他每步 1（寻路-1），所以只在没有别的路时才经过地穴；地面单位的视线和直线不经过地穴格（寻路-2、路线-2）。
- **坠落**：每帧敌人的回合之后，站在地穴格上（所在格，寻路-3）的地面敌人坠落：生命归 0，帧末离场（伤害-9），不算任何单位的击杀。飞行中（包括近地悬浮）的敌人不坠落，落地时还在地穴上就坠落。

- 来源：[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)「2023年2月14日闪断修复后，地穴的地面寻路代价为1,000,000」「任何判定点被判定为进入地穴格的地面敌人都会被立即判定为“坠落”（一种特殊的死亡方式）」，判定时机「①地面敌人进入地块/在地块上完成出场动画时」「②在已进入地块的敌人行动模式更改时」；[PRTS「特殊地形」oldid=428366](https://prts.wiki/index.php?title=%E7%89%B9%E6%AE%8A%E5%9C%B0%E5%BD%A2&oldid=428366)「危险的凹陷地形或地面破洞，经过的敌人会摔落至底部直接死亡」。代价记在走出的那一格、视线不经过地穴、每帧在敌人回合后判定为推断 INF-0152

### 部署-1 可部署地块

近战干员只能部署在可部署类型为 `MELEE` 的地块上，远程干员只能部署在 `RANGED` 的地块上，两类都可部署在 `ALL` 的地块上；特性允许时，近战干员也可以部署在 `RANGED` 的地块上（职业-10），远程干员也可以部署在 `MELEE` 的地块上（职业-19），召唤物在召唤者的特性允许时也可以部署在 `RANGED` 的地块上（职业-21）。地图外不能部署。

- 来源：数据：level.mapData.tiles[].buildableType、character_table.position

### 部署-2 部署条件

满足以下全部条件才能部署，否则这条指令被忽略，状态不变：

- 干员存在，座位存在；内容给出了卡组时（同步-9），干员在这名玩家的卡组里；
- 这名玩家场上没有同一名干员；
- 这名玩家没有失守（合作-4）；
- 这名玩家已部署的数量小于关卡的 `characterLimit`（每名玩家分别计算）；特性不计入部署数量的干员（职业-13）不受这条限制，也不计入已部署的数量；
- 干员不在再部署时间内（部署-3）；
- 费用不低于干员现在的部署费用（部署-3）；
- 地块满足 部署-1，且上面没有任何玩家的干员。

部署后扣除现在的部署费用并记在干员身上（撤退-1 返还时用），干员面朝指令给出的方向。

- 来源：每名玩家分别计算为推断 INF-0041

### 部署-3 再部署惩罚与再部署时间

每名玩家的每名干员有一张「卡」，记录再部署惩罚层数（0–2）和可以再次部署的帧。

- **部署费用**：⌊初始部署费用 × (1 + 0.5 × 再部署惩罚层数)⌋。初始部署费用是干员数据的 `cost`。也就是第二次部署要 1.5 倍、之后 2 倍。然后加上天赋改的部分（部署-10：干员第一次部署之前特性的首次部署费用增减，职业-21；各种减费），有加减时不低于 0。
- **离场**：干员撤退或生命归 0 离场时，卡的惩罚加 1 层（最多 2 层）；从离场那一帧起，经过再部署时间（干员数据 `respawnTime` 秒，没有时 60 秒，按 时间-2 换算成 n 帧），第 离场帧 + n 帧起才可以再部署。生命归 0 不返还费用。

- 来源：[PRTS「部署费用」oldid=434779](https://prts.wiki/index.php?title=%E9%83%A8%E7%BD%B2%E8%B4%B9%E7%94%A8&oldid=434779)：「部署费用（属性）=(初始部署费用+基础费用增减)×费用倍率+实时费用增减」，再部署惩罚「通常在干员每次退场（包括撤退、被击倒）后会累积一层再部署惩罚（上限两层），每层为待部署区的自己提供0.5的额外费用倍率……第二次部署所需的费用为一开始的1.5倍（之后向下取整），第三次则变为一开始的2.0倍」；[PRTS「数值范围」oldid=439605](https://prts.wiki/index.php?title=%E6%95%B0%E5%80%BC%E8%8C%83%E5%9B%B4&oldid=439605)：RESPAWN_TIME 再部署时间，下限 0，未给出时 60；数据：character_table 各阶段 respawnTime（处决者 18 秒、行商 25 秒、情报官 35 秒，多数 70 秒）；计时的起止为推断 INF-0042

### 部署-4 常驻天赋

干员数据带 `talentBb`（常驻天赋的 blackboard，干员-6）或 `talentMods`（常驻天赋的效果，干员-16）时，干员部署时就带着一个 Buff：键 `talent`，没有持续时间（不会结束），修饰器按 技能-5 的属性键表从 `talentBb` 换算，再加上 `talentMods`。它和其他 Buff 一样计入属性（属性-1），部署时的生命按带着它的最大生命值算满。

- 来源：天赋常驻生效、和技能的属性加成同样换算为推断 INF-0088；数据：character_table 的 talents（干员-4）

### 部署-5 在场天赋

每帧在干员的回合之前（帧-1 第 7 步，和 职业-13 的光环一起），每个在场、干员数据带 `fieldTalents` 的干员，对其中每一条（职业、势力或所有友方单位，blackboard，效果的修饰器），给场上这个职业、或有这个势力（干员-10）的每个干员——所有友方单位时是每个干员和召唤物——（任何玩家的，包括它自己）一个键为 `field:<它的 id>:<序号>` 的 Buff，修饰器按 技能-5 的属性键表从 blackboard 换算，再加上效果的修饰器。带 `skill` 的只在来源的技能运行时（为是）或不运行时（为否）给；带 `after` 的只在来源这次部署满这么多秒后给；对几个职业的（`professions`）给其中任一职业的干员。带 `max`（同类效果取最高）的，Buff 的键是 `field:max:<修饰器键按字典序以逗号连接>`，所有这样的天赋共用：一个单位只保留其中修饰器绝对值之和最大的那条（相等时先算到的）。来源不在场时去掉这些 Buff。

干员数据带 `fieldAspd` 的干员（引星棘刺的天赋「视界」）在场时，同样每帧给场上每个友方单位（干员和召唤物，任何玩家的，包括它自己）攻击速度 + `ally`、每个敌人（不含中立单位）攻击速度 + `enemy`（直接加算，键 `aspd:<它的 id>`）；单位所在格在一条至少 `cnt` 格长的直线可通行地面上（同一行或同一列连续的可通行地面格，不可通行的格截断；按关卡的地块算一次）时，再加 `allyExtra`、`enemyExtra`。

- 来源：干员-9；作用于所有玩家的干员为推断 INF-0094；同类效果取最高的比较为推断 INF-0256，按来源技能的为推断 INF-0263，部署后经过的时间为推断 INF-0267；视界：数据：character_table 引星棘刺天赋「在场时，所有友方单位攻击速度+5，敌方单位攻击速度-5；位于连续6格或以上直线道路的友方和敌方单位受到的效果翻倍」（`attack_speed_ally`、`attack_speed_enemy`、`cnt`、`…_extra`），[PRTS「引星棘刺」oldid=435248](https://prts.wiki/index.php?title=%E5%BC%95%E6%98%9F%E6%A3%98%E5%88%BA&oldid=435248)「在战斗开始时，判断并记录下全场所有“连续6格（或以上）直线的、可通行的”地面地块……可部署但不可通行的地面地块将不参与计算/截断地块连接……不可部署但可通行的地面黄线格可以参与计算」；单位按所在格判断、几个来源叠加为推断 INF-0246

### 部署-6 范围天赋

和 部署-5 同时，每个在场、干员数据带 `rangeTalents` 的干员，对其中每一条（对象、修饰器），给在它攻击范围（攻击-1，含攻击距离；按 索敌-1 判定）里的每个对象一个键为 `range:<它的 id>:<序号>` 的 Buff，带这些修饰器：对象为敌人时是场上的敌人（不含中立单位），为友方时是场上的干员（任何玩家的，包括它自己和召唤物；只对远程干员的 `ranged` 只给部署类型为远程位或全部位的，`melee` 只给近战位或全部位的，`profession` 只给这个职业的，`professions` 只给其中一个职业的，`others` 不给来源自己）。带区域 `area` 的，不看攻击范围，看对象所在格是不是来源所在格加区域的某个偏移（不随朝向转动；带 `rotate` 的按来源的朝向转动，方向-2）。带条件 `when` 的，还要对象此刻满足：`hpBelow` / `hpAbove` 生命低于 / 高于最大生命值的 `value`，`blocked` 被阻挡或阻挡着单位，`normal` 地位级别为普通（不是精英、领袖），`flying` 飞行，`epHalf` 有一种元素值低于最大值的一半（职业-29），`hpRatioAtMostSrc` 生命比例不高于来源的，`sameDir` 朝向与来源相同（职业-32），`maxHpHighest` 是有一格在来源攻击范围里的干员中最大生命值最高的（相同时 id 小的，职业-33），`sluggish` 持有不免疫的停顿，`coldOnly` 持有不免疫的寒冷而没有冻结，`frozen` 冻结（职业-34）。带标记 `flags` 的，Buff 同时带这些标记。带 `srcWhen` 的，只在来源满足这个条件增益的条件（职业-18）时给；带 `during` 的，只在来源这次部署未满这么多秒时给（职业-35）。离开范围的、条件不再成立的、来源不在场的，去掉这个 Buff。

- 来源：干员-11、干员-22；对任何玩家的干员、对范围内所有敌人（包括飞行的、隐匿的）生效为推断 INF-0095，条件与区域的判定为推断 INF-0259

### 部署-7 时间天赋

干员数据带 `timedTalents`（时间天赋，干员-13）时，干员部署时对其中第 i 条加一个键为 `timed:<i>` 的 Buff：

- 「部署后N秒内」（`during`）：带它的修饰器，持续 `seconds` 秒；
- 「在战场停留N秒后」「在场N秒后」（`after`）：没有结束时间，每 `seconds` 秒（不受衰减率影响）触发；第一次触发时带上它的修饰器，此后不变；
- 「每在场上停留N秒」（`stack`）：同样每 `seconds` 秒触发，每次升一级（最多 `max` 级），修饰器为它的修饰器 × 级数。

修饰器 `ammoFlat`（相加、向下取整）加到弹药技能开始时的弹药数（技能-4）；已经开始的不变。

- 来源：干员-13；第一次在部署后一个间隔、级数乘修饰器为推断 INF-0103；[PRTS「蕾缪安」oldid=435022](https://prts.wiki/index.php?title=%E8%95%BE%E7%BC%AA%E5%AE%89&oldid=435022)「弹药上限提升效果仅能在弹药类技能开始时生效，已开启的技能无法受益」

### 部署-8 部署时的天赋

干员数据带 `deployTalents`（部署天赋，干员-14）时，干员部署时（特性生效之后、被动技能发动之前）按顺序：

- **技力**：区间 [`sp[0]`, `sp[1]`) 里的一个整数——区间不止一个数时抽一个随机数（随机-1），取 `sp[0]` + ⌊随机数 × (`sp[1]` − `sp[0]`)⌋——加到技能的技力上（不超过上限，技能-2）；
- **治疗**：治疗场上每名干员（任何玩家的，包括自己）`value` 点生命，或 `scale` × 自身攻击力（治疗规则同 伤害-11，产生 `heal` 事件）；
- **护盾**：获得这么多层护盾（伤害-8，键为 `deployShield` 的 Buff）。

- 来源：干员-14；区间的上界不含、随机数的抽取方式为推断 INF-0104

### 部署-9 移动

内容可以让在场的干员「移动」到另一格（`moveOperator`）：

1. 目标格不是它能部署的格子（部署-1），或已有别的干员：它被撤退（撤退-1），不再处理。
2. 否则它放开阻挡的敌人（阻挡-3），站到目标格（朝向不变），然后：
   - **一般**：同一个单位在那里重新部署——不带任何 Buff、技能状态（运行中的技能结束），技力清空，部署时的效果再次生效（特性、部署天赋、被动技能、召唤物卡，部署-2、部署-8、召唤-4，`deploy` 事件带 `move`），不积累再部署惩罚，不返还费用；部署完成后流失生命（伤害-10），使生命比例与移动前相同。
   - **保留**（内容的特殊设置）：Buff、技能状态和生命都保留，只发 `deploy` 事件（带 `move`），部署时刻改为现在。Stronghold 的移动都是这样（DIF-0034）。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 移动（ba.addash）：「不退场，以当前血量在目标位置部署」「本质上为一次特殊的撤退-再部署行为」「①尝试判断目标位置是否可部署 ②若目标地块不合法，强制撤退自身并不再处理 ③撤退自身，在目标地块再部署，完成移动」「除非具有特殊设置，否则执行移动行为时：不会继承任何Buff、技能状态，不再被视为手动部署；因移动撤退时不会积累再部署惩罚；可以通过移动行为多次触发部署时触发的效果（包括且不限于：岁怒、初始技力增加）；部署完成后，立刻流失一次生命值以匹配移动前的生命比例；部署时将清空技力」；强制撤退按一般撤退处理、移动时放开阻挡与朝向不变为推断 INF-0145

### 部署-10 天赋改的费用

干员的特性（职业-24；天赋的部分见 干员-29、职业-30）还可以改玩家的费用和卡的部署费用：

- **开局费用**：玩家开局的费用是关卡的 `initialCost` 加上自己卡组里每名干员特性的 `startCost`，有加时不超过 `maxCost`（费用-1）。
- **费用回复**：玩家费用的计时每帧减去玩家自己在场、有生命的干员特性的 `costRate` 之积（没有时为 1），减到 0 或以下时加 1 点费用、计时加回 `costIncreaseTime` 换算的帧数，多减的部分留着（费用-1）。
- **部署费用**：部署-3 的 ⌊初始部署费用 × (1 + 0.5 × 再部署惩罚层数)⌋ 之后，加上下面各项，有加减时不低于 0：
  1. 干员第一次部署之前（卡还没有记录、也不在场上），特性的首次部署费用（职业-21；天赋的加到模组的上）；
  2. 卡组的减费：这张卡所在的卡组里每名干员特性的每条不带 `field` 的 `costCuts`，对这张卡的职业（`profession`）或它的势力之一（`power`）时加上 `value`；带 `first` 的只在这个玩家还没有部署过（在场，或卡有记录）这个卡组里任何一名它对的干员时；
  3. 在场的减费（有对局状态时）：场上每名有生命的干员（任何玩家的）特性的每条带 `field` 的 `costCuts`，对这张卡时加上 `value`；同一个 id（`char`）的干员的同一条只算一次，取最大的减费；
  4. 玩家的下一名干员的减费（`cut`），携带的单位（装置-6）和建造者（守御-4）的卡不算；
  5. 这张卡自己的减费（`cuts` 里它的值）。
- **撤退后的减费**：干员撤退（撤退-1；被击倒不算）时特性有 `retreatCut` 的，玩家的 `cut` 设为它和已有的之中较大的减费。玩家部署一名干员（建造者不算）付费之后，`cut` 去掉（携带的单位不去掉），这张卡的 `cuts` 去掉。
- **部署时的减费**：干员部署时（移动 也算，部署-9）特性有 `deployCut` 的，玩家卡组里这个职业、不在场上的每张卡的 `cuts` 加 `value`，不超过 `max` × `value` 的减费。

`cut`、`cuts` 和第一个技能的记录 `once`（职业-30）只在有时才出现在玩家的状态里。

### 撤退-1 撤退

玩家只能撤退自己的干员；带标记 `noRetreat`（无法撤退）的不能撤退，战术家的援军在召唤物形态下撤退时变为战术点（召唤-11）。撤退后干员离场（部署-3），并返还费用：

返还量 = ⌊min(这次部署消耗的费用 × 返还倍率, 初始部署费用)⌋

返还倍率由分支特性给出（职业-1），默认 50%，冲锋手 100%；特性说不受初始部署费用限制时（职业-21），返还量 = ⌊这次部署消耗的费用 × 返还倍率⌋。返还后的费用不超过上限（费用-1）。

- 来源：[PRTS「部署费用」oldid=434779](https://prts.wiki/index.php?title=%E9%83%A8%E7%BD%B2%E8%B4%B9%E7%94%A8&oldid=434779) 撤退返费：「返费量=⌊min(部署费用（属性）×返还倍率,返还上限)⌋」，返还上限「通常等同于单位的基础部署费用」，返还倍率「大部分召唤物、装置、特种-行商分支通常为0%，先锋-冲锋手为100%，其他大部分干员为50%」，「当前费用到达最大费用上限时……溢出部分将会被丢弃」

### 费用-1 费用

每名玩家各有一份费用。开局为关卡的 `initialCost`，每隔 `costIncreaseTime` 秒（按 时间-2 换算成帧）加 1，不超过 `maxCost`。卡组的天赋可以加开局费用、在场干员的天赋可以加快回复（部署-10）。
