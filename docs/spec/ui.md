# 界面

`@aue/ui` 把原版的 Unity 界面预制件画在页面上：战斗界面（ADR 0021）和促融共竞的战斗外界面（ADR 0063），实现见 `packages/ui/src/`。界面不进模拟：它只读页面给它的数据，再把玩家的点按交给页面。这里规定预制件怎样排版、怎样画、动画怎样播放、页面怎样操作它。

素材可以提供**战斗界面包**（`ui/battle.json`，由维护者另行准备，ADR 0018）：

| 字段 | 含义 |
|---|---|
| `ref` | 参考分辨率（宽、高） |
| `screens` | 预制件的节点树，按名字：每个节点的名字、是否启用、矩形变换 `rt`、组件 `comps`、子节点 |
| `sprites` | 精灵图：宽、高、九宫格边距 `border`、图片文件 `uri`（相对界面包） |
| `clips` | 动画片段：循环方式、时长、曲线 |
| `hud` | 战斗界面要用到的节点、精灵图、颜色和时间（见后面各条） |

**战斗外界面包**（`ui/lobby.json`，同样由维护者另行准备）用同一种格式，参考分辨率为 1280 × 720，另有 `views`（每个界面的页面控制器数据：节点、模板、片段名、颜色、时长，按节点给出，没有类名）、`atlases`（按名字取的精灵图）、`art`（关卡图、加载图）、`sounds`（点按和片段事件用到的音效库）、`strings`（界面文字）。它的图形标出自己是否接收点按（`ray`），并多了下面几条用到的组件：列表 `list`、滚动视图 `scroll`、滚动条 `scrollbar`、回收列表 `recycle`、翻页 `pager`、拖动适配 `dragFit`、多行最佳适配 `bestFit`、宽高比适配 `aspect`、背景适配 `bgFit`、全屏 `fullscreen`、缩放器 `scaler`、颜色组 `colorSet`、开关 `switch`、输入框 `input`、点按音效 `click`、补间 `tween`、圆弧条 `circle`、嵌套预制件 `mark` 与 `inst`；材质多了描边 `outline`、灰度 `grey`，以及带特效提示 `fx` 的「不画」。

节点的组件：图片 `img`（精灵图、颜色、类型、填充）、文字 `text`（文字、字号、样式、对齐、字体名、最佳适配、是否换行、颜色）、渐变 `grad`、画布组 `group`（不透明度）、嵌套画布 `canvas`、遮罩 `mask`（矩形 `rect`、图形 `mask`、模板 `stencil`、软遮罩 `soft`）、只占位不画的图形 `nodraw`、描边或投影 `outline`、布局组 `lg`、布局元素 `le`、内容尺寸适配 `csf`、滑条 `slider`、开关 `toggle`、按钮 `button`、动画 `anim`。图形的材质 `mat` 按效果给出：普通混合、叠加、滚动的贴图坐标、模板形状，或不画。

### 界面-1 画布

- 界面画在一块画布上，画布按界面包的参考分辨率（战斗界面包 1920 × 1080，战斗外界面包 1280 × 720）缩放：页面宽 W、高 H（CSS 像素）时，缩放 k = min(W ÷ 参考宽, H ÷ 参考高)，画布为 W ÷ k × H ÷ k 个参考像素。整块参考区域总在页面上，较长的一边变长。
- 每个界面占满画布；在世界里的画布（自己有尺寸的嵌套画布）按自己的尺寸排版，由页面放到世界里。
- 页面可以先载入界面包的全部精灵图（载入失败的照样算完，不能染色），并逐张得知已经完成多少张、共多少张，用来显示载入进度。

- 来源：界面包的根画布：随屏幕缩放、参考分辨率 1920 × 1080、按宽度匹配；页面比参考分辨率更宽或更高时取哪一边为推断 INF-0113

### 界面-2 矩形变换

- 节点的矩形在父节点（宽 PW、高 PH）里：宽 = (锚点最大 x − 锚点最小 x) × PW + 尺寸增量 x，高同理；轴心点放在锚点的参考点（锚点最小 + 锚点跨度 × 轴心）加上锚定位置处。动画给出本地位置时，轴心点放在父节点轴心加上本地位置处。
- 缩放和绕 z 轴的旋转以轴心为中心。Unity 的 y 轴向上，页面的 y 轴向下。
- 没有矩形变换的节点是父节点中心的 100 × 100；界面的根和没有尺寸的嵌套画布占满父节点。根画布的矩形由画布驱动、保存成缩放 0 时，同样占满画布。

- 来源：Unity UI 手册「Basic Layout」与「Rect Transform」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/UIBasicLayout.html>

### 界面-3 自动布局

- **布局组**（横向、纵向）按顺序（可反转）排列启用的、不忽略布局的子节点：内边距、间距、子节点对齐（九种）；控制子节点尺寸时子节点取首选尺寸，否则取自己的尺寸；主轴上剩下的空间按子节点的弹性尺寸分（强制展开算 1）；放不下首选尺寸时，每个子节点按同一个比例取在最小尺寸与首选尺寸之间（比例 = (可用 − 最小之和) ÷ (首选之和 − 最小之和)）；交叉轴上强制展开或有弹性尺寸时占满，否则（控制子节点尺寸时）取可用尺寸，但不小于最小尺寸、不大于首选尺寸（一段长的换行文字按可用宽度换行）。
- **首选尺寸**：布局元素给出的，否则布局组按子节点算出的（主轴上相加加间距，交叉轴上取最大，再加内边距），否则文字量出的，否则矩形自己的尺寸；不小于布局元素的最小尺寸。**最小尺寸**：布局元素给出的，否则布局组按子节点的最小尺寸同样算出（不控制尺寸时取子节点自己的尺寸），否则为 0。
- **网格布局组**：启用的、不忽略布局的子节点按格子尺寸排，加间距和内边距，整块按子节点对齐放在矩形里。起始轴为横向时一行一行排，每行的列数：固定列数；固定行数时按子节点数算出；否则为宽度放得下的格数；至少 1。起始轴为纵向时一列一列排，每列的行数：固定行数；固定列数时按子节点数算出；否则为高度放得下的格数；至少 1。起始角在右边时列从右往左数，在下边时行从下往上数。首选尺寸：宽为固定列数（不固定时取子节点数的平方根向上取整）个格子，高为按当前宽度排出的行数个格子，各加间距和内边距。
- **内容尺寸适配**：锚点不拉伸的那一轴，尺寸取首选尺寸。
- 页面自己放置的节点（如单位条的底板，界面-19）不参加所在布局组的排列。

- 来源：Unity UI 手册「Auto Layout」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/UIAutoLayout.html>（放不下时在最小与首选之间按比例取、交叉轴上把可用尺寸夹在最小与首选之间，Unity UI 源码 LayoutGroup.cs SetChildrenAlongAxis <https://github.com/Unity-Technologies/uGUI/blob/2019.1/UnityEngine.UI/UI/Core/Layout/LayoutGroup.cs>；关卡详情目标面板里「最高纪录」的高度 58.28 与预制件里 Unity 存下的一致）、「Grid Layout Group」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/script-GridLayoutGroup.html>；只实现到这里列出的程度，为推断 INF-0114；网格按起始轴、起始角定位格子的算法见 Unity UI 源码 GridLayoutGroup.cs SetCellsAlongAxis <https://github.com/Unity-Technologies/uGUI/blob/2019.1/UnityEngine.UI/UI/Core/Layout/GridLayoutGroup.cs>

### 界面-4 图形与文字

- **图片**：精灵图乘以颜色（逐通道相乘，不透明度相乘）。类型：简单（拉伸，保持比例时居中缩放进矩形）、九宫格（四角保持原尺寸、边和中间拉伸，矩形比边距之和小时四角按比例缩小；左右或上下边距相接、中间一列或一行没有宽度时，拉伸相接处那一列或一行像素）、平铺（按精灵图原尺寸重复）、填充（横向从左或右、纵向从下或上、360° 从下右上左之一顺时针或逆时针，按填充量裁掉其余）。没有精灵图的图片画成它的颜色。页面给的图片（头像、技能图标）铺满矩形。
- **渐变**：颜色点乘以图形的颜色，竖带从左到右，否则从下到上。颜色点的位置按枢轴在矩形中心时的坐标算：枢轴在一条边上时，这条边处的位置是 0.5。
- **画布组**的不透明度乘到整棵子树。
- **文字**：字号、粗体斜体、九种对齐、颜色、描边（四个角各一份）或投影（一份）；富文本的颜色、粗体、斜体、字号标签；横向不换行时不换行，否则在矩形宽度内换行；宽度按自身内容定的文字（内容尺寸适配取首选宽度，或横向布局组按首选宽度设置子节点而不拉伸）和纵向截断、矩形只容得下一行的文字也不换行（高度由布局组或内容尺寸适配设定的除外，它的高度就是全部行）；最佳适配时字号取能放进矩形的最大整数字号（不超过最大、不小于最小）。字体按预制件要的字体名换成页面提供的字体，没给出时按文字（只有拉丁字符的用拉丁字体，否则用中文字体）；原字体的小写字母也画成大写的（Novecento 系），文字按大写显示。富文本整段作为一个行内文字排版，带颜色的部分和前后文字一起换行。
- **遮罩**：矩形遮罩、图形遮罩和软遮罩把子树裁到自己的矩形里；软遮罩读另一个节点的图形时（界面包的 `softMask.mask`），子树只透过那个图形的精灵图显示：在那个图形的矩形里（不再裁到软遮罩自己的矩形），按精灵图的不透明度，或读颜色通道时按它的亮度（`softMask.ch`），矩形外不显示；图形遮罩不显示自己的图形时不画它。**模板遮罩**：兄弟节点中第一个带模板的图形写模板（有只写模板的图形时取它），后面的读：只遮读者所在的兄弟节点；写模板的图形名字带 mask 或没有精灵图时只写不画。模板形状是写者的精灵图，或材质给出的圆、圆角矩形。读者的比较方式为「不等于」时（界面包的 `stencilOut`），它画在写者形状以外的地方。

- 来源：Unity UI 手册「Image」「Text」「Mask」「Rect Mask 2D」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/UIVisualComponents.html>；字体替换、模板遮罩的分组规则为推断 INF-0115；渐变颜色点位置的起点为推断 INF-0189；软遮罩读颜色通道时按亮度画为推断 INF-0192

### 界面-5 动画

- 动画片段的每条曲线按路径找到节点；关键帧之间按三次 Hermite 插值，斜率的绝对值不小于 10²⁹ 时保持前一个关键帧的值（阶跃）。时间在第一个关键帧之前取第一个值，在最后一个之后取最后一个值。
- 可以动画的属性：本地位置、缩放、z 轴旋转；锚定位置、尺寸增量、锚点、轴心；画布组的不透明度；图形的颜色（各通道）、是否启用、填充量；节点是否启用；图片的精灵图（取不晚于当前时间的最后一帧）。
- 播放：循环方式为循环或片段名带 `_loop` 时循环，否则播一次后停在最后一帧；可以倒放、延迟、改速度，也可以从片段中的某个时刻开始（之前那一段跳过，其中的事件不触发）。开始播放时立即套用第一帧（从中途开始时套用那一刻）。同一节点重播同一片段时替换前一次。时间按界面的时钟推进。

- 来源：Unity 手册「Animation Curves」<https://docs.unity3d.com/Manual/animeditor-AnimationCurves.html>、「Keyframe」<https://docs.unity3d.com/ScriptReference/Keyframe.html>

### 界面-6 点按

- 页面可以让节点能点按：点按显示中的节点时调用页面的处理。节点或它的父节点有按钮（或开关）、过渡方式为颜色染色时，按下期间它的目标图形再乘以按下颜色，松开或移出时恢复。
- 其他节点不接收指针，指针穿过界面落到战场上。

- 来源：Unity UI 手册「Transition Options」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/script-SelectableTransition.html>；原版按淡入淡出时间渐变，这里立即切换，为推断 INF-0116

### 界面-7 滑条

- 滑条显示一个值：先按最小、最大值换算成 0–1（取整数值时先取整）。填充矩形的图片是填充类型时，把填充量设为这个比例；否则把填充矩形的锚点设为 0–1，再把滑条方向那一轴的锚点最大值设为这个比例（方向反转时把锚点最小值设为 1 − 比例）。

- 来源：Unity UI 源码 Slider.UpdateVisuals <https://github.com/Unity-Technologies/uGUI/blob/2019.1/UnityEngine.UI/UI/Core/Slider.cs>

### 界面-8 模板

- 列表容器里的项由模板预制件生成：放在容器的子节点末尾（或指定位置），保持模板根节点的矩形；容器有布局组时由布局组排列。生成的项可以单独移除。
- 预制件里的引用（节点、精灵图、动画片段）在生成的项里按项自己的根解析。引用按路径上的名字逐级找节点；同一层有几个同名节点时，依次试每一个，直到整条路径找到为止。

- 来源：界面包的列表容器给出它生成项所用的模板（维护者另行准备的素材，ADR 0018）

### 界面-9 不画的部分

- 下列部分不画，也不放占位：界面里的粒子、界面里的 Spine 模型、3D 物体、显示渲染纹理的图片、材质为「不画」的图形（界面包按材质的效果给出：引擎只画普通混合、叠加、滚动贴图坐标、模板形状、描边和灰度几种）。
- 材质为「不画」但带特效提示（溶解、扭曲）的图片，不做特效（界面包给出参数的背景扭曲和噪声渐隐除外，见界面-36），按它的混合方式（叠加或普通混合）照常画出；没有自己的精灵图的不画（它的样子全来自特效的贴图，界面包里没有）。按方向扫入的溶解图用材质的主色画（材质要求时再乘图片自己的颜色），透明度是自己的乘主色的；颜色的绿通道是扫入的进度：0 时完全不显示，约 0.94 以上全部显示，其间按材质的扫入贴图逐点显现，贴图值高的先显现，边缘按材质的柔化宽度平滑。
- 叠加的材质按页面的加色混合画，滚动贴图坐标按时间平移图片，灰度把图片画成灰色。滚动的图片画在它里面一层四边各大一个周期（平铺的按精灵图的大小，否则按图片自己的大小）的元素上，平移的是这一层：页面只移动已经画好的这一层，不必每帧重画图片所在的整块图形（主界面地面下的平铺底纹就是这样一块很大的图形，重画跟不上的机器上整屏会忽明忽暗）。面积不小于 2048 × 2048 参考像素的滚动图片，这一层是一块画布：平铺的图案在上面画一次，画布的长边不超过 2048 像素；同样大的、被圆形形状裁出的纯色图片（主界面地面的边缘）也画在一块这样的画布上，不用浏览器的遮罩。这两块在 3D 地图的透视下交给浏览器按屏幕分辨率光栅化，占的显存会让手机丢掉压在上面的整个界面。
- 圆形形状的材质画在显示的图片上（不是遮罩）时，图片按它裁成圆环：到矩形中心的距离（以矩形的宽高为 1）在外半径以内、内半径以外处不透明，两条边各在各自的柔化宽度内平滑过渡（三次平滑）；只有外半径时是圆盘。

- 来源：没有贴图的东西不显示（ADR 0021：界面里不放不能用的东西）；叠加与滚动的效果为推断 INF-0117，带特效提示的图片照常画、扫入图按绿通道显现为推断 INF-0182，扫入的阈值与平滑取自界面包给出的材质值；圆形形状的内外半径与柔化宽度取自界面包（维护者另行准备的素材），画成圆环的方式为推断 INF-0190

### 界面-10 部署卡

- **待部署区**：本方卡组里不在场、也没有被隐藏（波次-9）的干员各一张卡，按卡组的顺序沿画布底边靠右排开；卡宽为画布宽 ÷ 卡数，限在界面包给出的范围（109–178 参考像素）内。
- **卡面**：页面给的头像（没有时不显示头像）；职业图标和职业色条（界面包的职业表）；稀有度底条（1–4 星一种，5 星、6 星各一种）；精英阶段图标（精英 0 不显示）；现在的部署费用（含再部署惩罚，部署-3）显示在头像上方。
- **能否部署**：不在再部署中、没有被吞噬它的敌人锁定（敌能-30）、当前费用不少于部署费用、还有部署名额时可以部署。不能部署的卡，头像、底框、图标和费用乘以界面包的禁用颜色，不能拖选。
- **再部署中**：卡上显示再部署的遮罩、剩余秒数（一位小数）和圆环（剩余时间占再部署时间的比例）。
- **选中**：选中的卡的内容上移界面包给出的距离（20 参考像素）。
- 其他系统的标记（连携、助战、剩余部署次数等）不显示。

- 来源：[PRTS「部署费用」oldid=434779](https://prts.wiki/index.php?title=%E9%83%A8%E7%BD%B2%E8%B4%B9%E7%94%A8&oldid=434779)：部署费用「该属性会直接显示在干员头像上方」「若当前费用不足以支付部署费用，则该单位无法被玩家拖选」；职业表、稀有度底条、精英阶段图标、禁用颜色、选中的上移距离、卡宽范围取自界面包（维护者另行准备的素材，ADR 0018）；不能部署时一律变灰、卡宽的分法、倒计时的格式与圆环的含义为推断 INF-0118

### 界面-11 费用

- 当前费用（整数）显示在画面右下角；下方的白条按距下一点费用的冷却进度从左到右填满：1 − 距下一点的帧数 ÷ 费用回复间隔的帧数。当前费用到达上限时，白条换成显示 MAX 的满条。

### 界面-13 方向选择器

- **透视画布**：战斗界面包的透视画布（1920 × 1080 参考像素，每参考像素 0.00337 格）平放在地面上——参考像素的 x 向东、y 向北，画布的中心在场上的一点。它在画面上的样子由四个角经镜头的投影（渲染-13）确定，中间按经过这四点的射影变换。
- **部署**：可以部署的卡按下后拖到它能部署的格上松开（或者按下后再点那一格），格上出现方向选择器，同时盖上暗色遮罩。之后从任意处拖动：在东、南、西、北四个地面方向（各一格在画面上的投影）里取拖动走得最远的那个为朝向；拖动的距离小于向东一格投影长度的 0.4 倍时不取。取到的朝向的箭头染成界面包的高亮颜色，并显示干员朝这个方向的攻击范围（渲染-9）；松开时按这个朝向部署。点取消按钮撤回。
- **拖动块**：选择器中心有界面包的摇杆拖动块（半透明的菱形）。拖动时它跟着拖动在地面上走过的位移（从按下处算起，按格中心处一格向东、一格向北在画面上的投影分解，换成摇杆所在节点的像素：透视画布的参考像素再除以选择器的缩放 2.5）移动，离中心最远为摇杆区域宽度的一半（213 像素，地面上约 1.8 格）；选择器出现时和松开后回到中心。

- 来源：透视画布的尺寸与比例、方向选择器、箭头的普通和高亮颜色取自界面包；透视画布平放在地面上并以格为中心、拖动的判定为推断 INF-0120；拖动块、它的区域和「从按下处算起、松开后回中心、不超出区域半径」的设置取自界面包的摇杆，拖动块按地面位移移动为推断 INF-0213

### 界面-14 干员菜单

- 点本方在场的干员：它脚下出现干员菜单（同一透视画布，中心在干员脚下）——撤退按钮在左上，技能按钮在右下；干员离场时菜单关闭，点别处也关闭。
- **技能按钮**：技能图标（素材的技能图标；干员没有技能、或者没有图标时不显示技能按钮）。积攒技力时按已积攒的比例从下往上填充，并显示未就绪标记；手动技能可以发动时显示就绪标记；运行中按剩余时间占持续时间的比例显示，可以主动关闭（技能-7）时显示停止标记；自动触发的技能显示自动标记。

### 界面-15 合作的费用请求

两人的对局里，费用面板上方的费用请求面板一次显示一种状态（合作-5），按下面的先后取第一种：

1. 协作者有开放的请求：「协作者请求费用」、同意时会划拨的费用（min(划拨上限, 本方的费用, 协作者离费用上限的差)）、同意和拒绝按钮、请求剩余时间的进度条。
2. 本方有开放的请求：「等待答复」和请求剩余时间的进度条。
3. 本方的请求得到回应后 2 秒内：同意时显示划拨来的费用，拒绝时「队友拒绝」，忽略时「队友忽略」。
4. 本方还在请求的冷却中：距可以再请求的秒数（向上取整，两位）。
5. 本方能请求（有协作者、双方都没有失守、本方费用低于上限、双方都没有开放的请求、不在冷却中）时为请求按钮，按钮上为划拨上限；否则「无法请求」。

点请求按钮发出请求（指令 `ask`）；点同意或拒绝回应协作者的请求（指令 `answer`）。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)：「请求费用：向对方发起一次部署费用请求」「费用请求存在15s冷却时间，对方忽略或拒绝时，你会获得相应的提示」「费用达到上限/对方已丧失指挥权时/对方正在执行费用请求时，你无法执行费用请求」；各状态的面板和文字取自界面包；回应结果显示 2 秒、几种状态的先后为推断 INF-0122

### 界面-18 结束、失守与重连

### 界面-19 单位条

- 页面每帧给出每个画出来的单位：它脚下在画布上的位置（参考像素；飞行的敌人为空中的位置，渲染-21）、种类（干员、敌人、领袖级敌人）、生命值占最大生命值的比例、技能（没有，或技能状态和填充比例）、元素（没有，或界面-20 的元素表盘）。

- **技能标记**：本席位的干员手动技能可以发动、且没有被状态阻止（界面-14）时，单位脚下放一份界面包的技能标记面板，只显示其中的就绪标记——黄色菱形（在面板中心往上 154.7 参考像素），后面一圈黄色光圈在 0.5 秒里从 47 扩大到 100 参考像素并淡出，反复播放；技能运行中可以主动关闭（技能-7）时只显示停止标记。其他时候不放；标记变了时重建。

- 来源：[PRTS「生命值」oldid=425018](https://prts.wiki/index.php?title=%E7%94%9F%E5%91%BD%E5%80%BC&oldid=425018)：常规生命值「表现为我方单位模型下的『蓝条』、敌方单位模型下的『橙条』/『红条』（领袖级单位）」；面板、各条、底板、滑条组和各条的滑条取自界面包；面板跟随脚下的位置、拖尾不显示为推断 INF-0126；技能标记面板、它的各部分、它们的位置和光圈的补间取自界面包；面板放在脚下与原版录像相符（哔哩哔哩 BV1zGsezzEjm 第 1P 约 70 秒：菱形中心在单位脚下往上约 68 像素、即约 154 参考像素）；只给本席位的干员、停止标记何时显示为推断 INF-0209

### 界面-20 元素表盘

- 单位有低于最大值的元素时，面板的普通插件位置显示它的当前损伤元素（元素-5）的元素表盘：表盘的白条按这种元素的元素值占最大值的比例填充，中心是这种元素的颜色；干员的表盘带这种元素的图标，敌人的表盘没有图标，只按元素变颜色（领袖级同敌人）。
- 爆发期间（元素-3）表盘显示爆发的元素，白条按爆发已经过去的时间占爆发时间的比例填充；敌人的表盘这时还显示爆发的光圈（爆发的颜色）。爆发结束、所有元素值回到最大值时表盘消失。
- 受到元素损伤时的扩散动画不播放。
- 渲染状态（第 4 版）里每个单位的 `element` 给出这种元素（神经、侵蚀、灼燃、凋亡、狂躁为 1–5，没有为 0）、`ep` 给出白条的比例、`burst` 在爆发期间为 1。

- 来源：[PRTS「元素」oldid=440971](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=440971)：「当单位存在一项不为最大值的元素时，模型下部会显示对应的元素图标，并以白条显示剩余的元素值」，「实体为敌人类单位时改为小尺寸图标（不显示元素图标，仅根据元素种类改变背景色）」，「如果存在多个不为最大值的元素值，将只会显示当前元素值最低的元素图标」；表盘、各元素的颜色、图标和爆发颜色取自界面包；爆发期间的显示、扩散动画不播放为推断 INF-0127

### 界面-21 开始面板

### 界面-22 阶段开始的横幅

- 合作的对局里，每个阶段（合作-6）开始时（休整结束、计时开始），在整块画布上显示一次阶段开始的横幅：标题为「目标·」加任务标题，旁边是阶段号，下面是最低目标的说明；阶段有进阶目标时再显示进阶目标的说明，没有时这一行不显示（关卡-5）。横幅播放它的动画片段一次，播完收起。

### 界面-23 召唤物卡

- **显示**：召唤物卡（召唤-4）在召唤者在场、并且持有至少一个、或有复制在冷却（队列）、或再部署策略为唯一时，显示在待部署区；召唤者不在场时不显示。
- **顺序**：召唤物卡按初始部署费用升序、费用相同按单位 ID 文本升序插入待部署区；干员卡的顺序不变。
- **卡面**：同干员卡（界面-10），另显示剩余数量的底和数字（持有数）。
- **能否部署**：不在再部署中、持有至少一个、场上数量少于场上数量上限、当前费用不少于部署费用，部署占用数为 1 的还要有部署名额（召唤-4）。不能部署时同样变灰、不能拖选。
- **部署高亮**：只能部署在召唤者攻击范围内的召唤物，只高亮召唤者现在攻击范围内的可部署地块（渲染-8）。

### 界面-24 点按区与挡点按

### 界面-25 颜色组、开关与状态

- **颜色组**：节点的染色（按下、不可用）同时套到它列出的每个目标图形上。
- **开关**：状态为真时显示 `on` 那部分、隐藏 `off` 那部分，为假时反过来；有渐变时间时，显示的一部分在这段时间内不透明度从 0 渐变到 1，隐藏的一部分从当前渐变到 0 后隐藏，后一次切换取代前一次。

### 界面-26 列表

### 界面-27 滚动视图

- **范围**：内容在视口里滚动（可横、可竖）；内容的边不能离开视口内侧。内容比视口小时按它的轴心当成视口大小。内容不必在视口下面（可以是视口的兄弟节点），位置按两者在界面里的位置之差算。
- **拖动**：指针按下后移动超过 10 个 CSS 像素才算拖动，内容跟着指针走；弹性模式下拖过边时按 Unity 的橡皮筋公式（超出量 × 0.55 ÷ 视口尺寸）只显示一部分超出，夹住模式下不能拖出边。拖动过的这次按下不算点按。拖动开始后视图才接管指针，没拖动的按下照常点到视图里的按钮。
- **松手后**：弹性模式下超出边时按弹性时间平滑回弹（Unity 的 SmoothDamp）；否则有惯性时按松手前的速度继续滑，每秒速度乘以减速率，低于每秒 1 像素停下；夹住模式始终留在范围内。
- **滚轮**：沿滚动轴移动滚轮的像素量（换算成参考像素）乘以灵敏度。
- **滚动条**：值为归一化位置，大小为视口与内容之比；把手的锚点按方向放在 `值 × (1 − 大小)` 起的一段（反向从另一端起）。显示方式为需要时显示时，内容放得下就隐藏。
- **拖动适配**：内容放得下时不能拖，`hide` 节点隐藏；还有内容的方向显示箭头。
- **翻页**：松手时滚到最近的一页（一页为视口宽或高），松手时速度超过每秒 200 像素则翻到速度方向的下一页，用翻页时间缓出。
- 页面可以读出视图在两个方向上的偏移，也可以把内容放到给定的偏移并停下它的运动（重新填充列表时回到开头）。

- 来源：Unity UI 源码 ScrollRect.cs（RubberDelta、LateUpdate、CalculateOffset，内容的范围在视口的坐标里算：GetBounds）<https://github.com/Unity-Technologies/uGUI/blob/2019.1/UnityEngine.UI/UI/Core/ScrollRect.cs>、Scrollbar.cs（UpdateVisuals）<https://github.com/Unity-Technologies/uGUI/blob/2019.1/UnityEngine.UI/UI/Core/Scrollbar.cs>、Unity 手册「Mathf.SmoothDamp」<https://docs.unity3d.com/ScriptReference/Mathf.SmoothDamp.html>；拖动起点、滚轮的换算、翻页的规则为推断 INF-0178

### 界面-29 多行最佳适配与描边材质

- **多行最佳适配**：文字字号取不大于文字本身字号、不小于最小字号的最大整数，使文字在矩形宽度内换行后放得下矩形（宽、高都不超出），用二分法找。

### 界面-30 适配

- **宽高比适配**（Unity 的 AspectRatioFitter）：宽决定高（高 = 宽 ÷ 比例）、高决定宽、放进父节点、盖满父节点；后两种居中、锚点拉满。
- **背景适配**：按图片的宽高比盖满父节点；背景自己的矩形（父节点加上它的尺寸差）已经比这更大（两边都不小）时保持自己的矩形，居中。每次布局从节点本身的矩形重新计算，不把上次适配得到的尺寸差作为下次的输入。
- **全屏**：图片铺满整块画布，不管它的父节点在哪里。
- **缩放器**：它记下的目标尺寸与目标现在的尺寸之比（两轴取小）为系数，记下的各节点的位置、尺寸和字号乘以系数；系数为 1 时不变。记下的节点不在预制件里时不管。

- 来源：Unity UI 手册「Aspect Ratio Fitter」<https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/script-AspectRatioFitter.html>；背景适配、全屏与缩放器取自界面包的字段（维护者另行准备的素材，ADR 0018）；缩放器的系数为推断 INF-0181，背景保持自己更大的矩形为推断 INF-0191

### 界面-33 补间

### 界面-36 扭曲与噪声渐隐

- **扭曲**：图片的贴图坐标（先按图片的滚动速度平移）朝一张滚动的噪声贴图在该点的值拉近，拉近的比例是界面包给出的量乘以图片颜色红通道的两倍；噪声按给出的速度乘以颜色绿通道的两倍平移，按给出的平铺重复。画出的是图片自己的颜色（颜色只决定扭曲的快慢和强弱），透明度是图片的乘颜色的。备赛页和开赛展示的背景：界面包给出速度 0.01、量 0.02，颜色为白色，噪声每秒沿两轴各平移 0.02，坐标朝噪声值拉近 0.04。
- **噪声渐隐**：图片按两倍的自身颜色乘材质主色画（每个分量最多为 1）；透明度是图片的乘颜色的、主色的和增益，再乘噪声值超过阈值的部分除以宽度（0–1），最多为 1；阈值为 0 时不按噪声。噪声按给出的速度平移、按给出的平铺重复。备赛页倒计时提示时的橙色圆圈：阈值 0.047、宽度 1、增益 1.2，噪声按 0.3 倍平铺，每秒平移 (0.4, −0.3)。
- 两种效果按图片在页面上的尺寸逐帧画出；噪声或图片移动不到四分之一个贴图像素时沿用上一帧。页面不能运行时（没有 WebGL、图片或噪声未载入、九宫格或平铺的图片、保持宽高比的图片、页面给的图片），图片照常画出（界面-9）。

- 来源：效果的参数（噪声贴图、平铺、速度、拉近的量、阈值、宽度、增益、主色）取自界面包（维护者另行准备的素材，ADR 0018）；两种效果的算法为推断 INF-0193

- **建筑工的卡**：建筑工（守御-4）在待部署区里是计数卡：剩余张数在卡上显示（卡的剩余次数底板与数字），没有剩余时不显示这张卡；只有休整期间、费用够时可以部署，不占部署名额，没有再部署倒计时。
- **部署高亮**：选中建筑工时，只高亮没满级的设施上下左右相邻、可部署的格子（渲染-8）；建成的液压式高台是可部署远程干员的高台（守御-5）。

### 界面-40 合作界面的变化片段

两人对局的合作界面在状态变化时播放界面包的片段（控制器数据 `hud.coopTop`、`hud.coopStage`、`hud.coopCost`、`hud.coopResting`、`hud.coopEmotes`）；页面第一次显示时直接是当时的样子，不补播：

- **失守与复活**：一方失守时，顶栏这一方的生命换成复活倒计时，播放这一方的倒计时入场片段；复活时换回生命，播放生命入场片段。
- **二倍速**：一方打开二倍速开关时，这一方的标记播放选中片段进场，同时它的光亮起，过控制器的淡出时间（0.467 秒）后熄灭；关掉时选中片段倒放，标记退场。
- **任务**：计时进入警示（界面-16）后，计时器循环播放警示片段，离开警示时停下。新的阶段开始时，先把达成标记退回，再播放换阶段的片段：上一阶段的标签划过，新阶段的标签进场（顶栏的第一行标签保持页面最先看到的阶段，换阶段之后显示的是第二行）。计数达到最低目标时播放达成片段，标记在最低目标的计数上——阶段有进阶目标时是左边的计数，没有时是右端的计数；计数又低于目标时播放撤回片段。计数达到进阶目标时，右端的计数播放达成片段。
- **暂停确认**：协作者的暂停申请出现时，确认面板播放出现片段。
- **阶段横幅**（界面-22）：训练（房间-11 的训练关卡）中用横幅的训练片段。堡垒守御的每一波防御开始时（1 秒内）显示波次横幅：第一波的横幅写「坚守阵地」加关卡波数加「波次」，以及当前波次 / 关卡波数（训练中用它的训练片段）；之后各波的横幅写当前波次 / 关卡波数；最后一波的横幅照界面包原样。每一波只显示一次。
- **费用请求**（界面-15）：收到费用和协作者的请求出现时，各自的节点播放自己的片段。
- **休整**（界面-39）：一方同意跳过休整时，它那一侧播放自己的片段；新的休整从片段的开头开始。
- **局内表情**（界面-38）：按钮冷却结束、恢复可点时播放按钮的出现片段。

- 来源：界面包的合作顶栏、倍速面板、任务栏、暂停确认面板、阶段横幅、费用请求、休整面板、局内表情按钮的控制器数据（片段名与各自的节点、警示开始的 10 秒、倍速灯的淡出时间 0.467 秒，维护者另行准备的素材）；各片段在何时播放按控制器字段的用途对应，倍速灯在淡出时间后熄灭、没有进阶目标时标记右端的计数、第一波横幅的波数写法、换阶段时两行标签的分工为推断 INF-0226

### 界面-41 阵地足球

阵地足球（足球-6…足球-16）的两人对局：

- **比分**：合作顶栏不显示状态面板（生命与任务），改用界面包顶栏里的阵地足球面板：我方与敌方的进球数，比赛剩下的时间（分:秒，向上取整）。我方领先时显示「领先」标签并播放它的进场片段；不再领先时标签隐去。
- **球卡**：足球卡（足球-14）只在本座位持有被接住的球时出现在待部署区。
- **场地**：守门位、冰面与黏液的格，以及球的踢动累积，见 渲染-26。
- **开场横幅**：比赛开始时（第一次收到阵地足球状态），开场横幅（界面-22 的那一界面）显示界面包里阵地足球自己的面板（「足球模式」「比分超过对方球员」「比赛开始!」）并播放它的片段一次，之后不再显示；没有合作阶段的横幅。
- **进球横幅**：一方的进球数比上一次收到的多时，界面包的进球面板显示这一方的一组——我方进球是「进球！」，对方进球是「失球！」——并播放面板的片段一次，播完收起；第一次收到的比分不算。

- 来源：界面包的合作顶栏阵地足球面板（`panel_cooperate_football_status`：我方、VS、敌方、两个比分、计时器、领先标签与它的片段 `multiplay_battle_topbar_football_lead_tag`）；界面包开场横幅里的阵地足球面板与它的片段（`hud.coopStage.football`）、进球面板 `coop.score`（我方一组、敌方一组与片段，`hud.coopScore`）；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「被我方守门员挡下的足球会临时进入我方待部署区」；第一季录像（哔哩哔哩 BV173JM6iErM，2025.4 促融共竞#1 阵地足球）：比赛开始时出现「足球模式」横幅，之后每次进球出现「进球！」约一秒半，不再出现开场横幅；计时器显示剩下的时间、领先标签的出现条件为推断 INF-0641，两个横幅的时机为推断 INF-0654
