# 装置

关卡预部署的装置单位：在场的时机、属性，以及它们与阻挡、敌我攻击的关系和在场效果。

### 装置-1 装置单位

关卡的预部署单位（波次-6）有装置记录（关卡-6）且给出所在格时，它生效期间是场上的一个装置单位（单位种类 `DEVICE`，不属于任何玩家，`owner` 为 −1）：站在所在格（高度取地块的），朝向取数据的，属性取记录的（属性-1），生命为满。不隐藏的从战斗开始（第 0 帧，指令之前）就在场；隐藏的在 `ACTIVATE` 动作执行时出现，`WITHDRAW` 动作执行时离场。生命归 0 的装置和其他单位一样在帧末离场（伤害-9）。装置不进行普通攻击，不移动。

- 来源：数据：level.predefines（position、direction、hidden、alias）与 character_table 的装置记录（关卡-6）；PRTS「作战机制」oldid=433935 小队动作指令表（ACTIVATE、WITHDRAW，见 波次-1）

### 装置-2 阻挡与被攻击

装置默认算我方单位（敌方装置见 装置-3）：

- **阻挡**：阻挡数大于 0 的装置和干员一样阻挡敌人（阻挡-1、阻挡-2），被它阻挡的敌人攻击它（敌人攻击-1）。
- **被选中**：远程敌人和攻击干员一样选中范围内可以选中的装置（敌人攻击-1，按 索敌-5 的顺序，嘲讽等级取装置的）。
- **占格**：干员不能部署在有装置的格子上（部署-1）。
- **寻路**：装置不改变敌人的寻路：它的格子不算类障碍物地块（寻路代价不变），敌人照原来的路走到它面前，阻挡数大于 0 时被它阻挡。

- 来源：数据：城防路障 trap_097_hstone「可以阻挡多名敌人」，阻挡数 20；[PRTS「模板:装置信息」oldid=431605](https://prts.wiki/index.php?title=%E6%A8%A1%E6%9D%BF%3A%E8%A3%85%E7%BD%AE%E4%BF%A1%E6%81%AF&oldid=431605)「重写地块：启用时，在场期间根据自身配置修改所在地块配置（包括：高度类型、部署类型、通行类型、地形标记、是否<阻挡路线>等）※如无特殊说明，启用此项时默认会重写所在地块的部署类型为不可部署」；[PRTS「作战机制」oldid=433935](https://prts.wiki/index.php?title=%E4%BD%9C%E6%88%98%E6%9C%BA%E5%88%B6&oldid=433935)「在包含重写为<阻挡路线>的地块（以下简称类障碍物地块）参与的寻路过程中，还会计算他们的寻路代价……每个类障碍物地块的地面寻路代价为1,000」；[PRTS「城防路障」oldid=417801](https://prts.wiki/index.php?title=%E5%9F%8E%E9%98%B2%E8%B7%AF%E9%9A%9C&oldid=417801)「重写地块=是」，没有特殊说明。装置被敌人选中、占格为推断 INF-0148；城防路障不把格子改为<阻挡路线>为推断 INF-0158

### 装置-3 阵营与免疫

内容给每种官方装置一份说明；关卡里有没有说明的装置时，这一关暂不支持。说明可以写：

- **敌方装置**：干员像对待敌人一样选中它（索敌-3，嘲讽等级取装置的；装置没有路线，路径距离为 0），普通攻击、溅射、连锁与范围天赋里的「敌人」都包括它；它不阻挡敌人，敌人不选中、不攻击它；被打倒时和其他单位一样离场（装置-1）。
- **免疫**：装置对列出的异常状态免疫（状态-7）。
- 治疗只选干员，装置不会被治疗。

官方装置：城防路障（trap_097_hstone）是我方装置，免疫晕眩、冻结、寒冷、沉默、沉睡；山海密语仪（trap_096_gflag）是敌方装置（嘲讽等级 −1）。

- 来源：[PRTS「城防路障」oldid=417801](https://prts.wiki/index.php?title=%E5%9F%8E%E9%98%B2%E8%B7%AF%E9%9A%9C&oldid=417801)「阵营=我方」「持有禁疗、孤立、晕眩免疫、冻结免疫、寒冷免疫、沉默免疫、沉睡免疫」；[PRTS「山海密语仪」oldid=337660](https://prts.wiki/index.php?title=%E5%B1%B1%E6%B5%B7%E5%AF%86%E8%AF%AD%E4%BB%AA&oldid=337660)「阵营=敌方」「嘲讽等级=-1」；数据：character_table trap_096_gflag tauntLevel −1。敌方装置的路径距离与「敌人」范围包括它为推断 INF-0150

### 装置-4 在场效果

装置的说明可以给出它在场时给所有敌人（中立单位除外）的属性修正：每个装置在每个敌人身上一个 Buff，随装置离场消失，所以几个装置的修正叠加（加算的相加，乘算的相乘，属性-2）。山海密语仪：攻击速度 +25（直接加算）、移动速度 ×1.15（最终乘算），数值取它天赋的 blackboard（attack_speed、move_speed）。

- 来源：[PRTS「山海密语仪」oldid=337660](https://prts.wiki/index.php?title=%E5%B1%B1%E6%B5%B7%E5%AF%86%E8%AF%AD%E4%BB%AA&oldid=337660)「在场时，所有敌方单位的攻击速度+25，移动速度最终提升至115%（可无限叠加）」；数据：character_table trap_096_gflag 隐藏天赋 blackboard move_speed 1.15、attack_speed 25；几个装置的移动速度相乘为推断 INF-0150

### 装置-5 能力放置的装置

敌人的能力可以在一格上放置关卡有记录的装置（关卡-6）：这格上没有干员和装置时，装置出现在这格，朝上，属性取记录的，生命为满；它不属于任何预部署单位（别名为「装置键@编号」），不会被 `WITHDRAW` 撤回，生命归 0 时离场。阵营、免疫与在场效果按 装置-3、装置-4。

- 来源：[PRTS「山海众掌令使」oldid=436476](https://prts.wiki/index.php?title=%E5%B1%B1%E6%B5%B7%E4%BC%97%E6%8E%8C%E4%BB%A4%E4%BD%BF&oldid=436476)「在经过的首个可部署的“玉门天灾工事”上部署30级的山海密语仪」；朝向与「可部署」的判定为推断 INF-0157

### 装置-7 轰隆隆先生

我方装置 `trap_018_bomb`。关卡的 token 卡列出它时，每位玩家的卡组有这张卡，开局张数是那个 `count`（IG-DF-1 是 0）。部署在近战位，费用是记录的 `cost`（这一关 5），占用部署数 0，阻挡数 0，不攻击，生命取记录（100）。卡由敌能-80 发放。不记入该座已部署的干员，场上可以同时有多张。

部署后 1.5 秒（45 帧，时间-2）触发：自身所在格和上下左右四格上的每个敌人晕眩 12 秒（状态-5，可抵抗），飞行单位也中。然后销毁自身。周围八格不算，为推断 INF-0572。中立单位不晕眩；隐匿、无法选中或隐藏的敌人，只要站在这些格子上就晕眩，为推断 INF-0573。

销毁是离场：不返还已付的费用，不加再部署惩罚，也不算撤退。这一张的再部署时间在部署的那一帧已经开始，时长是页面的再部署时间 5 秒；抽出的记录只有 `cost`，没有 respawnTime。再部署策略一栏的值是「默认」，该栏的提示写「默认：部署后进入再部署时间」：销毁、提前撤退或生命先归零都不重新计时，也不晕眩、不返还，为推断 INF-0574。页面没有写不可撤退，可以手动撤退，规则相同。

实体类型一栏的提示写「装置：默认无法被选中，仅可被少数单位选中」，所以它默认无法被选中。装置-2 的默认可被选中不适用于它。

技能坏脾气默认可被沉默。触发那一帧处于沉默则不晕眩，仍然销毁，为推断 INF-0576。装置机制里的「并销毁自身」不跟着技能一起取消。

这些卡的张数、归还帧和等待触发的装置记在快照第 19 版。没有这张卡的玩家不带这块状态。
