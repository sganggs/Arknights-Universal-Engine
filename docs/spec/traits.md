# 职业与分支特性

实现见 `packages/sim/src/traits.js`（特性的引擎规则）和 `packages/content/src/traits.js`（官方分支的数据表）。部署费用、再部署见 field.md 部署-3、撤退-1。

### 职业-1 特性数据与按位置的默认值

每名干员属于一个职业分支（`subProfessionId`）。分支特性在模拟里是一组数据，没写的项取干员位置的默认值：

| 项 | 含义 | 近战默认 | 远程默认 |
|---|---|---|---|
| `blockedFirst` | 可以且优先攻击自身阻挡的单位（即使在攻击范围外或为飞行单位） | 是 | 否 |
| `antiAir` | 可对空：普通攻击能选中攻击范围内的飞行单位 | 否 | 是 |
| `filter` | 仇恨过滤器（索敌-3） | 仇恨降序 | 仇恨降序 |
| `secondary` | 二次过滤器（索敌-3） | 无 | 无 |
| `targets` | 普通攻击的最大目标数（职业-3） | 1 | 1 |
| `heal` | 普通攻击改为治疗（职业-2） | 否 | 否 |
| `hits` | 每次攻击对每个目标的伤害次数（职业-3） | 1 | 1 |
| `mods`、`flags` | 在场期间一直生效的修饰器和标记（职业-4） | 无 | 无 |
| `hitStatus` | 每次命中给目标的异常状态（职业-4） | 无 | 无 |
| `killCost` | 攻击或技能击杀敌人后获得的费用（职业-5） | 0 | 0 |
| `refund` | 撤退返还倍率（撤退-1） | 0.5 | 0.5 |
| `rangeTiles` | 普通攻击按敌人位置所在的格索敌，不看碰撞体（体积-5） | 否 | 否 |

- 普通攻击的伤害类型是干员数据的 `dmgType`（默认物理），由分支给出（职业-7）。
- 近战干员阻挡的敌人即使是飞行单位、在攻击范围外，也在候选里；其他飞行单位只有可对空时才是候选。能阻挡飞行单位要有 `blockFly` 标记（阻挡-2），可以由特性的 `flags` 给出。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899)：近战分支「可以且优先攻击自身阻挡的单位（即使目标处于攻击范围外或为飞行单位）」，远程分支「可对空」；[PRTS「索敌的概念」oldid=376233](https://prts.wiki/index.php?title=%E7%B4%A2%E6%95%8C%E7%9A%84%E6%A6%82%E5%BF%B5&oldid=376233)：「远程位干员通常而言不会优先攻击自己阻挡的目标」；[PRTS「选择器」oldid=428553](https://prts.wiki/index.php?title=%E9%80%89%E6%8B%A9%E5%99%A8&oldid=428553)：目标行动方式（仅地面、仅飞行、全部）；数据：character_table[].subProfessionId、position

### 职业-2 治疗

`heal` 为是的干员，普通攻击不打敌人，而是治疗友方：

- **候选**：攻击范围内、生命大于 0、没有禁疗的干员。两名玩家的干员互为友方。
- **顺序**：仇恨过滤器「生命比例升序（满生命值除外）」——生命已满的不选；生命比例（当前生命 ÷ 最大生命）低的在前，比对精度 0.001；相同时保持创建顺序。
- **治疗量**：攻击力 × 攻击力倍率（技能-5），按 伤害-11 结算，每次产生一个表现事件 `heal`（事件第 4 版：id、target、amount 为实际回复量）。
- 治疗攻击和普通攻击一样走冷却、技能、攻击回复技力。
- 干员带有标记 `attackFoes` 的 Buff 时（内容用它表示「技能期间攻击改为攻击敌人」），普通攻击不治疗，按非治疗干员的规则选择并攻击敌人。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899) 医师：「普通攻击产生治疗，优先治疗生命比例最低的目标」「通常不会治疗生命值为满的单位，且治疗行为受禁疗制约」；[PRTS「仇恨」oldid=429076](https://prts.wiki/index.php?title=%E4%BB%87%E6%81%A8&oldid=429076)：3 号过滤器「生命比例升序(满生命值除外)」「典型使用者：各类医疗干员的普通治疗」，默认比对精度 0.001；[PRTS「选择器」oldid=428553](https://prts.wiki/index.php?title=%E9%80%89%E6%8B%A9%E5%99%A8&oldid=428553)：治疗行为的选择器不选中禁疗单位；两名玩家互为友方、治疗攻击计为攻击为推断 INF-0045

### 职业-3 目标数与伤害次数

- **目标数**：普通攻击取排好的候选（索敌-3）的前 n 个。n 由特性给出：一个数；`blockCnt` 为干员当前的阻挡数（不低于 1，候选里被阻挡的在前，不足时取范围内的其他敌人）；`all` 为全部候选。技能的目标数（技能-5）比特性的多时，用技能的。
- **伤害次数**：每次攻击对每个目标造成 `hits` 次伤害；技能的 `times` 与它相乘。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899) 强攻手、重剑手：「普通攻击最大目标数等于阻挡数（不会低于1）」，轰击术师：「普通攻击同时攻击范围内的所有敌人」；数据：character_table 剑豪特性「普通攻击连续造成两次伤害」；与技能的组合为推断 INF-0046

### 职业-4 在场修饰器与命中效果

- **在场修饰器**：干员部署时，特性的 `mods`、`flags` 作为一个键为 `trait` 的 Buff 加到干员身上，没有结束时间。部署时先加特性，再发动被动技能（技能-3）。
- **命中效果**：干员攻击的每一下伤害结算时，顺序为：伤害（伤害-7）→ 击杀判定（职业-5）→ 攻击附带的元素损伤（元素-2）→ 特性的命中效果。命中效果只在这一下之前目标仍有生命时发生：`hitStatus` 给目标施加异常状态（状态-5），然后是行为的 `hit`（职业-6）。

- 来源：数据：character_table 凝滞师特性「对敌人造成短暂的停顿」，blackboard `sluggish` 0.8；[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899) 凝滞师「特性停顿时间为0.8秒」；一下伤害内的顺序为推断 INF-0047

### 职业-5 击杀与费用

干员的攻击或技能造成的伤害让一名有生命的敌人生命归 0 时，这次击杀算在这名干员身上：特性的 `killCost` 加到拥有者的费用上（不超过上限，费用-1），然后是行为的 `kill`。只看攻击和技能，不看伤害来源：没有来源的伤害（如元素爆发）不算。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899) 冲锋手：「击杀来源判定仅与攻击、技能有关，与伤害的来源无关」；数据：character_table 冲锋手特性「击杀敌人后获得1点部署费用」，blackboard `cost` 1

### 职业-6 行为接口

内容可以按分支 id 提供行为：部署时（`deploy`）、每一下命中后（`hit`）、击杀后（`kill`）；干员攻击冷却结束、没有在进行的攻击时，能否攻击（`canAttack`：返回否时这次当作没有目标），以及没有目标时做什么（`store`：返回是即储存了一次，占用一个攻击间隔；返回否即什么都不做；不回答时按引擎自己的规则，职业-12；行为接口第 4 版）；哪些敌人这时不选为攻击目标（`skip`：对一个敌人返回是时，索敌时把它排除，在范围内、被它阻挡的也一样；行为接口第 5 版）；部署时是否由行为接管分支自带的部署效果（`own`：返回是时，引擎不给这名干员特性的 Buff 和维持消耗的 Buff，职业-4、职业-10；攻击方式的 Buff 照常，职业-12）。行为只能通过上下文作用，上下文与技能的相同（技能-6，行为接口第 1 版），只是 `bb` 是特性的 blackboard、没有 `kind`：读取干员、blackboard 和属性；加减 Buff、施加异常状态；造成伤害、元素损伤、治疗；给拥有者费用。内容代码不能直接写单位字段（ADR 0045）。

- 来源：设计决定，见 [ADR 0055](../adr/0055-sdk-prepared-now-built-after-mvp.md)、[ADR 0046](../adr/0046-versioned-interfaces.md)

### 职业-8 溅射、余震与按阻挡的攻击倍率

- **按阻挡的倍率**：干员的普通攻击打到一个它没有阻挡的敌人时，这次攻击的倍率乘特性的 `unblockedScale`（默认 1）。
- **溅射**：攻击（近战在命中时，远程在投射物到达时）打到目标后，目标周围半径内的其他敌人也受到这次攻击，伤害为目标所受的 `scale` 倍。半径按单位位置之间的直线距离计（不大于半径）；隐藏的敌人不受影响；只波及地面的溅射不影响飞行单位。隐匿生效的敌人不在其中（索敌-2）；迷彩的在。溅射目标在命中前确定，目标被击倒也照常波及。
- **余震**：有余震时，目标和溅射目标再各受一次攻击，倍率为余震的倍数。
- 溅射和余震的每一下都按普通攻击的命中处理（击杀计入干员，特性的命中效果照常生效，职业-4、职业-5）。

### 职业-9 不被友方治疗与自身回复

- **不被友方治疗**（特性旗标 `noAllyHeal`）：其他单位的治疗对它无效，治疗干员也不选它为目标；它自己对自己的治疗照常生效，即使它处于禁疗。
- **自身回复**：按特性的 `selfHealOn`，每次回复特性的 `selfHeal` 点生命，每次产生表现事件 `heal`：
  - 按攻击（`attack`，收割者）：干员的一次攻击落下时，每打到一个敌人（锁定的目标中仍在场、有生命、没有隐藏的）回复一次，每次攻击最多 `selfHealMax` 次（一个数，或它的阻挡数，至少 1）；
  - 按伤害（`damage`，武者）：干员每次对敌人造成伤害（以它为来源、扣了生命的一次伤害：攻击的每一段、溅射、技能、天赋……）回复一次；生命流失（伤害-10）和无来源的伤害（伤害-7）不算。

### 职业-10 在场的维持：部署位置、阻挡时免疫、技能时的伤害类型、生命流失与费用消耗

- **远程位**（`rangedTiles`）：近战干员也可以部署在远程位的地块上（部署-1）。

- **技能时的法术伤害**（`skillArts`）：技能运行时开始的普通攻击造成法术伤害（技能给了伤害类型时用技能的）。

- **费用消耗**（`costDrain`：每 `every` 秒 `cost` 点）：部署时加一个键为 `upkeep` 的 Buff，没有结束时间，每 `every` 秒（按 时间-2 换算成帧，不受衰减率影响）触发一次：先发 `merchantPay` 事件（钩子-3，处理函数可改这次的费用或取消这次扣费），干员所属玩家的费用不少于（改后的）费用时扣去，少于时干员撤退（撤退-1，返还按它的返还倍率）。

### 职业-11 近处范围的倍率、跳跃链、伤害转治疗

- **近处范围**（`zone`：格子、倍率、是否作用于范围外）：干员的攻击（或治疗）打到一个目标时，目标在这些格子里（格子相对干员所在格、随朝向转动，同攻击范围，按 索敌-1 判定），倍率再乘 `scale`；`outside` 为真时改为目标不在里面时才乘。它和按阻挡的倍率（职业-8）相乘。
- **跳跃链**（`chain`：目标数上限 `max`、每跳倍率 `scale`、半径 `radius`、格子 `cells`）：攻击打到第一个目标（命中时，远程攻击在投射物到达时）后，从它跳到下一个目标，再从那个目标跳，直到共 `max` 个目标或找不到下一个；同一条链不重复跳到同一个单位。每一跳的伤害（或治疗量）是上一跳的 `scale` 倍。
  - 伤害链：下一个目标是距当前目标不超过 `radius` 格、可以被选中的敌人（隐匿除外，迷彩不论，可对空才包括飞行单位）里最近的一个，一样近时取先创建的；每一跳按攻击的伤害次数结算，和普通命中一样触发命中效果（职业-4）。溅射和余震只作用于第一个目标。跳跃链不因迷彩排除为推断 INF-0290。
  - 治疗链：下一个目标是当前目标所在格周围 `cells`（不随朝向转动）里、在场且不拒绝友方治疗（职业-9）的干员——生命已满的也可以——生命比例（精度 0.001）最低的，一样时取最晚部署的。禁疗照常使治疗无效。
- **伤害转治疗**（`healOnHit`，比例）：干员对一名敌人成功造成伤害后，治疗它攻击范围内一名干员（按治疗的选择，职业-2：未满生命、没有禁疗、不拒绝友方治疗，生命比例最低的）；没有这样的干员时不治疗。算扣了生命的每一次伤害（伤害-7）：攻击的每一段、溅射、跳跃、技能和天赋的伤害都算；生命流失（伤害-10）、无来源的伤害（伤害-7：事件里来源为空，不是「自身」造成的）和元素损伤（元素-2：只降低元素值，不扣生命）不算。治疗量 = 这一下已经确定、尚未扣除生命的伤害 × 比例；目标剩下的生命更少时仍按这个数。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899)：散射手「特性加成生效范围默认情况下为同部署方向的 1-3，生效方式为提升攻击倍率」；疗养师「治疗同部署方向的一定范围 2-3 外的目标时，治疗量将受特性衰减倍率影响（最终乘算）」；链术师「跳跃范围半径为1.7，无特殊说明的场合不会进行重复弹跳」「“短暂停顿”的时长为0.5s」「每次伤害均为前次伤害的(1-15%)=85%」，模组的特性部件：battle_equip_table 惊蛰 CHA-X「每次跳跃伤害降低10%」（`attack@chain.atk_scale` 0.9）、布丁 CHA-Y「每次跳跃伤害不再降低」（1.0）；链愈师「跳跃范围为 x-4，无特殊说明的场合一次治疗链不会对已跳跃过的单位重复跳跃」「每次治疗的倍率均为前次倍率的75%」「优先跳跃至范围内生命比例最低＞部署时间点最晚的我方单位。可选择满生命我方单位为跳跃目标，但仍受禁疗制约」；咒愈师「自身成功造成伤害后，且存在治疗目标时进行治疗（受禁疗制约），治疗量于造成伤害数值确定后、正式应用伤害前被确定」；数据：character_table 各分支特性文字与 blackboard（`atk_scale` 1.5、`heal_scale` 0.8、链的目标数、`attack@sluggish` 0.5、`attack@chain.atk_scale` 0.75、咒愈师 `scale` 0.5；咒愈师的 blackboard 只有 `scale`），skill_table 刺玫「荆藤庇荫」（skchr_vendla_2）「该角色受到攻击时刺玫对目标造成攻击力{atk_scale:0%}的法术伤害并仅对该角色触发刺玫特性」、焰影苇草「枯荣共息」（skchr_reed2_2）「每{cooldown}秒对一名敌人造成相当于焰影苇草{atk_scale:0%}攻击力的法术伤害并仅对该干员触发焰影苇草特性」，range_table 的 1-3、2-3、x-4（干员-8）；伤害链取最近的敌人、跳跃在命中时立即发生、咒愈师治疗的选择同治疗干员为推断 INF-0091

### 职业-12 攻击方式：技能期间才攻击、技能外的加成、技能期间治疗、子弹、储存能量、回复元素值、浮游单元、回旋投射物

- **技能期间才攻击**（`attackInSkill`）：技能没有运行时不进行普通攻击（技能照常回复技力、可以发动）。
- **技能外的修饰器与标记**（`idleMods`、`idleFlags`）：技能没有运行时干员带一个键为 `idle` 的 Buff，带这些修饰器和标记；部署时就有，每个干员回合在技能推进之后按技能是否运行加上或去掉。
- **蓄力**（`charge`：攻击加成 `atk`、级数 `steps`、起始加成 `init`）：部署时加一个键为 `charge` 的 Buff，起始为 `init` 对应的级数（`init` × `steps` ÷ `atk`，取整，不超过 `steps`；模组「部署后获得+100%加成」），每 30 帧（不受衰减率影响）触发一次：技能没有运行时升一级（最多 `steps` 级），每级攻击力直接乘算 +`atk` ÷ `steps`；技能运行时保持不变；技能结束时回到 0 级（特性「技能结束时重置攻击力」，在两次触发之间开始又结束的技能也一样），此后照常每次触发升一级。
- **技能期间治疗**（`skillHeal`）：技能运行时开始的普通攻击改为治疗（选目标同治疗干员，职业-2），倍率再乘 `skillHeal`。
- **子弹**（`bullets`：上限 `max`、倍率 `scale`）：部署时子弹是满的（键为 `bullets` 的 Buff 的 `value`）。攻击冷却结束时：没有子弹，或子弹没满且没有目标，就装填一发（子弹立即加 1），这次行动占用干员的基础攻击间隔（攻击间隔属性的基础值，不受攻速和攻击间隔加成影响），期间不攻击；否则有目标时正常攻击，每次攻击用掉一发子弹，倍率乘 `scale`。
- **储存能量**（`store`，最多份数）：攻击冷却结束时没有目标、储存没满，就储存一份（键为 `energy` 的 Buff 的 `value` 加 1），这次行动占用一个攻击间隔。下一次攻击落下时（不是治疗），储存的每一份向第一个目标发射一个投射物，伤害为干员攻击力的法术伤害，然后储存清零；攻击被打断没有落下时储存保留。
- **回复元素值**（`epHeal`，比例）：治疗的目标还包括生命已满但有元素值低于上限的干员；选目标时先按生命比例，一样时按当前损伤元素（元素-5）的元素值从低到高。每次治疗也使目标每种低于上限的元素值增加 治疗量 × 比例，不超过上限；目标处于禁疗或元素爆发（元素-3）时不增加。
- **要塞**（`fortress`：远程攻击的溅射半径）：候选除了攻击范围内的，还有自身所在格这一格范围内的敌人（近战范围，按 索敌-1 判定：普通敌人看碰撞体，体积-5），排在其余候选之后；对自身阻挡的或在自身所在格范围内的目标进行近战攻击（不溅射，不发射投射物），对其余目标进行远程攻击（发射投射物，攻击-3；溅射半径为 `fortress`，职业-8）。
- **技能外只打空中**（`idleAirOnly`）：技能没有运行时，普通攻击只选空中敌人和自身阻挡的敌人。
- **技能期间的溅射**（`skillSplash`）：技能运行时，攻击的溅射用它（职业-8）。
- **起飞后的阻挡数**（`liftoffBlock`）：起飞时的阻挡数（阻挡-2）。
- **回旋投射物**（`boomerang`：去程速度 `out`、回程速度 `back`，格/秒）：普通攻击的投射物（攻击-3）以 `out` 飞向目标，到达时结算，然后以 `back` 飞回干员（追踪干员的当前位置），到达即回收，发出 `boomerangCaught` 事件（钩子-3）。结算之后、返回之前先发 `boomerangHit` 事件：处理函数设 `hold` 为是时，投射物停在到达处由内容接管——内容可以用这次攻击打别的单位（`boomerangStrike`，同到达时的结算），之后从任意位置把它送回（`sendBack`，只能一次，以 `back` 飞回）；停住期间它仍算没有回收，干员离场时消失。干员还有投射物没回收时不开始新的攻击（攻击冷却照常结束，之后等待）。目标在去程中离场、生命归 0 或消失时，投射物从所在处返回；干员离场时它的投射物消失。
- **浮游单元**（`funnel`：起始 `init`、递增 `delta`、上限 `max`）：部署时加一个键为 `funnel` 的 Buff（`value` 记上次攻击的目标 id，计数器记对它连续攻击的次数）。每次攻击到一个目标时（远程攻击在发射时），目标与上次相同则次数加 1，否则改记这个目标、次数归 0；这次攻击的倍率再乘 min(`max`, `init` + `delta` × 次数)。再部署时从头开始。

### 职业-13 不攻击、不计入部署数量、生命回复光环

- **不攻击**（`noAttack`）：干员不进行普通攻击（技能照常）。生效的 Buff 带标记 `noAttack` 时同样不进行普通攻击（内容用它表示「技能期间停止攻击」）。
- **不计入部署数量**（`free`）：部署不受关卡的部署数量限制，也不计入已部署的数量（部署-2）。
- **生命回复光环**（`regenAura`，比例）：每帧在干员的回合之前（帧-1 第 7 步），每个带光环的在场干员给攻击范围内（同 攻击-1，含自身所在格）的每个在场干员一个键为 `aura:<它的 id>` 的 Buff，生命回复速度直接加算 + 比例 × 它现在的攻击力（属性-6）；它的技能运行、技能 blackboard 有 `attack@atk_to_hp_recovery_ratio`（或去掉 `attack@` 的同名键）时，比例改用技能的。不在范围内的、光环来源已不在场的，去掉这个 Buff。不同来源的光环各自一个 Buff，一起生效。

- 来源：[PRTS「分支特性信息/data」oldid=427899](https://prts.wiki/index.php?title=%E5%88%86%E6%94%AF%E7%89%B9%E6%80%A7%E4%BF%A1%E6%81%AF/data&oldid=427899)：吟游者「“范围”指的是干员的攻击范围」「特性为基于自身攻击力来增加受益者的“生命回复速度”属性」；数据：character_table 吟游者特性文字「不攻击，持续恢复范围内所有友军生命（每秒恢复相当于自身攻击力10%的生命），自身不受鼓舞影响，且不受部署数量限制，但再部署时间极长」，blackboard `attack@atk_to_hp_recovery_ratio`（或 `atk_to_hp_recovery_ratio`）0.1，技能 blackboard 的同名键；每帧更新、不同来源叠加、技能运行时换用技能的比例为推断 INF-0093

### 职业-14 召唤物阻挡的敌人、陷阱的地块

- **攻击召唤物阻挡的敌人**（`summonBlocked`）：普通攻击的候选还包括自身召唤物（召唤者是它的单位，召唤-4）阻挡着的敌人，不论站在哪里（飞行的只在可对空时，职业-1）；它们和其他候选一起按仇恨过滤器排序，不优先。
- **召唤物阻挡时的倍率**（`summonBlockedScale`）：干员的攻击打到一个它自身召唤物阻挡着的敌人时，这次攻击的倍率乘它；与按阻挡的倍率（职业-8）、近处范围的倍率（职业-11）相乘。
- **陷阱的地块**（`trapTiles`）：这名干员的召唤物不能部署在有地面敌人站着的格子上（召唤-4 的部署条件）。算作敌人的是所有敌人类单位，不分阵营（中立单位也算）；它站的格是它的位置所在的格；飞行单位（含浮空、近地悬浮）和消失的单位不算。

### 职业-15 替身

`doll`（替身持续 `duration` 秒、切换 `switch` 秒、替身的攻击力加成 `atk` 与最大生命值加成 `maxHp`）的干员有两种形态：本体与替身。

1. **切换到替身**：本体形态下生命归 0（这一帧末，伤害-9）时不离场，开始切换（持有不死的不会归 0，状态-5）：
   - 清除自身的 Buff：正在运行的技能结束（第 4 点里、开启时切换且仍在运行的那个除外）；除了它自己的、没有结束时间的 Buff（特性、天赋、被动技能给的），其余全部去掉；
   - 生命设为最大生命值；
   - 切换期间（`switch` 秒）：不死、无敌、阻回、禁疗、孤立（友方的治疗不选中它）、不进行普通攻击（职业-13 的 `noAttack`），免疫晕眩、冻结、沉睡（状态-7）；阻挡数 ×0（最终乘算），放开阻挡的敌人。
2. **替身**：切换结束时再清除一次 Buff，生命设为最大生命值；替身持续 `duration` 秒：阻回，阻挡数 ×0，攻击力、最大生命值直接乘算 +`atk`、+`maxHp`。替身生命归 0 时干员照常离场。
3. **切换回本体**：替身时间到，开始切换回去：清除 Buff、生命设为最大生命值，切换期间的效果同上，只是阻挡数恢复。切换结束时再清除一次 Buff、生命设为最大生命值，回到本体形态。

阶段是干员身上一个键为 `doll` 的 Buff（值 1 切换到替身、2 替身、3 切换回本体；本体没有这个 Buff），随快照保存。替身的攻击范围、对空、不攻击、光环、伤害类型与减伤见 职业-16；画面上替身的动画见 渲染-24。

4. **技能开始的切换**（技能的 `doll`：`start` 开启时，`end` 结束时）：技能说明可以要求开始同一次切换。阶段、清除、生命重设、时长、标记都同上面的致命伤切换。不是攻击，也不先把生命归 0。
   - **开启时**：某一句里有「立即切换为<替身>」或「并切换为<替身>」（双月二技能「立即使周围的敌人在{anti_invisible_duration}秒内隐匿效果失效并切换为<替身>作战」，结城理三个技能「主动：立即切换为<替身>状态作战」）。开启的那一帧，增益结算之后、本帧其余结算之前开始；这一帧切换的 Buff 不计时，同致命伤切换。这个技能还在运行时，各阶段的清除不结束它，它自己的技能 Buff 是没有结束时间的自身 Buff，所以留着（双月「持续时间内」）；其余 Buff 照常去掉，生命仍设为最大生命值。持续时间不大于 0 的按立即技能，同一帧结束，不当作下次攻击（结城理 blackboard 的 `attack@` 写在「<替身>状态召唤」那一段）。
   - **结束时**：某一句是「技能结束后视为被击倒」（归溟幽灵鲨二技能；PRTS 按实际表现改作「技能结束后立刻切换为<替身>」）。技能按自己的原因结束之后、同一帧、阵亡结算之前开始切换。不造成伤害，生命不先归 0，所以不死、免死、复活和战术点的致命处理都看不到。说明若写成「技能结束后立刻切换为<替身>」或「技能结束后立即切换为<替身>」，同样在结束时切换（这一句里即使还有「立即切换」，也算结束时）。这个技能运行时持有的不死（「技能持续期间内干员的生命值不会低于1」）还没有实现。
   - **已经不在本体**（正在切换，或就是替身）：这次什么都不做。阶段、替身剩余时间、生命都不变。技能本身仍照常开启或结束。
   - 技能因为这次切换而结束，或因为移动、撤退而结束时，不由此再开始一次切换。
   - 「切换为<替身>作战时」是切换已经发生之后的效果，不要求切换（双月一技能）。「召唤<替身>」、只提到替身被击倒之后怎样，也不是这次切换。

### 职业-16 替身的攻击范围、对空与替身天赋

傀儡师的 `doll`（职业-15）还可以带下面几项，由 `@aue/content` 从数据里取（干员-15）：

- **替身的范围**（`range`）：特性 blackboard（含模组的特性部件，干员-7）带 `talent_override_rangeid_flag` 时，取模组特性部件里最后一个已解锁的范围编号，没有时取特性候选（干员-3）的；否则取带这个键的天赋候选（含模组的，干员-15）的范围编号。范围按范围表（干员-8）展开。
  - 替身战斗时（职业-15 的阶段 2），攻击范围换成这个范围，随朝向转动，攻击距离照常拉伸；技能运行时仍照 技能-8。
  - 切换期间和本体形态用自己的范围。
- **对空**（`antiAir`）：有替身范围的替身，普通攻击能选中攻击范围内的飞行单位（职业-1）。干员的召唤物不受影响。
- **法术伤害与减伤**（`arts`、`taken`）：替身战斗时，普通攻击造成法术伤害（技能给了伤害类型时用技能的）；带 `taken` 时，替身受到物理、法术伤害倍率 × `taken`（伤判，伤害-8；在替身阶段的 Buff 上）。
- **不攻击**（`attack` 为否）：替身战斗时持有 `noAttack`（职业-13），不进行普通攻击。
- **光环**（`aura`：`moveMul`、`scale`）：替身战斗时：
  - **减速**：每帧（与 部署-6 同时）给它攻击范围内每个地面敌人（不含飞行的、中立的）一个键为 `doll:<它的 id>` 的 Buff，移动速度最终乘算 ×`moveMul`。离开范围、或替身结束时去掉。
  - **伤害**：替身出现后每满 1 秒（30 帧），对攻击范围内的每个地面敌人按创建顺序各造成一次法术伤害，数值为 `scale` × 它当时的攻击力。这不是攻击，击杀算在干员身上（职业-5）。

数据里有替身范围的：风丸、维荻（x-4）、双月（x-1）、若叶睦（1-1）在特性上；贝娜、归溟幽灵鲨（x-4）在天赋上。结城理的特性有范围编号，但 blackboard 没有这个键，不算。

### 职业-17 模组追加的按目标倍率

带模组时，分支特性还可以带下面几项（由 `@aue/content` 从模组的特性数据或模组自己的数据里取，干员-7）。它们在干员的伤害开始结算之前（伤害-7 之前，`hit` 事件看到的已是乘过的量）、治疗结算之前（伤害-11）对目标逐个判断：

- **按目标的倍率**（`vs`：条件 `when`、攻击倍率 `atk`、伤害倍率 `dmg`、治疗倍率 `heal`）：条件对这次的目标成立时，`atk` 乘在这次伤害的量上（在防御、法抗之前），`dmg` 乘在这次伤害的 `mul` 上（在防御、法抗之后），`heal` 乘在治疗量上。条件：
  - `blocked`：目标被任一单位阻挡着，或它阻挡着单位；
  - `flying`：目标是飞行单位；`skillGround`：干员的技能运行中，且目标不是飞行单位；
  - `hpBelow`：目标的生命低于最大生命值的 `value`；`heavy`：目标的重量等级不低于 `value`；
  - `front`：目标所在格在干员朝向的正前方那一条直线上；`near`：目标在干员所在格或周围 8 格（切比雪夫距离 1 以内）；
  - `burst`：目标处于元素爆发（元素-3）；`onGround`：目标站在地面格（不是高台）上；
  - `skill`：这次伤害是技能的（伤害信息的 `isSkill`，钩子-3；治疗不算）；
  - `elite`：目标是精英或领袖敌人。

  `ep` 乘在干员对目标造成的元素损伤上（元素-2），连同干员的元素损伤倍率 `epDealtMul`（属性-2）。
  
  `noDodge` 为是时，条件成立的物理伤害不可闪避（伤害-8）。几项同时成立时相乘。
- **按距离的伤害倍率**（`far`：`min`、`max`、`dmg`）：干员与目标位置之间的直线距离不超过 `min` 时为 1，从 `min` 到 `max` 按距离线性升到 1 + `dmg`，`max` 及以上为 1 + `dmg`。
- **按范围内敌人数的伤害倍率**（`crowd`：`step`、`cap`）：1 + `step` × min(`cap`, 干员攻击范围内现在的敌人数)；只数在场、有生命、没有消失的敌方单位，飞行的也算。
- **一次攻击的倍率**（`packed`：`cnt`、`atk`）：攻击打到目标时，它的溅射（职业-8）波及的敌人数加上目标本身不少于 `cnt`，这次攻击对目标和溅射目标的各下伤害（含余震）的量都乘 `atk`。

这些倍率只看干员自己造成的伤害与治疗：攻击的每一下（含溅射、跳跃、余震）、技能和天赋的伤害与治疗（行为上下文，技能-6）、部署天赋的治疗都算；无来源的伤害（伤害-7）、生命流失、元素伤害不算，召唤物和其他单位造成的不算。

### 职业-18 模组追加的条件增益

带模组时，分支特性还可以带一组条件增益 `whiles`（由 `@aue/content` 从模组的特性数据或模组自己的数据里取，干员-7）：每项是条件 `when`（有的带数 `value`）和一组修饰器 `mods`。每个干员回合开始时（帧-1 第 7 步，在 职业-10 的阻挡时免疫之后、技能之前），条件成立时干员带一个键为 `while:<序号>` 的 Buff，带这些修饰器；不成立时去掉它。条件：

- `blocking`：阻挡着至少一个有生命的敌人；`notBlocking`：一个也没有；
- `hpAbove`、`hpBelow`：生命高于、低于最大生命值的 `value`（等于时都不成立）；
- 干员**自己的攻击范围**（不按技能改变的范围，技能-8；随朝向转动、按攻击距离拉伸）里在场、有生命、没有消失的单位：`enemies` 至少 `value` 个敌方单位，`groundEnemies` 至少 `value` 个不飞行的，`eliteEnemies` 有精英或领袖敌人，`burstEnemies` 有处于元素爆发的敌人；`allies` 至少 `value` 名别的干员（召唤物不算），`injuredAllies` 有生命未满的友方单位（干员自己和召唤物也算），`epAllies` 有元素值低于上限的友方单位，`skillAllies` 有别的干员的技能在运行；
- `alone4`、`alone8`：干员所在格相邻的 4 格、周围的 8 格上没有别的干员（召唤物不算）；
- `energy`：干员储存着攻击能量（职业-12）；
- `alchemy`：干员投出的炼金单元有一个在场（技能-13）；
- `always`：一直成立（模组追加的常驻修饰器）。

### 职业-20 模组追加的命中附带、技力与光环

带模组时，分支特性还可以带下面几项（由 `@aue/content` 从模组的特性数据、模组自己的数据和模组的类型里取，干员-7）。附带的伤害和元素损伤记在干员名下（行为上下文，技能-6），本身不再引起附带：

- **攻击附带的法术伤害**（`extraArts`）：干员攻击的每一下（含溅射、跳跃，不含余震）打到目标后，目标仍有生命时，再对它造成攻击力 × `extraArts` 的法术伤害。
- **受击附带的法术伤害**（`counterArts`）：敌人的攻击的一下打到干员后，干员仍在场时，对这个敌人造成攻击力 × `counterArts` 的法术伤害。
- **附带的元素损伤**（`epRider`：元素 `el`、比例 `ratio`，`arts` 为是时只看法术伤害）：干员的伤害（攻击、技能、天赋）扣了生命后，对目标造成这一下扣的生命 × `ratio` 的这种元素损伤（元素-2）。
- **爆发中的元素伤害**（`burstHit`：元素 `el`、倍数 `scale`）：干员的伤害打到处于这种元素爆发的目标后，再造成攻击力 × `scale` 的元素伤害。
- **技力**（`spOn`：`on`、`sp`、`every`）：`elite` 时，攻击的一下打到主目标、主目标是精英或领袖敌人；`survives` 时，攻击的一下打到主目标后主目标仍有生命；`catch` 时，每回收 `every` 个回旋投射物（职业-12）——干员的技能得到 `sp` 点技力（技能-2）。回收的计数是干员身上键为 `catches` 的 Buff。
- **付费的攻击力**（`payStack`：`atk`、`max`）：每次特性的费用消耗扣了费用（职业-10），干员身上键为 `payStack` 的 Buff 升一级，攻击力直接乘算 + `atk` × 级数，最多 `max` 级。
- **技能付费的攻击力**（`spendAtk`：`atk`、`max`）：干员的技能开启时付了 n 点费用（技能-10），本次技能期间攻击力直接乘算 + `atk` × min(n, `max`)。
- **光环**（`auras`：对象 `to`、修饰器 `mods`、标记 `flags`）：每帧和 部署-6 的范围天赋同时，给对象一个键为 `mod:<干员 id>:<序号>` 的 Buff，带这些修饰器与标记；不再是对象的、干员不在场的，去掉它。对象：`blocked` 干员阻挡着的敌人，`summonBlocked` 干员自己的召唤物阻挡着的敌人，`range` 有一格在干员攻击范围（攻击-1）里的敌人；都不含中立单位。
- **命中的状态带强度**：特性的 `hitStatus` 可以带强度 `value`（状态-5，如虚弱）。

### 职业-21 模组改的部署、撤退与召唤物

带模组时，分支特性还可以带下面几项（由 `@aue/content` 从模组的特性数据、模组自己的数据和模组的类型里取，干员-7）：

- **首次部署的费用**（`firstCost`）：干员第一次部署之前，部署费用加上它（部署-3），不低于 0。
- **首次撤退的再部署时间**（`firstRetreatRespawn`）：干员第一次撤退（撤退-1）后的再部署时间乘它；以后的撤退照常。卡上记着已经撤退过（`retreated`）。

### 职业-24 天赋的追加

干员数据可以带 `talentTrait`（干员-17…干员-19 读出的天赋的条件增益、按目标的倍率、命中效果和攻击的追加）。干员的特性（职业-1）是它自己的字段盖在默认值上，再加上这些：`whiles`、`vs`、`onHit` 接在特性自己的之后，`extraArts` 和特性的相加，`targets` 比特性的（是数时）多时取它。带 Stronghold 兼容 kit 的干员没有这些（kit 自己实现天赋，兼容-6）。

条件增益（职业-18）另有这些条件，同样在干员回合开始时判断：

- `blockingAtLeast`：阻挡着至少 `value` 个有生命的敌人；
- `lowHpEnemies`：干员自己的攻击范围里有生命低于最大生命值 `value` 的敌方单位；
- `burstEnemies` 带元素 `el` 时只看处于这种元素爆发的；
- 干员所在格和相邻的 4 格（曼哈顿距离不超过 1）上：`noEnemies4` 没有在场、有生命、没有消失的敌人（只数敌人，装置与召唤物不算），`soleEnemy4` 正好一个，`aloneUnits4` 没有别的友方单位（干员和召唤物）；
- `notInSkill`：干员的技能没有在运行。

按目标的倍率（职业-17）另有这些条件和效果：

- `unblocked`：目标没有被任何单位阻挡、也没有阻挡单位（`blocked` 的反面）；`notOwnBlocked`：目标不是被这名干员阻挡；
- `hpAbove`：目标生命高于最大生命值的 `value`；`light`：目标的重量等级不超过 `value`；
- `tag`：目标是带标签 `tag` 的敌人（关卡-1）；`rangedFoe`：目标是攻击方式为远程的敌人；`status`：目标带着标记 `status`（状态-5，如战栗的 `disarmedCombat`）；
- `defFlat`、`defPct`：条件成立的这一下伤害再加这么多无视防御、物理穿透（伤害-1，和来源的相加）。

**命中效果**（`onHit`）：干员攻击的每一下（含溅射、跳跃，职业-4 的状态之后）打到仍有生命的目标后，按顺序：带 `first` 的只对每个敌人第一次——目标带上键为 `seen:<干员 id>:<序号>`、没有持续时间的 Buff，已带着就跳过；带几率 `prob` 的抽一次随机数（随机-1），不小于它就跳过；然后给目标状态（状态-5，带强度），或带修饰器、持续这么多秒的 Buff（键 `talentHit:<干员 id>:<序号>`，再次命中时重新计时，同一来源不叠加）。

- 来源：干员-17…干员-19；接在特性之后、每一下结算为推断 INF-0254

### 职业-25 天赋的叠加、技力、坚忍与持续伤害

`talentTrait`（职业-24）还可以带叠加 `stacks`、技力 `talentSp`、坚忍 `grit`、光环 `auras` 和一次攻击的倍率 `packed`（干员-19…干员-23），接在特性自己的之后（坚忍取天赋的，`packed` 只在特性没有时取天赋的）。

- **叠加**：每个事件——干员的攻击或技能击杀敌人（职业-5；`summons` 的也算它的召唤物的击杀），或干员的伤害扣了敌人的生命（职业-9 的那一下，无来源、生命流失除外；`phys` 的只算物理伤害）——干员身上键为 `stack:<序号>` 的 Buff 记一次（`n`），级数为 ⌊次数 ÷ `every`（没有时 1）⌋，至多 `max`；修饰器是一级的修饰器按级数放大（乘的为 1 + (值 − 1) × 级数，其余 × 级数）。带 `seconds` 的，这个 Buff 从这次起持续这么多秒，到时整个去掉。
- **没有击杀**：条件增益 `noKills`（职业-18）在干员这次部署以来还没有击杀过敌人时成立；有这种条件的干员的击杀计在键为 `kills` 的 Buff 上。
- **技能的开启次数**：有 `fewStarts` 或 `laterSkill` 条件的干员，技能每次开启（技能-3）计在键为 `starts` 的 Buff 上；`fewStarts` 在次数少于 `value` 时成立，`laterSkill` 在技能运行中且次数至少为 2 时成立。
- **按敌人数**：带 `per` 的条件增益（`enemies`）每个回合按干员自己攻击范围里在场、有生命、没有消失的敌方单位数 n（至多 `per`）给 `while:<序号>` 的 Buff，修饰器 × n；n 为 0 时没有这个 Buff。条件增益也可以带标记（如迷彩 `camou`）。
- **技力**（技能-2，按阻回，技能运行中不加）：`attack`——干员的攻击落下、打到了敌人（不是治疗）；`kill`——击杀时；`heal`——攻击的每一次治疗（职业-2）给被治疗的单位；`attacked`——敌人的攻击的一下扣了干员的生命后，给它自己，再给它所在格和相邻 4 格上随机一个友方单位（干员或召唤物，可以是它自己；抽一次随机数，随机-1）；`enemyDown`、`allyDown`——帧末离场的单位（伤害-9，到达终点的除外）有一格在干员攻击范围里、是敌人或别的干员（召唤物除外）时，给它自己，`other` 再给它攻击范围里随机另一个友方单位；`skillEnd`——技能结束时（技能-4）带 `heal` 的先治疗自己 `heal` × 最大生命值（伤害-11），带 `share` 的抽一次随机数，小于 `prob` 时技力消耗 × `share`（向下取整）；`skillKills`——技能运行中的击杀计在键为 `skillKills` 的 Buff 上，技能结束时给 次数 × `sp`（至多 `max`），并去掉计数。
- **坚忍**：干员回合开始时（条件增益之前），键为 `grit` 的 Buff 带最多的修饰器 × min(1, 已损失的生命比例 ÷ `full`)。
- **持续伤害**：命中效果（职业-24）带 `dot` 的，目标带上键为 `dot:<干员 id>:<序号>` 的 Buff，持续这么多秒，每秒（从 1 秒起）受到一次法术伤害：`amount`，或命中时干员攻击力 × `scale`；伤害无来源（伤害-7），击杀记在干员名下（干员已离场时不记）。持续期间再次命中只重新计时，伤害数值不变。带 `when` unblocked 的只给没有被阻挡的目标。
- **光环** `blockedAll`（职业-20）：场上被任何单位阻挡着的敌人。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-26 天赋的时间

`talentTrait`（职业-24）还可以带下一次攻击 `nextAttack`（接在特性自己的之后）、倍率随间隔 `rhythm`、一段时间不攻击后的屏障 `idleShield`（干员-24，取天赋的）。

- **记录**：部署时（职业-4），特性用得到的，干员带上这些键的 Buff（没有结束时间，不影响属性），`n` 记一帧（−1 为还没有）：`lastAttack` 它的攻击上一次结束（攻击-2 落下）的帧，`lastSwing` 上一次开始的帧，`lastHurt` 上一次一下伤害扣了它生命的帧（生命流失除外），`lastJudged` 上一次一下伤害的伤判开始的帧（伤害-8：闪避、抵挡、命中率落空的也算，生命流失除外）；`dodges` 的 `n` 是闪避（和落空）还没有用掉的次数，从 0 起。
- **按时间的条件**（职业-18 的条件增益）：`idle`、`unhurt`、`calm` 分别在 `lastAttack`、`lastHurt`、`lastJudged` 距今至少 `value` 秒时成立；还没有记录时从部署算起，带 `fresh` 的直接成立。`highSide`：干员身后和两侧的格（朝右时为左、上、下，随朝向转动，方向-2）是高台（`HIGHLAND`）的至少 `value` 格。
- **下一次攻击**：干员的攻击开始时（攻击-1，在 攻击-4 的几率天赋之后；攻击-5 的也算），每一项条件成立的（`idle` 同上；`dodged` 为还有没用掉的闪避）：倍率 × `scale`，攻击力直接乘算 + `atk`（只这一次），每一下晕眩 `stun` 秒，命中数 × `times`，`blocked` 时目标是它阻挡的所有敌人（至多阻挡数）；有 `dodged` 的项成立时用掉一次闪避。然后，带 `rhythm` 的倍率再 × 1 + (`top` − 1) × k，k = (距上次攻击开始的帧数（没有时从部署算） − (`min` × 30 + 1)) ÷ ((`max` − `min`) × 30)，限制在 0–1。最后记下这次开始的帧；攻击落下时记下结束的帧。
- **一段时间不攻击后的屏障**：部署时开始等待（键 `shieldWait` 的 `n`）。干员回合开始时，带着这个屏障（键 `idleShield` 的 Buff，事件优先级 −1000，屏障量为当时最大生命值 × `share`，用完移除，伤害-8）时等待从这一帧重新开始；没有时，等待开始和上次攻击结束两者中较晚的一个距今满 `value` 秒，就获得它。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-27 天赋的生命

`talentTrait`（职业-24）还可以带低血时回复 `lowHp`、护盾层数 `layers`、最后的坚持 `lastStand`、冻结的生命 `frostLife`、用费用换生命 `costLife`、受击 `hurt`、反伤 `reflect`（干员-25，取天赋的），以及免死 `secondLife`（职业-22，特性没有时取天赋的）。

- **低血时回复**：部署时带键为 `lowHp`、标记不死（`undying`，伤害-9）的 Buff。干员回合开始时（坚忍之后，职业-25）生命低于最大生命值的 `below`、还带着它时，去掉它，治疗自己 `heal` × 最大生命值（伤害-11），此后带 `mods`（键 `lowHpAfter`，这次部署一直带着）。
- **护盾层数**：部署时带键为 `layers` 的 Buff，`init` 层护盾（伤害-8；层数用完也不移除），等待从部署开始（键 `layersWait`）。干员回合开始时，比上个回合少了几层就各治疗一次 `heal` × 最大生命值；等待满 `every` 秒时重新开始，层数少于 `max` 时加一层。
- **生命归 0 时**（这一帧末，伤害-9；在免死之后）：
  - 最后的坚持：这次部署第一次，生命设为 1，带 `seconds` 秒的不死和禁疗（键 `lastStand`）；时间到了还在场就撤退（撤退-1：返还部署费用、再部署惩罚照常）。
  - 冻结的生命：这次部署第一次（键 `frostLife`），生命设为最大生命值 × `hp`，自身冻结 `self` 秒（敌方的冻结，不降法术抗性，状态-5），攻击范围里有一格的每个敌人冻结 `foes` 秒。
  - 用费用换生命：所需费用为 `cost` × `mul` 的（这次部署已换过的次数）次方，玩家的费用够时扣掉（键 `costLife` 记次数），生命设为最大生命值 × `hp`。
- **受击**（读干员数据的 `talentTrait.hurt`）：一下伤害的伤判开始时（伤害-8；闪避、抵挡、命中率落空的也算，生命流失除外），带 `heal` 的，生命低于最大生命值的 `below` 时治疗自己 `high`，否则 `low`；带 `status` 的，伤害来源是有生命、不无敌、不隐匿、可以选中的敌人时，给它这个状态这么多秒。
- **反击与反伤**：敌人的攻击的一下打到干员时（闪避的也算），特性的 `counterArts`（职业-20）加上它 Buff 的 `counterArts`（相加：条件增益的）大于 0 时，对攻击者造成 攻击力 × 这个值 的法术伤害；然后场上每个带 `reflect`、这名干员有它的势力（干员-10）的干员，对攻击者造成 自身攻击力 × `scale` 的真实伤害（击杀记在它名下）。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-28 对敌人的天赋

### 职业-29 元素的天赋

`talentTrait`（职业-24）还可以带回应爆发 `burstOn`、脉冲 `pulses`、麻痹打断时的元素伤害 `palsyHit`、命中回复元素 `epOnHit`、治疗后的增益治疗 `healDot`（干员-28，取天赋的；前两个是列表，接在特性自己的之后），叠加（`stacks`，职业-25）还可以是 `burst`，目标倍率（`vs`）还可以带下面的条件和效果；条件增益（职业-18）还可以是 `fieldOps`：场上有生命的干员（不含召唤物）至少 `value` 名。

- **回应爆发**：敌人的元素爆发开始时（`burstStart`，元素-3），场上每名有生命的干员依次：它的每条这种元素的 `burstOn`——`field` 的不看位置，`range` 的要敌人有一格在它攻击范围里（不论可选性）——对敌人造成 攻击力 × `dmg` 的元素伤害（附带伤害，职业-20），并治疗它自己 `heal` × 最大生命值（无视禁疗，伤害-11）；然后敌人在它攻击范围里时，它这种元素的每条 `burst` 叠加加一层。
- **爆发期间的元素伤害**：`burstOf` 的条件是目标在 `el` 的爆发中；带 `post` 的在命中后（职业-28 的命中后效果之前）判断，所以使目标爆发的这一下也算。目标带键为 `burstDot:<干员 id>` 的 Buff（已有时取较高的倍率），每 1 秒受到 干员攻击力 × 倍率 的元素伤害（不计来源）；目标不在这种元素的爆发中、或干员不在场时，这个 Buff 去掉。
- **损伤持续**（`epDot`）：命中后立即造成一次 攻击力 × `scale` 的这种元素的损伤，然后 `seconds` 秒内每 1 秒一次（键 `epDot:<干员 id>`，已有时重新计时）；干员不在场时不造成。
- **脉冲**：干员回合开始时，部署后每满 `every` 秒，对它阻挡的敌人（`blocked`）、或有一格在它攻击范围里且可以选中的敌人（`range`，迷彩、飞行不论，索敌-2）：先造成 攻击力 × `ep.scale` 的这种元素的损伤，再造成 攻击力 × `arts` 的法术伤害（不计来源），再施加 `status` 的状态。
- **麻痹打断**：敌人的攻击被麻痹打断时（状态-8），场上每名攻击范围里有它一格的干员，对它造成 攻击力 × `palsyHit` 的元素伤害（附带伤害）。
- **命中回复元素**：干员的攻击落下、到达了敌人时（治疗的攻击除外），回复自己的元素值 `epOnHit` × min(到达的敌人数, 阻挡数，至少 1)（职业-12 的回复）。
- **治疗后的增益治疗**：干员普通攻击的治疗每治疗一名单位（职业-2），它带上键为 `healDot:<干员 id>` 的 Buff，`seconds` 秒，每 1 秒按层数各一次：治疗 当时干员攻击力 × `share`，回复元素值 这个量 × 干员特性的 `epHeal`；有禁疗时都没有。已有时加一层（至多 `max`），重新计时，量按这一次。
- **离场**：干员离场时，它留下的 `burstDot`、`epDot` 一并去掉（职业-28）。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-30 部署与技能的天赋

`talentTrait`（职业-24）还可以带开局费用 `startCost`、减费 `costCuts`、撤退后的减费 `retreatCut`、部署时的减费 `deployCut`、费用回复的倍数 `costRate`（这几项按 部署-10 生效）、独自部署的费用 `aloneCost`、部署时的技力 `deploySp`、回应技能 `allySkill`、技力脉冲 `spPulse`、攻击时的受击回复 `hurtAttackSp`（干员-29，取天赋的）；它的首次部署的费用 `firstCost` 加到特性自己的上；条件增益（职业-18）还可以是 `firstDeploy`：干员是第一次在场（它的卡还没有记录）；天赋的技力（职业-25）还可以是 `firstSkillEnd`。

- **部署时**：干员部署时（部署天赋之后、携带单位的效果之前，部署-8；移动 也算，但不是第一次部署，部署-9）依次：`deploySp` 里 `self` 的给自己 `sp`（带 `first` 的只在第一次部署时），`field` 的给场上其他每名这个职业的干员 `sp`；场上其他每名干员的每条 `arriving`，它是这个职业时给它 `sp`；有 `aloneCost` 而它上下左右 4 格没有其他干员（召唤物不算）时，它的玩家获得这么多费用（不超过上限）。技力按 技能-2 加。
- **回应技能**：一名单位的技能开始时（技能-3，含部署时发动的被动技能），场上每名特性有 `allySkill` 的干员，攻击范围里有它的格子时（自己的格子在范围里时也算自己）：获得 `sp` 技力（无视阻回），并带上键为 `allySkill` 的 Buff，`seconds` 秒、修饰器 `mods`；已有时只重新计时。
- **第一个技能**：干员的技能开始时，它有 `firstSkillEnd` 的技力、而它的玩家这场战斗里还没有记下这张卡时，记下（玩家的 `once`），它带上键为 `firstSkill` 的 Buff。技能结束时（技能-4）不是被关闭的（`stopped`，技能-7），有这个 Buff 就获得 `sp` 技力（无视阻回）并去掉它；被关闭时留着，到下一次结束。干员离场时 Buff 随它离开，以后的技能不再有。
- **技力脉冲**：干员回合开始时，部署后每满 `every` 秒，场上每名这个职业、技能是攻击回复的干员（任何玩家的）获得 `sp` 技力（技能-2）。
- **攻击时的受击回复**：干员的攻击落下、到达了单位时，它的技能是受击回复的，获得场上各干员 `hurtAttackSp` 中最大的那么多技力（技能-2；有阻止受击回复的标记时没有）。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-31 自身、治疗与部署的其他天赋

`talentTrait`（职业-24）还可以带部署时随机的增益 `deployPick`、敌人倒下时回血 `downHeal`、部署时的增益 `deployBuff`、全场回复 `fieldRegen`、治疗留下的效果 `healGives`、低地上的元素回复倍数 `groundEpHeal`、可以选中隐匿的敌人 `seeStealth`、伤害保底 `minDamage`、部署时的晕眩 `deployStun`、部署时的冲击 `deployBlast`（干员-30，取天赋的）；天赋的技力（职业-25）还可以是 `dealt`；条件增益（职业-18）还可以是下面这些：

- `hpNotBelow`：生命不低于最大生命值的 `value`；
- `neverHurt`：这次部署以来没有受到扣除生命的伤害（职业-26 的记录）；
- `stealthEnemies`：自己的攻击范围里有隐匿的敌人；
- `skillOrAfter`：技能运行中，或技能结束后不到 `value` 秒（记录技能结束的帧）；
- `lowSp`：技能没在运行，且技力不超过技力上限的 `value`；
- `enemiesNear` / `fewEnemiesNear`：自己的格子和周围 8 格上有生命的敌人至少 / 少于 `value` 名。

效果：

- **部署时**（职业-30 的部署效果之后）：`deployPick` 抽一个随机数（随机-1）选其中一项，作为键为 `pick` 的 Buff，没有持续时间；`deployBuff` 给场上每名这个职业的干员（包括自己、任何玩家的）键为 `deployBuff:<干员 id>` 的 Buff，`seconds` 秒（已有时重新计时）；`deployStun` 取干员普通攻击会选的第一个目标（索敌-1），它和与它距离不超过 `radius` 的、隐匿未生效的敌人晕眩 `seconds` 秒（迷彩不论，索敌-2），没有目标时什么也不发生；`deployBlast` 对自己格子和上下左右 4 格上隐匿未生效的敌人（迷彩不论，索敌-2）造成 攻击力 × `scale` 的真实伤害——玩家上一名部署的干员有 `again` 势力时再造成一次——然后晕眩 `stun` 秒。卡组里有带 `deployBlast` 的干员时，玩家部署干员（建造者不算）后记下这名干员（玩家的 `last`）。
- **敌人倒下**（伤害-9，职业-25 之前）：场上每名带 `downHeal` 的干员，敌人在它的格子或周围 8 格（`around`）、或被它阻挡（`blocked`）时，治疗自己 `share` × 最大生命值（无视禁疗，伤害-11）。
- **造成伤害**：干员的伤害扣除了敌人的生命时（职业-9 的那一步），每条 `dealt` 抽一个随机数，小于 `prob` 时获得 `sp` 技力（技能-2）。
- **治疗**（职业-2）：元素回复再乘 `groundEpHeal`（目标在低地格上时）；它的任何一次治疗（职业-33 的治疗钩子），带 `healGives` 的给目标键为 `healGives:<干员 id>` 的 Buff，`seconds` 秒——治疗前的生命比例高于 `above` 时 `aboveSeconds` 秒——已有时重新计时。
- **全场回复**：干员在场时，每名友方单位（任何玩家的）带键为 `fieldRegen:<干员 id>` 的光环 Buff，生命回复速度 + `fieldRegen` × 干员攻击力（部署-5 的光环更新）。
- **伤害保底**：干员攻击的伤害（伤害-7 第 5 步之后）不低于 攻击力 × `scale`；有 `front` 且目标在干员的格子或朝向前方的两格上时用 `front`。

- **攻击能量的倍率**：储存的攻击能量（职业-12）释放时，每份的攻击力 × `energyScale`。
- **敌人种类与种类记录**：干员击杀敌人时（职业-5），带 `kindStack` 的记下这种敌人（数据的键，`kind:<键>` Buff），层数为记下的种类数（`kinds` Buff，至多 `max`）；带 `slainKinds` 的，玩家的 `slain` 记下这张卡击杀过的种类（离场后也保留）。目标倍率 `slainKind`：目标的种类在记录里。被击杀的敌人有重伤时，击杀者获得重伤的值那么多技力（技能-2）。
- **技能开始的一击**：技能开始时（职业-25 的开始处理），对普通攻击会选的第一个目标造成 `scale` × 攻击力的物理伤害（计入击杀），再施加 `cold` 秒寒冷。
- **消耗费用的增益**：干员部署时（不含移动），以及开始一个要消耗费用的技能（技能-10）时，加一层（`spendBoost` Buff，至多 `max`），攻击范围里的地面敌人晕眩 `stun` 秒。
- **状态的叠加**：内容里有这种叠加时挂上 `beforeStatus` 处理函数（职业-33）：干员要对敌人施加这种状态、敌人不免疫时，加一层。
- **停留的脆弱**（部署-5 的光环更新）：攻击范围里的敌人进入时记下帧（`stay:<干员 id>` Buff，离开时去掉），带键为 `stayVuln:<干员 id>` 的光环 Buff：受到伤害倍率 × `base`，停留满 `after` 秒后 × `max`。
- **连击**：技能不运行时，干员的伤害扣除了敌人生命时计数加 1——离上次计数超过 `gap` 秒的从 0 起——，到 `hits` 时加一层（`comboStack` Buff，至多 `max`）、计数归 0。技能开始时、干员晕眩、冻结或缴械时计数归 0。
- **不致命**：干员对敌人的伤害至多使它剩 1 点生命（伤害-7）；伤害之后敌人生命不超过 1、还没有重伤时，施加重伤（状态-5）`seconds` 秒，值为 `sp`。
- **满蓄力的附加**：干员的伤害（附带伤害除外）之后，它的蓄力（职业-12）达到 `steps` 层时，对目标造成 `chargedRider` × 攻击力的物理附带伤害。
- **增长的几率**：敌人倒下时，场上每名几率天赋带 `grow` 的干员，敌人在这个势力的某名干员所在格或上下左右 4 格上时，计数加 1（`critGrow` Buff）。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。

### 职业-35 限时与场上的其他天赋

`talentTrait`（职业-24）还可以带场上的目标倍率 `fieldVs`、强化攻击 `powerAttacks`、定时的冲击 `timedBlast`、首次阻挡 `firstBlock`（干员-34，取天赋的）；场上的增益（职业-32）可以带 `during`（来源这次部署未满这么多秒时才给）；命中效果（职业-24）可以带 `during`（同上，按干员自己）和元素损伤 `ep`（这种元素、这么多点，元素-2）；优先攻击（职业-28）可以是没有这名干员的命中标记的敌人（`lacksHit`，可带 `during`）；目标倍率还可以是 `hpRatioAtMostOwn`（目标的生命比例不高于攻击者的）。

- **场上的目标倍率**：干员计算对目标的倍率时（职业-17），场上每名（任何玩家的，含它自己）带 `fieldVs`、势力是它的势力之一的干员，它的倍率也计入。
- **强化攻击**：干员这次部署第一次开始技能时（职业-34 的开始处理），带上键为 `powerAttacks` 的 Buff，值为 `count`，攻击倍率 × `scale`；之后每次攻击开始（选定目标时）值减 1，到 0 时去掉。
- **弹药的几率**：带 `ammoProb` 的几率天赋，技能开始时记下当时的弹药（`ammoStart` Buff）。
- **定时的冲击**：每帧干员的回合之后，部署后正好满 `after` 秒的干员，对自己格子和周围 8 格上隐匿未生效的敌人（含空中，迷彩不论，索敌-2）造成 `scale` × 攻击力的物理伤害（计入击杀），再施加 `fragile` 的脆弱，然后撤退（撤退-1，照常返还费用）。
- **首次阻挡**：干员回合开始时，这次部署还没有触发过、而它正阻挡着敌人时，取其中 id 最小的一个：玩家获得 `cost` 费用（不超过上限），它沉睡 `sleep` 秒（来源是干员），并记下（`firstBlock` Buff）。干员离场时，它施加的沉睡全部去掉。

带 Stronghold 兼容 kit 的干员没有这些（兼容-6）。
