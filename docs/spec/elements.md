# 元素

实现见 `packages/sim/src/elements.js`。麻痹见 状态-8，阻回、静默、元素免疫见 状态-9。

### 元素-1 元素值

元素有五种，按 id 排列：

| id | 键 | 损伤名称 |
|---|---|---|
| 1 | `SANITY` | 神经损伤 |
| 2 | `WATER` | 侵蚀损伤 |
| 3 | `FIRE` | 灼燃损伤 |
| 4 | `DARK` | 凋亡损伤 |
| 5 | `ANGER` | 狂躁损伤 |

- 每个单位的每种元素各有一个元素值，初始为最大元素值。
- **最大元素值**是一项属性（属性-3，前缀 `maxEp`）。基础值取内容给出的值；没有给出时，领袖级敌人（levelType 为 BOSS）为 2000，其余单位为 1000。
- 元素值不会自然恢复。
- 单位只记录低于最大值的元素值；没有记录的元素值就是最大值。

- 来源：[PRTS「元素」oldid=430495](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=430495)：元素类型表（ID、内部 ID、损伤名称），「每种不同的元素单独记录一份元素值，且初始为最大值」，「默认的最大元素值（MAX_EP）为1000，每秒元素值恢复（EP_RECOVERY_PER_SEC）为0」，「对于领袖级的敌人类单位，实际最大元素值（与其属性上限）变为2000」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)：「普通、精英敌人1000点、领袖2000点累计值」；最大元素值没有上限为推断 INF-0040

### 元素-2 元素损伤

单位受到 A 点某种元素的元素损伤时：

1. 不受影响的情况：单位生命为 0、无敌（无敌、沉睡，状态-5）、已消失（路线-4）、处于元素免疫（状态-9），或正在爆发（元素-3），或起飞且来源是行动方式为地面的敌人或未浮空的敌对装置（阻挡-2）。这时什么都不发生。没有来源的元素损伤照常结算。判定在 `elementHit` 之前做一次。
2. 发 `elementHit` 事件（钩子-3）：处理函数可改量 A、乘上倍率，或取消这次元素损伤；之后单位又变为不受影响的，也什么都不发生。
3. 受到的量（这里的 A 是事件之后的量乘倍率）：损伤抵抗 D 为 0 时是 A；D 大于 0 时是 max(0.05A, A × (1 − 0.01D))。再乘受到元素损伤倍率 `epTakenMul`（属性-2 的乘区），以及这种元素自己的受到倍率 `<元素>TakenMul`（如 `DARKTakenMul`，同样是乘区，职业-29）。
4. 这种元素的元素值减去受到的量，不低于 0。降到 0 时，这种元素爆发（元素-3）。

攻击附带的元素损伤，在这次攻击的每一下伤害之后结算：先伤害，再元素损伤。技能的攻击修正可以带一种元素和每下的元素损伤（技能-5、技能-6）。

**元素回复**：每帧，场上有生命、元素值没有全满的单位，按它的元素回复速度——`epRegen` 加 `epRegenRatio` × 最大生命值（两者都是加算，职业-29）——÷ 30 回复元素值，规则同 职业-12 的回复（爆发期间不回复，回到最大值的不再记录）。干员造成的元素损伤（攻击附带的、行为上下文的、模组附带的，职业-20），A 先乘它的元素损伤倍率 `epDealtMul` 与特性对目标的元素倍率（职业-17）。

- 来源：[PRTS「元素」oldid=430495](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=430495)：「受到的元素损伤=损伤值×(1-损伤抵抗×0.01)，后续可应用元素损伤倍率提升/降低等效果」，「实体受到元素损伤时会扣除元素值」，「攻击直接附带的元素损伤紧接在当次攻击的伤害后处理」；[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)「损伤公式」：损伤抵抗为 0 时 EDMG = A，大于 0 时 EDMG = max[0.05A, A(1 − 0.01D)]；[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606)：无敌「受到的伤害与元素值变为0」，元素免疫「元素值不会损失」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 元素损伤：「受到附加元素损伤的伤害时先结算伤害后结算元素损伤」；消失时不受元素损伤为推断 INF-0036

### 元素-3 爆发

- **开始**：某种元素的元素值降到 0 时，这种元素爆发：先发 `elementBurst` 事件（钩子-3；处理期间这个单位不受元素损伤；之后单位生命为 0 或已在爆发的，元素值回到最大值，不再继续），然后单位得到一个爆发 Buff（键 `burst:<元素>`），持续时间是这种爆发的时间（元素-4），按帧计（时间-2），衰减率固定为 1。产生表现事件 `burst`（事件第 3 版，字段 id 和元素 id）。然后是爆发的即时效果（元素-4），最后发 `burstStart` 事件（钩子-3；回应爆发的天赋在这里生效，职业-29）。
- **爆发冷却**：爆发 Buff 存在期间，单位所有元素的元素值都不再变化。同一时刻有几种元素将要爆发时，最先降到 0 的那种爆发，其余的不再受到损伤。
- **结束**：爆发 Buff 到期时，单位所有元素的元素值回到最大值。
- **伤害**：爆发造成的伤害没有来源（不吃任何单位的伤害倍率和穿透），不能被闪避。

- 来源：[PRTS「元素」oldid=430495](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=430495)：「当元素损伤令某一项元素值降低至0时，会触发相应的元素爆发」，「元素损伤爆发开始时会立刻给予单位相应的效果，随后进入爆发冷却状态」，「爆发冷却状态下，单位所有类型的元素值均无法损失、无法被其他手段回复」，「元素爆发结束时，爆发冷却也将一并结束，随后单位所有种类的元素值恢复至最大值」，「实际发生元素损伤爆发的元素取决于首个施加的元素损伤」，「元素爆发通常造成无来源的伤害」；不能被闪避为推断 INF-0037

### 元素-4 各元素的爆发效果

干员（角色类单位）受到「我方」一列的效果，其余单位受到「其他」一列的效果。表中「然后」之后的伤害在前面的效果之后结算。

| 元素 | 时间（我方 / 其他） | 我方 | 其他 |
|---|---|---|---|
| 神经 | 10 秒 / 10 秒 | 晕眩，持续爆发时间；然后 1000 点真实伤害 | 没有麻痹免疫时，施加 3 次 1 层麻痹（状态-8）；然后 6000 点元素伤害 |
| 侵蚀 | 10 秒 / 8 秒 | 防御力 −100（直接加算），永久，可无限叠加；然后 800 点物理伤害 | 防御力 −120（直接加算），永久，可无限叠加；然后 5000 点元素伤害 |
| 灼燃 | 10 秒 / 10 秒 | 爆发期间法术抗性 −20（直接加算）；然后 1200 点法术伤害 | 爆发期间法术抗性 −20（直接加算）；然后 7000 点元素伤害 |
| 凋亡 | 15 秒 / 15 秒 | 阻回、静默，持续爆发时间；每秒失去 1 点技力，受到 100 点法术伤害 | 50% 虚弱（状态-5），持续爆发时间；每秒受到 800 点元素伤害，虚弱降为 50% × 剩余时间 ÷ 爆发时间 |
| 狂躁 | 15 秒 / 15 秒 | 爆发期间攻击速度 +50（直接加算）；每秒受到 X 点真实伤害 | 没有效果（仍有爆发冷却） |

- **永久的防御力降低**：一个键为 `erosion` 的叠层 Buff，没有结束时间，不会因爆发结束而移除。
- **每秒**：爆发 Buff 每 30 帧触发一次（状态-4），第一次在爆发开始 30 帧后。凋亡的「剩余时间」取这次触发之后的剩余帧数。
- **狂躁的 X**：X = min(600, 100 + 50n)，n 是爆发开始后单位进行的攻击次数。一次攻击打多个目标或多下也只算一次。
- **来源**：爆发的来源是令元素值降到 0 的那次元素损伤的来源（没有则为无），记在爆发 Buff 上。爆发造成的伤害是记在它名下的无来源伤害（伤害-7 的 `sourceless`：事件里没有来源，击杀记给它），施加的状态以它为来源；每秒的伤害在它已不在场时为无来源。

- 来源：[PRTS「元素」oldid=430495](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=430495) 元素类型表的「元素损伤爆发」各列（持续时间、我方角色类单位受到的效果、其他单位受到的效果），以及「变动后敌人类单位无论阵营，损伤爆发时均使用"敌方单位受到的爆发效果"」；狂躁「X初始为100，每次触发狂躁时+50，上限为600」「多连击通常计为一次」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)：灼燃「法术抗性降低先于伤害生效」，神经·我方「"获得3层麻痹"实为获得3次1层麻痹」，凋亡·我方「虚弱的数值每秒更新一次」，狂躁「每次攻击时提升50，最多600」；狂躁按攻击计、晕眩可被抵抗缩短、敌人狂躁仍有冷却为推断 INF-0038；同页「元素爆发通常造成无来源的伤害，但是元素爆发本身来源于造成"爆条"的元素损伤的来源」

### 元素-5 当前损伤元素

单位的当前损伤元素：低于最大值的元素中，元素值最低的那种；元素值相同时取 id 小的。没有低于最大值的元素时，没有当前损伤元素。它只用于显示和部分索敌（行医），不决定爆发。显示见 界面-20。

- 来源：[PRTS「元素」oldid=430495](https://prts.wiki/index.php?title=%E5%85%83%E7%B4%A0&oldid=430495)「当前损伤元素」：「游戏会根据当前相应元素值最低>元素ID的顺序实时更新单位的当前损伤元素」，「当前损伤元素仅仅是当前最低的元素，不代表实际发生元素损伤爆发的元素」
