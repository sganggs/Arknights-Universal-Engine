# 敌人能力

敌人的天赋和技能。引擎提供钩子、延时爆炸和直击弹道（`packages/sim/src/foes.js`），各项能力的行为由内容按能力名提供（`packages/content/src/foes.js`），数值取自敌人数据，数据里没有的参数取自 PRTS 的敌人资料。

### 敌能-1 能力数据与普通攻击的伤害类型

- **天赋**：敌人数据的 `talentBlackboard` 按键名第一个 `.` 之前的部分分组，每组是一项天赋（如 `boom.atk_scale`、`boom.freeze` 是天赋 `boom` 的 `atk_scale` 和 `freeze`）。
- **技能**：敌人数据的 `skills`，每项有名字（`prefabKey`）、初始冷却（`initCooldown`）、冷却（`cooldown`）、技力消耗（`spCost`，记作 `sp`，没有为 0）和 blackboard。
- **伤害类型**：普通攻击的伤害类型取敌人图鉴（`enemy_handbook_table`）的 `damageType` 的第一项：`PHYSIC` 物理、`MAGIC` 法术，其余按物理。
- 内容按天赋名和技能名给出行为；没有行为的天赋和技能不起作用。

- 来源：数据：enemy_database 的 talentBlackboard、skills；enemy_handbook_table 的 damageType；[PRTS「重弩突袭者」oldid=437074](https://prts.wiki/index.php?title=%E9%87%8D%E5%BC%A9%E7%AA%81%E8%A2%AD%E8%80%85&oldid=437074)「技能0初始=2」「技能0消耗=8」与数据的 initCooldown、cooldown 对应；按前缀分组、取第一项伤害类型为推断 INF-0068

### 敌能-2 钩子

敌人能力的行为在这些时刻起作用，只能通过上下文作用（技能-6 的上下文，另加下列成员）：

| 钩子 | 时刻 |
|---|---|
| `spawn` | 敌人出现时 |
| `tick` | 敌人每帧的回合开始时（敌人攻击-1 之前）；此时能知道上一帧以来它是否受过伤害、是否刚被解除阻挡 |
| `targets` | 敌人要选攻击目标时，可以换掉候选（如远程与近战的切换） |
| `attack` | 敌人开始一次攻击时，可以改攻击的倍率、伤害类型、溅射、目标数 |
| `cancelHit` | 普通攻击的主命中结算前（溅射、连锁、余波不算）：返回真则这一下取消，不造成生命伤害、不造成元素损伤、不结算命中附带（敌能-49） |
| `death` | 敌人被击倒时（走到终点离场不算） |
| `fatal` | 敌人生命归 0、帧末离场之前（伤害-9）：返回真且已把它的生命设为大于 0 时，它留在场上，不算被击倒 |
| `unbalanceEnd` | 失衡在这一帧的回合里结束之后（位移-3，含被浮空结束）：这一帧的 `tick` 仍看得到失衡，滑行结算之后才调用 |
| `landed` | 普通攻击的一次命中连上时（造成的生命损失可以是 0；这一下是技能时也到这里。溅射不到。敌能-46） |
| `hpDamage` | 一次伤害走完伤判、还剩伤害、扣生命之前（钩子-3 的 `hpDamage`）：每一下调用一次，这一下的数值已经定了。伤判里被闪避、抵挡、护盾或屏障吸完的，以及在伤判之前就停掉的，不到这里。`hurt` 仍是上一帧以来生命是否下降，不是按这一下 |

敌人能力的上下文另有：`state`（这个敌人自己的能力状态，按名字存数）、`blocked`（是否被阻挡）、`unbalanced`（这一帧的回合开始时是否处于失衡，位移-3，只读）、`hurt`（上一帧以来是否受过伤害）、`taken`（累计受到的、会计入受击回复的伤害次数，从它的能力第一次读取时开始计；没有能力读取的敌人不计，敌能-38）、`unblocked`（是否刚解除阻挡）、`foes(radius)`（半径内可以攻击的我方单位和中立单位）、`inLine()`（与它同行或同列、可以被直击选中的我方单位和中立单位，由近到远）、`blast(...)`（延时爆炸，敌能-3）、`bolt(...)`（直击弹道，敌能-4）、`setHp(t, hp)`（直接设定生命，伤害-9）、`resetSkills()`（技能冷却回到初始冷却）、`onWay(u)`（单位所在格是否在它走到当前移动段终点的路上，包括它自己所在格，寻路-2）、`detour(row, col)`（绕行，路线-6）、`fell`（是否掉进了地穴，地图-4）、`summon(key, ...)`（召唤敌人，敌能-22）、`remove(u)`（把一个敌人的生命直接设为 0）、`devour(t)`（吞噬，敌能-30）、`lend(t, key, ...)`（借出的 Buff，敌能-25）、`around(t, area)`（目标所在格和周围格内它可以攻击的单位，敌能-29）、`enemies()`（场上所有非中立的敌人，可选与否）、`fly()`（把自己的行动方式改成飞行，并清掉当前路段已经计划的点，路线-2）、`draw()`（一次 [0, 1) 的均匀随机，随机-1）、`attackAgain()`（把攻击冷却清成 0，下一次攻击不等攻击间隔，攻击-2、敌能-44）、`zone(...)`（放一片污染秽蚀，敌能-46）、`bleed(t, damage, seconds)`（流血，敌能-46）、`onLow(u)`（单位所在格是不是低地，敌能-46）、`ground()`（飞行的单位把行动方式改回地面，并清掉当前路段已经计划的点，路线-2）、`ammoOf(u)`（干员正在运行的弹药技能还剩几发，否则 0）、`spendAmmo(u, n)`（扣掉这么多，不低于 0，不因此结束技能）、`renew(u, key, frames, mods)`（把这个键的剩余帧数改成这么多，修饰器换成这一份；没有就新加）、`ours()`（场上还在的干员和我方装置）。

冷却为负的技能只用一次：用过之后不再就绪。

- 来源：设计决定，见 [ADR 0055](../adr/0055-sdk-prepared-now-built-after-mvp.md)；受伤和解除阻挡在下一帧的回合开始时才被看到为推断 INF-0069

### 敌能-3 延时爆炸

一次爆炸有中心、半径、延迟、伤害（类型、数值）、可选的异常状态（名字、秒数）、是否波及飞行单位。延迟结束的那一帧（帧-1 的投射物阶段）对中心半径内（距离不大于半径）的我方单位和中立单位各造成一次伤害并施加异常状态。爆炸无视迷彩；隐匿生效的单位不在爆炸范围内（索敌-2）。来源无效时伤害没有来源。

- 来源：[PRTS「特殊机制」oldid=440928](https://prts.wiki/index.php?title=%E7%89%B9%E6%AE%8A%E6%9C%BA%E5%88%B6&oldid=440928) 死亡爆炸：「将会在攻击弹道发出点（没有的情况下在原地）释放一个延时爆炸弹道，在弹道延迟结束后对一定半径内的我方单位造成伤害」；[PRTS「冰爆源石虫」oldid=435593](https://prts.wiki/index.php?title=%E5%86%B0%E7%88%86%E6%BA%90%E7%9F%B3%E8%99%AB&oldid=435593)「爆炸半径1.65，延迟1秒，爆炸时来源无效……无视迷彩，不可对空」；从敌人当前位置发出、按圆心距离判定为推断 INF-0070

### 敌能-4 直击弹道

直击弹道从敌人的位置沿行或列（上、下、左、右之一）直线飞行，速度为每秒 10 格，碰到第一个我方单位或中立单位（与它的中心距离不大于 0.3，隐匿生效的不命中，无视迷彩）时命中：造成伤害、施加异常状态，或者在命中处引发一次爆炸（敌能-3，延迟 0）。飞出地图时消失。

- 来源：[PRTS「特殊机制」oldid=440928](https://prts.wiki/index.php?title=%E7%89%B9%E6%AE%8A%E6%9C%BA%E5%88%B6&oldid=440928) 直击：「此技能仅自身未被阻挡，且所在行列（基于射线，碰撞判定）存在……我方单位时可触发；此技能发射的弹道碰撞半径0.3（无视迷彩）」；弹道速度为推断 INF-0071

### 敌能-5 死亡爆炸

天赋 `boom`（冰爆源石虫、冰爆源石虫·α、高能源石虫、高能源石虫·α）、`Boom`（"喷射罐""喷爆罐"、辐能源石虫、辐能源石虫·α）：被击倒时，没有被沉默的话，在原地引发一次爆炸（敌能-3），伤害为攻击力 × `atk_scale`；有 `freeze` 时施加 `freeze` 秒的寒冷。有 `add_count` 时（辐能源石虫），场上其他每个有能量的敌人获得 `add_count` 点能量（敌能-13）。

| 敌人 | 半径 | 延迟 | 类型 | 飞行单位 |
|---|---|---|---|---|
| 冰爆源石虫、冰爆源石虫·α | 1.65 | 1 秒 | 物理 | 不波及 |
| 高能源石虫、高能源石虫·α | 1.25 | 1 秒 | 物理 | 不波及 |
| "喷射罐""喷爆罐" | 1.55 | 0 | 法术 | 波及 |
| 辐能源石虫、辐能源石虫·α | 1.25 | 0.5 秒 | 法术 | 不波及 |

"喷射罐"死亡时还会熄灭周围的"紧急供暖器"，引擎还没有这种装置。

- 来源：[PRTS「冰爆源石虫」oldid=435593](https://prts.wiki/index.php?title=%E5%86%B0%E7%88%86%E6%BA%90%E7%9F%B3%E8%99%AB&oldid=435593)「死亡爆炸（爆炸半径1.65，延迟1秒，爆炸时来源无效，造成攻击力200%的无途径物理溅射伤害并施加持续10秒的寒冷，无视迷彩，不可对空）」；[PRTS「"喷射罐"」oldid=435426](https://prts.wiki/index.php?title=%E2%80%9C%E5%96%B7%E5%B0%84%E7%BD%90%E2%80%9D&oldid=435426)「死亡后熄灭周围3x3范围内的紧急供暖器并对半径1.55范围内的我方单位造成攻击力100%的法术溅射伤害与10s寒冷（可被沉默）」；[PRTS「特殊机制」oldid=440928](https://prts.wiki/index.php?title=%E7%89%B9%E6%AE%8A%E6%9C%BA%E5%88%B6&oldid=440928)「如无特殊说明，此能力默认可沉默」；[PRTS「冰爆源石虫·α」oldid=435594](https://prts.wiki/index.php?title=%E5%86%B0%E7%88%86%E6%BA%90%E7%9F%B3%E8%99%AB%C2%B7%CE%B1&oldid=435594) 同冰爆源石虫；[PRTS「辐能源石虫」oldid=435841](https://prts.wiki/index.php?title=%E8%BE%90%E8%83%BD%E6%BA%90%E7%9F%B3%E8%99%AB&oldid=435841)、[PRTS「辐能源石虫·α」oldid=435842](https://prts.wiki/index.php?title=%E8%BE%90%E8%83%BD%E6%BA%90%E7%9F%B3%E8%99%AB%C2%B7%CE%B1&oldid=435842)「死亡爆炸（爆炸半径1.25，延迟0.5秒，造成攻击力400%的法术溅射伤害，不可对空；给予全场敌人1点能量）」，数据：Boom.atk_scale 4、add_count 1；[PRTS「高能源石虫」oldid=413890](https://prts.wiki/index.php?title=%E9%AB%98%E8%83%BD%E6%BA%90%E7%9F%B3%E8%99%AB&oldid=413890)「死亡爆炸（爆炸半径1.25，延迟1秒，爆炸时来源无效，造成攻击力400%的无途径物理溅射伤害，无视迷彩，不可对空）」；[PRTS「高能源石虫·α」oldid=375693](https://prts.wiki/index.php?title=%E9%AB%98%E8%83%BD%E6%BA%90%E7%9F%B3%E8%99%AB%C2%B7%CE%B1&oldid=375693)「死亡爆炸（爆炸半径1.25，延迟1秒，爆炸时来源无效，造成攻击力400%物理溅射伤害，无视迷彩，不可对空）」，数据：boom.atk_scale 4；"喷射罐"的延迟和对空为推断 INF-0072

### 敌能-6 喷射

天赋 `Boom` 带 `attack@times` 时（"喷射罐""喷爆罐"）同时改变它们的普通攻击，不带时（辐能源石虫）不改变：不按攻击间隔；一次攻击持续 `attack@cooldown` 秒，期间对目标造成 `attack@times` 次攻击力 × `atk_scale` 的法术伤害，第 k 次（从 1 数）在攻击开始后 k × 持续时间 ÷ 次数秒；结束后冷却 `attack@attack_cd` 秒才能开始下一次。

- 来源：[PRTS「"喷射罐"」oldid=435426](https://prts.wiki/index.php?title=%E2%80%9C%E5%96%B7%E5%B0%84%E7%BD%90%E2%80%9D&oldid=435426)「普通攻击不依赖攻击间隔。单次普通攻击持续4s，共造成3次攻击力100%的法术伤害，结束后进入3s冷却」；数据：Boom.attack@times 3、attack@cooldown 4、attack@attack_cd 3；各次伤害的时刻、键名与持续和冷却的对应为推断 INF-0073

### 敌能-7 首次攻击

天赋 `FirstAttack`（"投石机""榴弹炮"）：第一次攻击可以打到攻击半径（`rangeRadius`）内的目标，对目标及其上下左右相邻 4 格上的我方单位和中立单位造成攻击力 × `attack@first_atk_scale` 的法术伤害（锁定的目标照常；其余隐匿生效的不在其中，迷彩照常，索敌-2）；此后只攻击阻挡它的单位，造成物理伤害。

- 来源：[PRTS「"投石机"」oldid=435468](https://prts.wiki/index.php?title=%E2%80%9C%E6%8A%95%E7%9F%B3%E6%9C%BA%E2%80%9D&oldid=435468)「首次攻击对目标及其周围4格造成攻击力150%的法术伤害，此后仅进行近战攻击，造成物理伤害」「可以抛出巨大雪球造成十字溅射伤害」；周围 4 格即上下左右相邻格为推断 INF-0074

### 敌能-8 低血强化与远近攻击

天赋 `atkup`（帝国前锋精锐）：生命低于最大生命的 50% 时攻击力 +`atk`（直接乘算），回到 50% 以上时取消。“复仇者”的 `atkup` 给出 `hp_ratio`、没有 `atk`：生命不高于最大生命的 `hp_ratio` 时攻击力 +`AtkUp` 的 `atk`；`AtkUp` 的 `damage_resistance` 不使用（见 敌能-18）。帝国前锋精锐（攻击方式 `ALL`）未被阻挡时可以远程攻击半径内的地面单位，造成攻击力 50% 的物理伤害；目标的嘲讽等级相同时优先中立单位。被阻挡时只攻击阻挡它的单位。匪帮轰击者、匪帮轰击者头目（攻击方式 `ALL`）同样，未被阻挡时的远程攻击造成攻击力 50% 的物理伤害，并且打到目标所在格及周围 8 格上的我方单位和中立单位（`square`；锁定的目标照常，其余隐匿生效的不在其中，迷彩照常，索敌-2）。

- 来源：[PRTS「匪帮轰击者」oldid=435794](https://prts.wiki/index.php?title=%E5%8C%AA%E5%B8%AE%E8%BD%B0%E5%87%BB%E8%80%85&oldid=435794)、[PRTS「匪帮轰击者头目」oldid=435795](https://prts.wiki/index.php?title=%E5%8C%AA%E5%B8%AE%E8%BD%B0%E5%87%BB%E8%80%85%E5%A4%B4%E7%9B%AE&oldid=435795)「未被阻挡时可进行远程攻击，对目标及周围8格内的我方单位造成攻击力50%的物理伤害」；[PRTS「帝国前锋精锐」oldid=435717](https://prts.wiki/index.php?title=%E5%B8%9D%E5%9B%BD%E5%89%8D%E9%94%8B%E7%B2%BE%E9%94%90&oldid=435717)「未被阻挡时可进行远程攻击，远程攻击造成攻击力50%的物理伤害，不会攻击飞行单位」「目标嘲讽等级相同时，远程攻击优先攻击乌萨斯平民/斗士塔露拉/矿工游击队」「生命值低于50%时，攻击力+100%」；回到 50% 以上取消为推断 INF-0075

### 敌能-9 直击

技能 `CrossAttack`（速射轻弩手、重弩突袭者及其进阶）：初始冷却 `initCooldown` 秒、每次发动后冷却 `cooldown` 秒。冷却结束、自身未被阻挡、能行动且没被沉默，并且同行或同列有可以直击的目标时发动，朝最近的那个目标的方向：

- 速射轻弩手、速射劲弩手：发射 3 支直击弹道（敌能-4），各造成攻击力 100% 的物理伤害；
- 重弩突袭者、重弩猎杀者：原地停留 2.5 秒（技能持续时间），蓄力 1.4 秒后发射 1 支直击弹道，造成攻击力 × `atk_scale` 的法术伤害和 `stun` 秒的晕眩。它们的天赋隐匿：未被阻挡、也不在技能中时有隐匿（不能被我方选中）。这段时间把 `hide` 去掉，所以放开阻挡后不走索敌-2 的 3 秒窗口；条件结束的下一回合再加回。

- 来源：[PRTS「速射轻弩手」oldid=436612](https://prts.wiki/index.php?title=%E9%80%9F%E5%B0%84%E8%BD%BB%E5%BC%A9%E6%89%8B&oldid=436612)「直击：向目标方向发射3支弩箭，每支弩箭对击中的首个目标造成攻击力100%的物理伤害」；[PRTS「重弩突袭者」oldid=437074](https://prts.wiki/index.php?title=%E9%87%8D%E5%BC%A9%E7%AA%81%E8%A2%AD%E8%80%85&oldid=437074)「直击：蓄力1.4s后向目标方向发射1支弩箭，对击中的首个目标造成攻击力100%的法术伤害与5s晕眩」「技能持续2.5s」「隐匿（被阻挡，主动攻击期间均可解除）」；[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223)「隐匿：不阻挡时不成为敌方攻击的目标」；3 支同时发射、冷却从发动起算、停留与蓄力期间被阻挡仍继续为推断 INF-0076

### 敌能-10 掷弹

技能 `Bomb` 与天赋 `Light`（无畏掷弹兵）：未被阻挡、没被沉默时第一次受到伤害后（只有一次），向上下左右各发射一枚直击弹道（敌能-4），命中时引发半径 `projectile_range` 的爆炸（敌能-3，延迟 0），对其中的我方单位和中立单位造成攻击力 × `atk_scale` 的物理伤害；之后移动速度 +`Light.move_speed`（直接加算），重量 +`Light.mass_level`。

### 敌能-13 能量与过载

- **能量**（天赋 `blacksteel_energy`）：敌人出现时有 `init_stack_cnt` 点能量（没有为 0），上限 `max_stack_cnt`。每点能量使攻击力直接乘算 +10%、防御力直接乘算 +20%（作为键为 `energy` 的 Buff）。增减能量时限制在 0 和上限之间；处于过载时能量不增减。

### 敌能-27 多目标与冰原

- **多目标**（`Targets`，数据里没有，内容按 PRTS 加上）：一次攻击锁定 `n` 个目标（索敌-5 的顺序取前 n 个）；`direct` 为 1 时不发射投射物，直接命中。萨卡兹积怨者、恶咒者为 2 个、直接命中；冰原术师（队长）为 2 个。
- **寒霜一击**（技能 `coldattack`）：每次普通攻击得 1 点；攒够技能的技力消耗后，下一次攻击是技能攻击——命中时施加 `freeze` 秒寒冷——点数清零。
- **抵抗**（`Resist`，数据里没有，内容按 PRTS 加上）：始终持有抵抗（状态-5）。冰原术师（队长）、冰原狂战士队长。

### 敌能-35 支援光环与暴露

同名天赋按 blackboard 的形状分开。光环用借出的 Buff（敌能-25）：一个效果一个键，几份不叠加；持有者被沉默就不再借出，最迟两帧后消失。半径按圆心距离，不超过该半径算在内。

- **不进行普通攻击**（御4、寒霜，`defup` 带 `range_radius`）：出现时起不普通攻击（`noAttack`）。「可被沉默」写在光环那一句上，被沉默也不恢复攻击。静态刚体不在本条。
- **防御力**（`defup` 同时有 `def` 和 `range_radius`，御4）：半径内的其他非中立敌人防御力直接加算 + `def`（300），键 `defup`。只有半径、没有 `def` 的（寒霜）不加防御。只有 `def`、没有半径的还没有行为（关卡-2）。「实体类型为默认类或装置类」为推断 INF-0307。
- **法术抗性**（`magdef_add`，护障、护障·P）：自身攻击范围内的其他非中立敌人法术抗性直接加算 + `magic_resistance`（30），不含自己，键 `magdef`。攻击范围按记录的 `rangeRadius` 的圆心距离，不加干员碰撞的 0.25，为推断 INF-0308。
- **攻击速度**（`atkSpeedDown` 带 `range_radius`，寒霜）：半径内它可以选中的我方单位（不含中立；隐匿的不算）攻击速度直接乘算 `attack_speed`（−0.5），键 `frostAspd`。数据把 2.5 写在 `defup` 上，内容按页面加到 `atkSpeedDown`。直接乘算为推断 INF-0309。没有 `range_radius` 的 `atkSpeedDown` 仍是畸变恶性瘤（敌能-23），键仍是 `atkSpeedDown`。
- **暴露**（`Expose` 带 `range_radius`，远眺）：被击倒且没被沉默时，半径内它可以选中的我方单位（不含中立；隐匿的不算）获得 `weak[limit]` 秒脆弱，v = `damage_scale` − 1（状态-5；同名效果取最高，状态-2）。走到终点不算被击倒（敌能-2）。没有半径的 `Expose` 还没有行为（关卡-2）。v 与「20%脆弱」的对应为推断 INF-0310。暴露还可以无视封阻物或作战专用掩体触发直击；引擎还没有这些装置，这一半不起作用。

### 敌能-36 攻击回复的下一次攻击

技能 `stuncombat` 与 `PowerAttack` 按攻击回复技力，每次开始一次攻击记 1 点。技力还不到消耗 `sp` 时，这次仍是普通攻击，技力加 1，不超过消耗。技力已经满、冷却就绪、且没被沉默时，这次改为技能攻击：技力清零，冷却按该技能的 `cooldown` 重计（敌能-2 的 `use`）。冷却还没就绪，或正在被沉默时，不释放，技力停在消耗上；被沉默时普通攻击仍加技力。

- **眩晕打击**（`stuncombat`，粉碎攻坚手、粉碎攻坚组长、码头水手、码头水手长）：技能攻击命中时施加 `stun` 秒晕眩。攻坚手和组长的消耗是 2、晕眩 7 秒；水手和水手长的消耗是 3、晕眩 7 秒。能力以 ※ 开头，可被沉默。天赋 `Drown` 没有行为，关卡仍因它拒绝。

- **寒晖与二连击**（澪的 `PowerAttack`）：`times` 数据里没有，内容按 PRTS 加上 2。每次攻击的命中次数都乘这一个 2；寒晖再乘 `atk_scale`，不把技能表里的「2次」再乘一次。弹开「某种天命」不做。页面写她有沉默抗性（数据：`silenceImmune` 为真），沉默不会上身；行为只看身上有没有沉默。

### 敌能-39 岁兽残响

残响（木制瑞印、红木瑞印、小说卷轴、诗画卷轴、青铜镜、黄铜镜、木制镇纸、红木镇纸）具有特殊生命值。数据里没有这项天赋，内容按图鉴给它们加上 `hitCount`。生命值就是击倒所需的次数（数据的 `maxHp`：2、3、3、4、30、35、3、4），不另换算。关卡符文 `enemy_attribute_mul` 的 `max_hp` 仍按关卡-2 乘在这个次数上，每次成功伤害仍只减 1。

- **扣 1 点**：成功受到伤害、计算完毕、应用生命值变化时，生命只减 1，不论算出的伤害是多少。伤害本身不变：命中事件的伤害数值和造成伤害的返回值仍是算出的数（伤判之后、扣生命之前），不改成 1。带不死时，扣这 1 点之后仍按伤害-9 不低于 1。
- **算一次**：伤判结束后剩下的伤害大于 0，物理、法术、真实、元素都算。屏障先吸收，剩下的大于 0 仍算一次，事件里的数是剩下的。元素爆发走同一次伤害结算，算一次；攻击附带的元素损伤只加元素值，不另扣一次生命。只接受部分类型的（敌能-43）里，类型不符合的不减生命，伤害数值仍不变。
- **不算**：算出的伤害不大于 0、未命中、闪避、抵挡、护盾取消、屏障把伤害吸到 0、无敌、沉睡（不穿透时）、隐匿、无法选中、`hit` 取消、目标生命已是 0。直接设定生命和强制击倒（伤害-9）不是这次伤害；坠落（地图-4）用直接设定生命，不算一击。
- **生命流失**（伤害-10）跳过「成功受到伤害」，不改成 1，按算出的数值全额扣除，一次就可以击倒。
- **治疗**（伤害-11）不是受到伤害，按治疗把生命加回去，不超过最大生命。加回的是剩余次数。
- **无法被阻挡、不进行普通攻击**：出场起就有 `unblockable` 和 `noAttack`。`blockCnt` 为 0、攻击力为 0 本身不够。
- **失衡移动阻尼不实现**。位移-3 只有全体共用的摩擦（μ = 0.5），没有按单位的线性阻尼。木制瑞印、红木瑞印、诗画卷轴、青铜镜、黄铜镜、木制镇纸的页面写了「具有0.5失衡移动阻尼」；小说卷轴、红木镇纸的页面没有这句。

### 敌能-40 受创奔跑

两类敌人受创后加快移动。都不是冲锋（敌能-19）：不选目标，不绕行。

- **不攻击且不可阻挡**（天赋 `run`，鸭爵）：出场起就不进行普通攻击（标记 `noAttack`）、不可阻挡（标记 `unblockable`，已有的阻挡在这一帧解除）。攻击方式 `NONE`、半径 0 仍会打阻挡者（敌人攻击-1），所以不攻击要单独的标记。页面级别 0、1、2 写的是同一句；`enemy_2001_duckmi_2` 用同一项天赋，页面没有这名敌人。
- **开始奔跑**：第一次 `hurt` 为真时（敌能-2：当前生命低于上一回合记下的生命，下一回合开始时才看到），移动速度直接乘算 + `attack@move_speed`（属性-2 的 `movePct`）。没有结束时间，离场前一直保持，再次下降不叠加（推断 INF-0328）。级别 0 的数据是 4（+400%）；`enemy_2001_duckmi_2` 的数据是 3。
- **什么算受到伤害**（按天赋「受到伤害时」，不按能力简介的「受到攻击后」把下面几条改掉）：
  - 成功扣除生命的伤害算。伤害为 0、无敌、伤判把伤害归零（闪避、护盾或屏障完全吸收，伤害-8）不算，生命没有下降。
  - 生命流失扣除了生命也算。生命流失是伤害（伤害-10），天赋写的是受到伤害；能力简介写受到攻击，而生命流失跳过受到攻击时点。按天赋，不把生命流失排除在外（推断 INF-0329）。
  - 直接设定生命使当前生命下降也算，因为 `hurt` 只比较生命；直接设定生命本身不是伤害（伤害-9）。下一回合开始前已经被治疗回不低于上一回合记下的生命，则不算（推断 INF-0330）。

### 敌能-45 深池逐火

天赋 `Revive[Trigger]`（深池逐火战士、深池逐火精锐战士、深池逐火护卫）。数据的键是 `Revive[Trigger].prop_max_hp`、`Revive[Trigger].interval`。敌能-1 按第一个 `.` 分组，方括号留在天赋名上，行为名就是 `Revive[Trigger]`。`prop_max_hp` 不大于 0 时，这次被击倒照常离场。

战士形态被击倒后重生 1 秒，然后变成余烬：怨恨的余烬、暴怒的余烬、贪欲的火灰。战士形态每次被击倒都进入这一次重生，不是只在第一次。余烬被击倒则离场，不再重生（推断 INF-0353）。

- **这 1 秒**（键为 `revive` 的 Buff，持续 1 秒，30 帧；页面写的时长，不是 blackboard）：无敌、不能被选中、不可阻挡、不移动且不行动（`sidelined`）、失衡免疫（`noDisplace`，位移-1）、不进行普通攻击（`noAttack`）。生命设为当时的最大生命，仍是战士形态的基础；触发的那次伤害不把生命留在 0。这 1 秒内再次致命，包括穿透无敌的生命流失（伤害-10），仍不离场，生命回到该最大生命，不重新清空 Buff。隐匿不在这 1 秒里（推断 INF-0354）。被击倒的那一帧生命已经是 0，敌人回合不走，已有阻挡留到下一帧，由不可阻挡解除。Buff 在被击倒那一帧结束时还剩 30 帧；再过 29 帧仍在重生，第 30 帧进入余烬。
- **清 Buff、重置冷却**（推断 INF-0356）：重生开始时清空身上除本次重生以外的全部 Buff，白名单为空。这 1 秒结束、变为余烬时，技能冷却回到初始冷却。页面只写了「重生」，这两句沿用敌能-18 引用的特殊机制。
- **余烬**：基础最大生命值换成 `prop_max_hp`。换基础时不按比例改当前生命，再把生命设成换算后的最大生命。没有其他生命修饰时，这个数就是最大生命，也就是击倒次数：只加 `hitCount`（敌能-39 的扣 1 点；生命流失仍按全额），不加残响出场时的无法被阻挡和不攻击。不进行普通攻击是余烬 Buff 上的 `noAttack`。获得隐匿（索敌-2）：被阻挡时不生效；这份 Buff 不写 `restore`，放开后按默认 3 秒（90 帧）恢复。余烬可以移动，也可以被阻挡；不可阻挡和失衡免疫只在那 1 秒（推断 INF-0358）。持续 `interval` 秒（数据为 10，300 帧）。这层 Buff 在进入余烬的那一帧加上，当帧不减，之后每帧减 1；减到 0 的那一帧、攻击之前变回战士形态。
- **退出**：`interval` 秒内未被击倒则变回战士形态，基础最大生命值恢复为进入重生前记下的值，并恢复所有生命（当时的最大生命，不是余烬剩下的比例）。之后再次被击倒仍重生。
- **护卫的基础与关卡符文**（推断 INF-0355）：战士、精锐写「最大生命值变为5」，护卫写「基础最大生命值临时变为10（退出此模式后恢复）」，数据都是 `prop_max_hp`（5、5、10）。关卡符文 `enemy_attribute_mul` 的 `max_hp` 在装配时乘进敌人记录的 `maxHp`（关卡-2），重生记下的是这个乘过的基础；`prop_max_hp` 不再乘一次。退出后基础恢复成记下的值。
- **缴械**（推断 INF-0357）：护卫余烬的可见句在「不进行攻击」之外还写了缴械。三种余烬都不进行普通攻击，被阻挡与否都是 `noAttack`。缴械不另加标记。`disarmedCombat` 是战栗，只在被阻挡时停手，这里不用。

- **`BornAnim`**：出生动画。冷却 0、初始冷却 0、blackboard 为空，没有规则效果。按 `AtkUp` 登记空行为：技能名算已覆盖，什么也不做。
- **其他携带者**：行为只读各自 blackboard 的 `prop_max_hp` 和 `interval`。深池逐火精锐护卫 `enemy_1292_duskld_2`、假想敌：再生 `enemy_9010_acpupp` 的天赋若是 `Revive[Trigger]`，就得到同一行为。这两页没有读，不加 `FOE_EXTRAS`。假想敌的其他能力不实现。

### 敌能-46 污染秽蚀、枯朽战车与流血

**污染秽蚀**是留在场上的一片区域（中心、半径、持续秒数）。距离不大于半径才算在内（与敌能-3 的爆炸相同）。范围内的我方单位按它所在格的高度受到真实普通伤害：低地取低地伤害，高地取高地伤害；防御和法术抗性都不减。没有所在格，或高度既不是低地也不是高地的，不受这次伤害（推断 INF-0370）。隐藏、或生命不大于 0 的，不在范围内。

- 第一次在区域放上之后 1 秒，之后每秒一次，一共持续秒数那么多次；最后一次的那一帧结束，区域就没有了（推断 INF-0359）。
- 同名效果不叠加：一个单位每秒最多受一次。同一帧有多片到期时，先放上的那片的数值生效；这一下被无敌挡掉也占掉这一秒（推断 INF-0360）。无敌仍按伤判挡住伤害（推断 INF-0361）。
- 可对空时，行动方式为飞行的单位也在范围内。起飞不是飞行（阻挡-2）：只有写明无视无法选择时才打到起飞、隐匿和无法选中。写明无视迷彩时迷彩也不挡。没有这句的区域仍按索敌-2，这四类都不在范围内（推断 INF-0362）。
- 没有这种区域时，它不进入状态哈希。

**死亡**（天赋 `PollutedDie`，萨卡兹枯朽战士 `enemy_1267_nhpbr`、组长 `enemy_1267_nhpbr_2`）：被击倒且没被沉默时，在原地放一片。半径 `projectile_range`（2），持续 `projectile_life_time` 秒（8），低地 50、高地 25。可对空，无视无法选择、迷彩。范围内是我方干员和召唤物，不包括装置和中立单位。坠落也是死亡（地图-4），同样放。走到终点离场不算被击倒。默认可沉默。

**枯朽战车**（天赋 `Empty`、技能 `PollutedRangedAtk`）是攻击回复的技能（敌能-12 的记法）：出现时技力等于消耗。页面写 2/2，数据没有单独的初始技力（`initCooldown` 为 −1，`Empty.sp` 也是 2），所以第一次攻击就是技能，之后每两次普通攻击再来一次（推断 INF-0371）。技力已满且没被沉默时，这次攻击改为技能，技力清零；否则技力 +1，不超过消耗。沉默时不改为技能，技力仍累加。

- 被阻挡时，不是技能的那一下伤害为攻击力 × `attack@chuang_atk_scale`（2，即 200%）。技能那一下即使被阻挡也是 100%（推断 INF-0363）。没被阻挡的普通攻击仍是 100%，也不放区域。

### 敌能-47 巢涌者的脉冲、神经损伤与抵抗

深溟巢涌者（`enemy_1234_dsubrl`）、富营养的巢涌者（`enemy_1234_dsubrl_2`）。天赋 `EpDamage` 的数据键是 `ep_damage_ratio`，不是敌能-38 的 `attack@ep_damage_ratio`，仍挂在同一个行为上：内容标记 `pulse` 为 1 时它是下面的脉冲，否则不完整（关卡-2）。天赋 `Buff` 只有数字 `one_minus_status_resistance` 时才是本条。两名的数据相同，页面写法不同，由内容标记 `form` 分开：1 是深溟巢涌者，2 是富营养的巢涌者。这些都写在天赋栏里，按「如无特殊说明，天赋默认不可沉默」，沉默不影响它们。

- **不进行普通攻击**：出场起带 `noAttack`。
- **脉冲**：攻击范围内每秒一次。射程是数据的 `rangeRadius` 再加 0.25（敌人攻击-1）。出场那一帧不打，满 1 秒才打第一下，之后每满 1 秒再打。富营养的巢涌者处于消失时计时停住，已经走了的时间留下，不归零；深溟巢涌者的页面没有写消失，消失时照打。
- **打谁**：这个射程里、按普通攻击那套可选规则选得到的我方干员（含召唤物）和我方装置。中立单位不打。隐匿、无法选中、沉睡、迷彩、消失、飞行单位不在里面。起飞的由既有的对地规避挡住，打上去也没有伤害和元素损伤。
- **法术伤害**：攻击力的 100%（页面上的数，数据里没有这一项），类型是法术，走伤害结算，吃法术抗性。不是普通攻击，不带 `isAttack`，不触发普通攻击上的附带元素损伤（敌能-38）。会计入受击回复（技能-2）。两页的「无类型法术伤害」和「法术普通伤害」在这里是同一种。
- **神经损伤**：元素是神经，数值是攻击力 × `ep_damage_ratio`（两名都是 0.05）。同一次脉冲里先算法术伤害。深溟巢涌者接着对每个打到的目标造成神经损伤，这一下没有扣到生命也造成；富营养的巢涌者「自身造成伤害时」才造成，即这一下实际扣了生命之后。元素损伤不再追加一次。这两名没有别的伤害，别的来源不在本条。
- **抵抗**：深溟巢涌者持有抵抗状态，强度是 −`one_minus_status_resistance`，一减状态抵抗率最终乘算为 1 + 这个数（数据 −0.5，即 ×0.5）。这是抵抗：麻痹因此掉层（状态-8）。富营养的巢涌者把同一个数直接加算进一减状态抵抗率，不加抵抗状态（页面写「非抵抗」），麻痹不因此掉层。默认一减状态抵抗率是 1 时，两者都是 0.5，可抵抗状态的持续时间都按状态-3 缩短。
- **停顿免疫**：持有 `immune:sluggish`，停顿施加不上（状态-7），身上没有停顿，按状态名去认停顿的也认不到。
- **不在本条**：退行的巢涌者（`enemy_1234_dsubrl_4`）数据同形，`ep_damage_ratio` 为 0.1，页面未读，不打标记，两项都不完整。引痕者（`enemy_1232_dssalr`、`_2`、`_4`）的 `Buff` 是 `hp_ratio`、`def`、`max_hp`、`block_volume`，`EpDamage` 的倍率是 0，都没有这些标记，仍不完整。`Creep` 不在本条。

### 敌能-48 近地悬浮与升空

掠海漂移体的天赋 `Float`，和喷气人的技能 `TakeOff`。吉兆飞鳞、噩兆飞鳞、自惧飞行不在本条。`TakeOff` 还挂在风遁忍者、风遁宗师、弧光突击队、弧光突击队队长、浮袭者上；那些页面没读，黑板不是下面这一形的仍不完整（关卡-2），运行时也不做。

- **近地悬浮**（`Float`，黑板为空）：出场就有，不等第一次被阻挡。Buff 键 `hover`，标记 `hover`（算作空中单位）和 `noDisplace`（失衡免疫），没有结束时间。地面干员挡不住，能挡飞行的才挡得住；近战干员一般选不中它，正在挡它的可以（阻挡-4）。行动方式保持地面，按地面路线走，不调用 `fly()`。悬浮期间照常攻击，没有 `noAttack`。和敌能-20 不同：那边第一次被阻挡后才悬浮、有时限、不攻击，结束后防御力直接加算 −1300。为推断 INF-0380。
- **失效**：晕眩、沉睡、无法行动、冻结（`freeze` 与 `enemyFreeze` 都算）任一加上，这次悬浮结束，不再回来。无法行动在本页和晕眩一样是晕眩标记；沉睡在本引擎不带晕眩，要单独看。浮空、麻痹震颤、束缚、沉默，以及合起来的「不能行动」，都不结束它（推断 INF-0381）。结束时解除阻挡，去掉这份 Buff，再晕眩 0.5 秒。触发的那份晕眩还在也照加；同一键排队，时间照常走，较短的一份可能在排队里走完（状态-2，推断 INF-0382）。冻结、沉睡和这 0.5 秒并行。

- **升空**（`TakeOff`）：黑板恰好两个数字，`duration` 和 `balloon_s[fly].move_speed`，多一个键就不是这项（推断 INF-0387）。冷却结束、当时被阻挡、能行动、没被沉默，就得到升空检测器，没有结束时间。看的是挡着，不是刚被挡上。初始冷却只决定第一次什么时候就绪。拿到的这一拍不检测，之后每 0.33 秒检测一次；这一拍没挡着就留着检测器，再等 0.33 秒。检测到被阻挡才升空，并撤掉检测器。沉默和不能行动只拦住发放；检测器在身上，或已经在飞，都不停。晕眩不暂停飞行和降落的计时（推断 INF-0385）。

### 敌能-51 一层物理或法术护盾

- **多段**：一次攻击的每一段各算一次。只有第一段物理或法术消耗层，后面的落下。

### 敌能-52 抗性降低

天赋 `def_reduce`（弧光镜卫、弧光镜卫长）。速胜卫士的 blackboard 与弧光镜卫相同，它的页面没有读过，不按这一条行动。

- **叠层**：每一下走到 `hpDamage`（敌能-2）获得 1 层：伤判之后还剩伤害、扣生命之前。这一下的防御、法抗已经算完，数值不变；下一下才用降低后的。同一帧里的每一下各算一层。
- **生效**：层数 ≥ 2 时才生效。生效时按全部层数计：n 层的防御直接加算为 n ×（`def` / `max_stack_cnt`），法术抗性同样用 `magic_resistance`，不是 (n − 1) 倍。1 层只记着层数，防御和法抗不变。2 层是防御 −100、法抗 −4；80 层是数据里的 −4000、−160。
- **弧光镜卫长**：同一个天赋、同一组键，也按 ≥ 2 生效，到 85 层（−4250、−170）。它的页面是较早的一版，写「每次受到伤害时，自身防御-50，法术抗性-2」，没有写「≥2层」，为推断 INF-0403。
- **门槛**：内容按页面补 `gate`（2）。没有这个数的 `def_reduce` 不起作用（关卡-2），速胜卫士因此未覆盖。
- **列与合计**：加在防御、法术抗性的直接加算（`defFlat`、`resFlat`）。数据里的 `def`、`magic_resistance` 是叠满的合计，每层是合计除以 `max_stack_cnt`。算完仍按属性-3 限制范围（防御、法抗下限 0）。
- **上限**：到 `max_stack_cnt` 层为止，再受到伤害不加层。
- **不去**：层数没有持续时间，不随时间消失，也不会被清掉或减少。
- **外观**：`change1_stack_cnt`、`change2_stack_cnt`（镜卫 15 与 45，镜卫长 15 与 60）是持有不低于这些层时的特效或特征变化，不改规则，不实现。

- **沉默**：这是天赋，天赋格没有写可被沉默；「天赋&能力」栏标题的提示写天赋默认不可沉默。沉默不停它。

### 敌能-53 穿刺手加速

天赋 `rush`、`firstattack`（萨卡兹穿刺手、萨卡兹穿刺手组长）。不是「复仇者」的技能 `Rush`（敌能-19），也不是投石机的天赋 `FirstAttack`（敌能-7）。

只认读过的两页。`rush` 要有 `dlancer_t[trigger].move_speed`、`dlancer_t[trigger].interval`、`dlancer_t[trigger].trig_cnt`，`firstattack` 要有 `atk_scale`，并且内容按这两页补上 `paged`。`firstattack` 没有自己的行为，它的 `atk_scale` 由 `rush` 读。没有 `paged` 的 enemy_5059_yrlanc（另有 `CollectCoin`）、enemy_5007_lancfd，以及黑板是 `mcndog_t`、`mcnrsh_t`（另有 predelay，叶毯还有 `weak[limit]`）的结构性原理、叶毯，都不由这里实现。

- **进入与退出**：敌人回合开始时，没被阻挡、也没有晕眩或束缚，进入加速状态。被阻挡不退出：已经在加速状态里时，挡住后照样保持，层数不变；不在加速状态里时，被阻挡就不进入。退出只有两种：下面的额外一击之后，以及晕眩或束缚——还在的每一回合都退出，并且不进入。冻结、沉睡、缚地不退出。晕眩、束缚按状态-5 的 `stun`、`root`。
- **层数**：进入的那一拍（登场，以及退出后再次进入）不获得层，也不算一次尝试。此后每 `interval` 秒尝试一次。加速状态中、次数未满时，尝试会成功：加 1 层移动速度直接乘算 +`move_speed`（页面的 +50%），层数相加，记在一份没有期限的加成上（`movePct` = `move_speed` × 层数，与按属性-2 把同样多的层加在一起相同）。到 `trig_cnt` 次后留在加速状态，不再加层。被阻挡的那一拍不尝试、不消耗次数，间隔计时也停着；晕眩、束缚的那一拍已经退出。
- **退出时**：去掉这份移速加成，尝试次数和间隔计时都回到 0。
- **额外一击**：加速期间（包括被挡住之后），普通攻击打掉了目标的生命时，按当时的移动速度属性（属性-1 的 `moveSpeed`，页面「移动速度」一栏的数，不乘 `move_multiplier`）× `atk_scale` 再造成一次物理伤害。这一次不是攻击（不带 `isAttack`）。普通攻击先结算，再结算这一次，然后退出加速状态。普通攻击已经把目标打到 0 生命时，这一次打不出伤害（伤害-7），加速状态仍然退出。打掉 0 生命的命中不是成功攻击，不加这一次，也不退出。
- **沉默**：两页都没写可被沉默。天赋&能力栏标题的提示写「如无特殊说明，天赋默认不可沉默」，沉默不停这两项。

移动速度栏的提示把该属性值和实际走速分开：「游戏内敌人的实际移动速度 = 该属性值 × move_multiplier（参数），通常情况下该参数为0.5」。数值顺序的提示把「±Y%」放在③直接乘算。穿刺手页晕眩的术语提示是「状态机尝试切换至STUN（无法攻击、释放技能、阻挡敌人类单位；敌人类单位无法移动）」；组长页的同一提示没有「；敌人类单位无法移动」。束缚的术语提示是「无法移动」。
